# 多级引用链的指针常量（追链由一层改为循环）

日期：2026-10-07。状态：已完成。`gen/sym_ct_lit_text` 的一次小改，三个调用侧同时受益。

## 实测先行的两个发现

**① 单文件侧多级链本来就可用**：三级链探针 `C1 = "hi"; C2 = C1; C3 = C2;` + `$first(C3)` → `rc=0`。
因为这类常量在前端折叠后 `cval` 直接可用，`F_ADDR` 路径不一定被走到。（所以 todo 里
「两级链仍拒绝」的说法只对**跨模块**成立。）

**② 跨模块侧三级链确实失败**（这才是真问题）：

```
../math/src/api.yh:86:1: 错误: pub 指针常量（字符串）暂不支持跨模块导出
```

原因：`gen/sym_ct_lit_text` 只追**一层** —— `CHAIN_3 → CHAIN_2` 追到了，但 `CHAIN_2` 自己
也是 kind 3（引用式），函数当时要求被引用者必须是 kind 2，于是返回失败。

## 改动：一层 → 循环（带跳数上限）

```yh
pub fn sym_ct_lit_text(sym_id int, out_off *int, out_len *int) int {
    let cur int = sym_id;
    let hops int = 0;
    for hops < 16 {
        let kind int = g_state.c_syms[cur].const_expr_kind;
        if (kind == 2) { ...填 out_off/out_len; return 0; }   // 到字面式
        if (kind != 3) { return 1; }
        let nxt int = sym_lookup_off(...);
        if (nxt < 0 || nxt >= g_state.c_sym_n || nxt == cur) { return 1; }
        if (g_state.c_syms[nxt].kind != SYM_CONST
            || (g_state.c_syms[nxt].flags & F_ADDR) == 0) { return 1; }
        cur = nxt;
        hops += 1;
    }
    return 1;   // 超过 16 跳：环或超深链，按不支持处理
}
```

跳数上限同时兜住两件事：`A -> B -> A` 这类**环**（不会死循环），以及病态的**超深链**。
「被引用者必须仍是 `SYM_CONST + F_ADDR`」的检查保留在每一跳上。

## 效果

| 写法 | 之前 | 现在 |
| --- | --- | --- |
| 跨模块 `pub const A *char = "hi";` | 可用 | 可用 |
| 跨模块 `pub const A *char = B;`（B 字面式） | 可用（第 42 轮） | 可用 |
| 跨模块 `A = B = C = "hi"`（多级） | **拒绝** | **可用** |
| 单文件多级链 | 本来可用 | 可用 |
| `= base.TEXT`（模块限定名） | 拒绝 | 仍拒绝（名字池里没有限定名，追链只能跟裸标识符） |
