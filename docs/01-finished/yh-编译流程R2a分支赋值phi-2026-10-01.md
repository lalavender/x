# yh 编译流程 R2a：分支赋值与 phi 合流（2026-10-01）

本切片在已有标量参数、顺序单绑定局部变量与同类型赋值基础上，增加单层
`if/else` 赋值合流。函数可在分支前声明并初始化标量局部变量；两个分支块可按序
赋值参数或这些局部变量，后续单个 `return` 读取合流后的当前值。每个变化的绑定在
四块 CFG 的合流块中生成具有 then/else 前驱输入的 typed phi。原先两个分支直接
return 的三块 CFG 路径保留。嵌套条件、循环、分支内声明、分支后继续执行语句和复杂
内存/聚合赋值仍不进入当前 lowering 子集。

局部 lowering 与 phi/分支缓冲管理拆到 `compiler/parse/ast_ir_control.yh`，主 lowering
保留在 `ast_ir.yh`。函数缓存键版本升至 v5；IR 序列化格式未变，缓存中仍验证 target、
CFG、phi 前驱与 SSA 支配关系。

`tests/modules/projects/irfront/main/main.yh` 增加 `branch_update` 与 `branch_local`：
前者覆盖分支前参数在一侧更新、另一侧沿用原版本；后者覆盖分支前 `let` 初始化的
局部变量在两侧分别更新。项目门检查两份四块缓存都含双输入 phi，并实际运行两条路径；
程序退出码为 219。缓存门现要求 11 个函数 IR，入口变化全命中，局部函数实现变化只
失效一项，损坏缓存拒绝后重建。`yh check` 仍在 IR 前结束。
