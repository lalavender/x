# yh test 测试体降低与运行期断言（YT2a）实施记录

日期：2026-10-23。范围：把 test 体降低为模块内 `pub` 无参 `void` 函数，
把 `$assert` 降为运行期调用，并在 `--no-run` 下走完整
CheckedModule→SSA→LLVM→对象发布。测试入口模块、逐例进程、结果协议、
`testing.fail/skip`、超时与汇总属 YT2b，未实现。

## 交付

- `compiler/parse/parse_decl.yh`
  - 测试模式下 pass1 为每条 test 登记内部函数
    `__yh_test_<file>_<decl>`（`F_GLOBAL | F_PUB`、无参、返回 `void`），
    符号写回该文件 `PDecl.test_sym`；
  - pass2 用正常函数上下文（`sem_fn_begin` + `ast_function_begin` +
    `parse_block` + `sem_fn_end` + `ast_function_end`）解析并捕获测试体，
    断言体标记 `c_test_body`；
  - 生产构建保持 pass1 跳过、pass2 只做语法检查，零符号、零发射。
- `compiler/parse/parse_comptime.yh`
  - 测试体内 `$assert(cond[, msg])` 降为
    `__yh_test_assert(cond, line, col, msg)`：条件是普通运行期表达式，
    不要求编译期常量；消息可省略（生成空指针字面量）；
  - 生成实参与实参链共用断言调用的 token 范围，避免父节点范围校验失败。
- `compiler/parse/parse_stmt.yh`：测试体内的 `$assert` 语句按普通表达式语句
  （`AST_STMT_EXPR`）记录，而不是编译期诊断语句。
- `compiler/builtin/prelude.yh`：登记
  `__yh_test_assert(bool, int, int, *char) void` 内建声明（无运行时定义）。
- `compiler/ast/`、`compiler/check/`
  - `TK_TEST` 声明进入 `AstDecl`/`AstFunctionContext`/`CheckedModule`；
  - `PDecl` 增加 `test_sym`，测试函数不能按源码名字反查；
  - `check/verify` 与 `check/checked_module` 允许生产构建中
    `sym_id == -1 && body_stmt == -1` 的 test 声明。
- `compiler/cmd/test_cmd.yh`：`--no-run`/默认命令不再走 check-only，
  发布测试模块对象（不链接）；新增 `--emit-llvm` 审阅开关；
  输出改为「测试构建通过: N 个用例」。

## 语料与门禁

- `tests/modules/test-check.py` 增至 19 条断言，新增：
  - `emit-llvm`：`yh test --no-run --emit-llvm` 成功；
  - `test-bodies-lowered`：对象含 `__yh_test_*` 定义、LLVM 文本含
    `call void @"__yh_test_assert"`；
  - `production-has-no-test-symbols`：生产 `.build` 对象零测试符号。
- `tests/modules/projects/ytest` 的 8 条测试全部降低（含跨文件私有调用、
  文档测试与平台文件）。

## 验证

- `make test`：语法 81/81、49/49；run 211/212、fail 136/136、pass 9/9；
  `test-check` 19/19；TOML 6/6；代码统计 6/6。
- `make selfhost-native`：模块固定点一致、cc4 自解析 114 个源文件、
  project cases 121/121 全绿。
- 手工核对 `tmp/yh-test/check/llvm/ytest-app.ll`：测试函数体包含
  跨模块调用、条件比较与 `__yh_test_assert` 调用；生产 `.build` 对象无
  `__yh_test` 符号。

## 边界

- `__yh_test_assert` 只有编译器内建声明，尚无运行时定义，测试二进制无法链接。
- 没有测试入口模块、逐例进程、结果协议、`fail`/`skip`、超时与汇总；
  `yh test` 不执行任何测试体。
- 测试函数是模块 `pub` 符号，但仍不写入 `.s.i`/生产对象（仅测试模式登记）。
- 未滚种子；compiler 源码仍不含 test 块。
