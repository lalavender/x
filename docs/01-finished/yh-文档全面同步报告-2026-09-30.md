# yh 全仓库文档同步报告

日期：2026-09-30。范围：全部现行文档（README、AGENTS.md、CONTEXT.md、
`compiler/README.md`、`docs/03-design/`、`docs/adr/`、`docs/02-plan/`、
`docs/todo.md`）。**未修改编译器代码与测试。**

## 背景

0.0.3 删除了 C 版 stage0（`src/`）与 `bootstrap/`，清单文件由 `mod.toml`
改名 `project.toml` 并删除 `entry` 字段，CLI 改为子命令式。这些变更在
一轮内集中落地，文档未同步，出现大量会误导读者的事实性错误陈述。

## 核对基准（实测，非推断）

- CLI 实测：`yh --syntax-check <file>`、`yh --emit-asm <file>`、
  `yh -o <out> <file>`、`yh build [-o out] [module]`、`yh run`、
  `yh version`、`yh list [--resolve name]`。`-c`、`-run`、`-sysroot`、
  `-Wl,-oformat=...` 实测均打用法并以退出码 2 失败——**已删除**。
- Makefile 实测目标：`all`、`seed`、`install`、`uninstall`、`test`、
  `selfhost-native`、`test-all`、`explorer`、`clean`、`help`。
  **无 `bootstrap`、无 `g3`**。
- 目录实测：`src/`、`bootstrap/`、`VERSION` 不存在；
  `compiler/` 为 gen/lex/parse/cmd 四模块共 25 个 `.yh`、13,338 行；
  `compiler/project.toml` = name `yh` / version `0.0.3` / source `.`，无 entry。
- 语言实测：数组字面量语法是 `[1,2,3]`（无类型前缀、无花括号），
  `[4]int{1,2,3,4}` 会报「元素个数与数组长度不一致」。
