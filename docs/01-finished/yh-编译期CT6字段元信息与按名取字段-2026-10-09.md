## P1b `$for f in T.fields`

### 语法

无需改 g4：`comptimeForStmt` 的 `IDENT '.' IDENT` 形态已覆盖（与
`$for v in E.values` 同形），分派在解析期按 `.` 之后的固定名完成
（`values` → 枚举、`fields` → 结构体/联合体）。

### 语义与实现

- `gen/model.yh` 新增 `F_FIELD_META` 元信息绑定标志；绑定槽位约定：
  `offset` = 字段下标、`type_id` = **字段类型**（因此可直接作
  `$is_type(f, T)`/`$is_int(f)`/`$is_float(f)` 的静态类型引用）、
  `cval` = 宿主结构体/联合体类型 id（投影字段名时查字段表）、`const_ready = 1`。
- `parse/parse_comptime.yh` 新增 `parse_comptime_field_for`：按字段**声明顺序**
  展开（`t_fields[owner.sub + i]`），每轮建立只读绑定；
  typed 路径把每个字段保存为 wrapper（op=0）下的独立块，普通路径逐轮解析发码
  ——与 `E.values` 完全同构；规模预算复用 `ct_charge_expansion`（1024/字段）。
- `gen/sem_value.yh` 新增 `sem_field_meta_name`：把 `.name` 投影为只读字段名
  静态 C 字符串（`em_data_name_string` + `name_off/len`）。
- `parse/parse_expr.yh`：成员访问分支识别元信息绑定（枚举/字段共用一次
  标志读取），字段元信息只允许 `.name`；裸用（非谓词实参位置）报
  「字段元信息迭代变量必须访问 .name 或作类型谓词实参」。
- 谓词实参放行：`gen/state.yh` 新增 `c_ct_meta_bare` 计数，
  `parse_comptime_pred` 解析实参期间递增——`$is_type(f, T)` 的 f 是元信息
  绑定（本身不是值），只作静态类型引用。

| 类别 | 用例 | 覆盖 |
| --- | --- | --- |
| run | 172-comptime-field-meta | typed 逐字段块 + 类型谓词分派计数（int/float/混合）、普通路径展开 + `.name` 投影 |
| fail | 159-comptime-fields-non-struct | 枚举用 `.fields` 拒绝 |
| fail | 160-comptime-field-meta-bare | 裸用元信息绑定拒绝 |

## P1c `$field(x, "name")`

### 语法

无需改 g4：`$field(x, "name")` 走既有 `comptimeCall` 的 `callArgs` 形态
（字符串字面量是普通表达式），由语义层按内建名 `field` 拦截。

### 语义与实现

- `parse/parse_expr.yh` 新增 `parse_comptime_field_access`：
  - 解析基底 x（**正常求值**，与 `.` 同一 `sem_member` 路径：指针基底自动
    解引用、值/地址形态一致），第二实参必须是字符串字面量；
  - 字段名取字符串内容区（`str_start + 1`、`str_len - 2`），按 `np_data`
    字段表匹配名字解析出**字段下标**；
  - 普通路径与 typed 路径共用 `sem_member`（普通路径直接发码）；
  - typed 捕获为 `AST_EXPR_CTFIELD = 15`（`child0` = 基底，**op 槽记录字段
    下标**——sym_* 槽受 AST 校验约束不可挪用）。
- `comptime/ct_ir_place.yh`：`ct_ir_member_place` 支持 kind 15（用 op 记录的
  下标直接定位，跳过源码 token 名匹配——`$field` 的名字不在源码标识符位置）；
  `ct_ir_member_root_slot` 同步支持。
- `comptime/ct_ir.yh`：`ct_ir_support_code` 放行 kind 15；
  `ct_ir_eval_expr` 的 kind 9/15 共用 `ct_ir_member_read`。
- **只读**：`ct_ir_lvalue` 不识别 kind 15，因此 `$field(x, "name") = v`
  自然按「编译期赋值只支持可写局部变量或受支持聚合元素」拒绝。

### 用例

| 类别 | 用例 | 覆盖 |
| --- | --- | --- |
| run | 173-comptime-field-access | 普通路径（值/指针基底）、typed 正文取值与运算、顶层 const 聚合实参 |
| fail | 162-comptime-field-unknown-name | 字段名不存在 |
| fail | 163-comptime-field-name-not-string | 第二实参不是字符串字面量 |
| fail | 164-comptime-field-write | 写入只读拒绝 |

## 已知边界

- 仅单文件语义完整；`.s.ct` 跨模块闭包正文里的 fields/`$field` 形态序列化延后
  （与 `$if` 表达式同一批）。
- 字段名匹配按源文本（无转义处理）：含转义的字符串名匹配失败会报
  「结构体没有该字段」。
- `$field` 第二实参只接受字符串字面量（字段元信息绑定 f 作实参的形态未开放，
  需要时再补）；字段元信息只投影 `.name`（类型判断用谓词、取值用 `$field`）。
