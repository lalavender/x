# yh 汇编器与链接器项目归位

日期：2026-10-07。范围：仓库根 `asm/`（yh_asm，汇编器）与 `link/`（yh_link，
链接器）、`Makefile`、相关文档。不涉及 `compiler/`、`bin/yh` 种子、`libs/`。

## 1. 目标

用户明确两点：

1. `asm/` 与 `link/` 是**两个独立项目**，处于开发阶段，开发完成后分别替换
   编译器现在的汇编与链接外部工具；
2. 两者必须保持独立、**可以被调用**——互不依赖、互不 import，只通过标准
   对象文件交接。

整理前的实际状态是错位的：`link/` 里寄放着**汇编器**实现（`src/obj` 对象模型
与出口 + `src/asm` 编码与解析），而它自己的链接器职责（TC4 起）一行未写；
`asm/` 里则是上一代较弱的汇编器实现（无浮点、无 GOT、无 Mach-O）。

| 项目 | 整理前 | 整理后 |
| --- | --- | --- |
| `asm/`（yh_asm） | 上一代汇编器：11 个 `.yh`、5528 行，能力到 TC1–TC3，无浮点/GOT/Mach-O | **唯一汇编器**：现役实现全部在这里（19 个 `.yh`、7065 行），能力到 TC3+TC8 |
| `link/`（yh_link） | 汇编器实现（同上），名称与实际职责不符 | **链接器骨架**：`src/main/main.yh` 入口，命令形态与退出码固定，TC4 起填实现 |

## 2. 动作

### 2.1 汇编器实现归位到 asm/

- `link/src/{obj,asm,main}` 整体迁到 `asm/src/`，`link/tests/*`（编码向量门、
  语料差分门、对象结构门、Mach-O 三个门、容器链接门、语料与 docker 上下文）
  整体迁到 `asm/tests/`。
- 工具名随之从 `yh_link` 改为 `yh_asm`：`main.yh` 用法文案、`tests/*.py` 的
  默认产物路径、`YH_LINK` 环境变量、README 全部同步。
- 上一代 asm 实现（`asm/src` 的 `a_bytes`/`b_model`/`c_elf` + 7 个 `asm` 文件 +
  703 行测试驱动，共 5528 行）与它的 `tests/{check.py,compare_elf.py}` 移出
  归档到 `tmp/removed-2026-10-07/asm-legacy/`：实现被现役版本取代，不保留第二份。

### 2.2 link/ 清空为链接器项目

- 删除迁走的 `src/{obj,asm}` 与 `tests/`，保留 `project.toml`（name `yh_link`）
  并新写入口骨架 `src/main/main.yh`：`--version` 正常返回，`link` 子命令与无参
  调用打印「尚未实现」并返回退出码 2——不让骨架被调用方误当可用链接器。
- 新增验收门 `link/tests/check.py`：冷编 + 入口行为（`--version` 退出 0 且含
  工具名；无参与 `link` 子命令退出 2 且报未实现）。
- `link/README.md` 重写为链接器定位（TC4/TC9/TC10/TC11），并声明与汇编器
  只通过对象文件交接。

### 2.3 恢复上一轮误删的能力

上一轮按「去冗余」删掉的 17 个无调用点函数全部恢复原位（`mul_chk`、`buf_clear`、
`buf_align`、`rd_u16le`、`rd_u64le`、`is_pow2`、`ts_equal`、`sec_file_size`、
`es_shndx_of`、`sh_ok`、`cond_alias_len`、`mem_size_bytes`、`lex_tok`、`e_testbr`、
`p_err_at`、`p_txt_len`、`p_is_imm_start`）；项目仍在开发阶段，未接线的能力
不是冗余。它们随实现一起迁到 `asm/src/`。

保留上一轮的真实缺陷修复：`asm/src/asm/33_enc_br.yh` 的 `e_nop` 符号扩展
（`0xd503201f.to_type(i64)` → `.to_type(u32).to_type(i64)`），它修好了自检
`ENC#102` 与语料 `04-ldst-modes.s`/`06-sysops.s` 的汇编失败。

未恢复：旧 `link/src/ln/`（SHA-256 + 自检，295 行）。它没有生产调用点，
属于 TC10 签名的超前实现，归档仍在 `tmp/removed-2026-10-07/link-src-ln/`。

### 2.4 构建入口

`Makefile`：

```make
make yh-asm     # 用 $(YH) 冷编 asm/，产出根目录 yh_asm（并 codesign）
make yh-link    # 过渡别名：把同一份 yh_asm 再复制成 yh_link
```

`yh-link` 是过渡别名：编译器 `compiler/cmd/link_cache.yh` 的 `mb_asm_tool`
目前仍按 `yh_link`（及 `YH_LINK`）查找、按 `asm` 子命令调用，切换查找名后
删除该目标（已记入 [todo.md](../todo.md)）。两个可执行文件目前字节相同。

## 4. 未做与遗留

- **编译器查找名未切换**：`mb_asm_tool` 仍找 `yh_link`；切换后删 `make yh-link`
  别名并跑 `make selfhost-native` 复验。
- **指令级负例门未迁移**：上一代 asm 项目的 19 条负例（越界立即数/偏移、SP 与
  ZR 混用、未知助记符、未定义局部标签、非 2 的幂 `.balign` 等）随旧实现归档，
  没有重写进现实现；其中浮点类在现实现已支持浮点后不再适用。
- **链接器实现未开始**：TC4 起（静态 ELF 链接），随后 TC9（Mach-O 装载）、
  TC10（ad-hoc 签名）、TC11（编译器最终链接步切过来）。
- **不滚种子**：本次只改 `asm/`、`link/`、`Makefile` 与文档，`compiler/`、
  `bin/yh` 未动。
