# `.s.ct` 正文闭包认引用式指针常量（共用追链函数）

日期：2026-10-07。状态：已完成。第 42 轮的对称项 —— 让**跨模块 CT 函数正文**里引用
`pub const A *char = B;` 也能工作。

## 问题

第 42 轮让接口（`.s.i`）导出时追链重放最终字面式，但 `.s.ct`（CT 函数正文闭包）这一侧
仍要求 `const_expr_kind == 2`：

```yh
let string_ptr int = (type_kind == gen.TY_PTR
    && gs.t_types[type_id].elem == gen.TY_CHAR
    && (sym.flags & gen.F_ADDR) != 0
    && sym.const_expr_kind == 2).to_type(int);   // ← kind 3 落到这里为 0
```

于是「正文里引用引用式常量」报「跨模块 CT 闭包暂只支持直接字符串字面量指针常量」。

## 改动：不写第二份拷贝，提取共用追链函数

两处（`iface.yh` 的 `.s.i` 导出、`iface_ct.yh` 的 `.s.ct` 发射）逻辑完全同构，所以把第 42 轮
内联在 `iface.yh` 里的追链提成 `iface_ct.yh` 的 pub 函数，两处共用：

```yh
// iface_ct_lit_text：把「字符串指针常量」追到最终的字面式初始化文本……只追**一层**
pub fn iface_ct_lit_text(sym_id int, out_off *int, out_len *int) int
```

- `kind == 2`（字面式）→ 直接返回；
- `kind == 3`（引用式）→ `sym_lookup_off` 找被引用常量，要求它是 `SYM_CONST + F_ADDR +
  kind 2`，返回**它**的字面式；也防了自引用（`src == sym_id`）；
- 其他 → 返回 1。

调用侧：`iface_ct_emit_const` 去掉 `string_ptr` 里的 `const_expr_kind == 2` 条件，改用该函数
取文本，诊断改为「跨模块 CT 闭包暂只支持**直接或引用式**的字符串字面量指针常量」；
`iface.yh` 的 30 行内联缩成 4 行调用。

（注：`len` 是 yh 内置名，不能作参数名 —— 首版签名用 `off`/`len` 报「此处需要一个参数名」，
改名为 `out_off`/`out_len`。）

## 用例与门同步

  （正文里引用引用式常量），host 顶层 `const ALIAS_BODY int = $math.alias_head();` 断言
  `ALIAS_BODY - 104`。

  **该边界已在第 44 轮修掉** —— 追链函数下沉到 `gen/sym_ct_lit_text`，单文件侧一起接线，
