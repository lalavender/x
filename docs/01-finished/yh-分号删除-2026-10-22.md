# 分号删除（compiler/）完成记录

日期：2026-10-22，分支 `0.0.8-rc`。换行终结已落地并通过全门后，按
[分号清理方案](../02-plan/yh-分号清理实施方案.md) 执行 Phase 2 的编译器部分。

## 范围与结果

| 项 | 数值 |
|---|---:|
| 涉及文件 | 101 |
| 删除分号 | 24,514 |
| 保留分号 | 1,061（同一行分隔、裸块前） |
| 行数变化 | 0 |

判定与 `compiler/lex/layout.yh` 一致：只删「上一 token 能结束语句，且下一 token
在更后面的行 / 是 `}` / 是 EOF」的分号；同一行两条语句之间、裸块 `{` 之前、
跳转语句后裸块之外的 `;` 全部保留。删除只去掉分号字符本身，注释前空格与注释
对齐不动（如 `kind int            // 注释`）。

## 工具适配

源码扫描工具原先假定 `module x;` 带分号，改为分号可选：

- `tools/selfhost_snapshot_gate.py`：module 声明正则 `;?`；
- `tests/selfhost/link-cache.py`：同一正则；
- `tools/compiler-performance.py`：模块名改为 `line[len("module "):]` 再剥分号。

## 验证

- `make`：冷编成功，产物 `compiler/.build` 与删除前逐文件对比，**非 manifest
  差异 0 处**（只有源码哈希 manifest 变）。
- `make test`：ANTLR 正例 80/80、反例 44/44；运行语料 350/351（1 条平台 SKIP）。
- `make selfhost-native`：cc3→cc4 的 27 个产物一致、cc4 自解析 101 个源文件、
  modules 19/19、project cases 115/115。
- 本地种子为「rc 线源码构建的编译器」（`bin/` 不入库）。

## 遗留

- `libs/`、`tests/`、`examples/` 未清理分号（`tests/` 保留显式分号的覆盖）。
- 种子：`0.0.8-rc.7` 发布后 `make fetch-seed` 取到官方种子（sha256
  `624ffc50…`），实测包含换行终结、能冷编无分号源码；本地已 `make seed`
  滚到新一代（`e96eca03…`）。
- `0.0.8-rc.4` 资产二进制曾不含换行终结（与 tag 源码不一致）；`0.0.8-rc.7`
  重新发布后 darwin/linux 资产均含该特性（字节与行为双重核对），并已在发布
  流程里加入打包产物自检。
