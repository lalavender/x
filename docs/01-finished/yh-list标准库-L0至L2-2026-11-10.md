# yh-list标准库-L0至L2-2026-11-10

## 概述

按 [list 标准库设计](../03-design/yh-list标准库设计.md) 交付 `libs/list`：
无泛型约束下的动态列表（ArrayList）。元素以运行期字节宽度连续存放，宽度必须
来自调用方 `sizeof(T)`；元素地址以 `*void` 暴露，调用方 `to_type(*T)` 定型。
不新增语言语法、不改 `compiler/`、不改既有 `string`/`json`/`toml`/`cli` 的
私有容器。

## API 与契约

| 函数 | 语义 |
| --- | --- |
| `make(element_size) List` | 空列表，不分配；`element_size == 0` 为无效列表 |
| `release(value) void` | 释放存储并清零 4 个字段，可重复调用 |
| `clear(value) void` | `count = 0`，保留 `data`/`capacity` |
| `reserve(value, capacity) Status` | 保证容量；不改 `count` |
| `element_at(value, index) *void` | 元素地址；越界/空指针返回 `0` |
| `push(value, element) Status` | 复制一个元素到尾部 |
| `push_all(value, elements, count) Status` | 一次追加 `count` 个元素 |
| `pop(value, out) bool` | 取走尾元素；空列表 `false` |
| `insert(value, index, element) Status` | 插入并后移；`index > count` 为 `status_bounds` |
| `remove_at(value, index, out) bool` | 取走第 `index` 个元素并前移 |

实现要点与设计一致：起步 16 槽、容量翻倍、上限 `LIST_MAX_BYTES /
element_size`；扩容 = `memory.alloc` + `memory.copy` + `memory.release`；
`insert`/`remove_at` 的移位用模块内 `list_copy_overlap`（重叠安全；Windows
零 CRT 上 libc 的 `@[extern] memset/memmove` 与 prelude 重复符号，故不依赖
`libc`）；所有失败路径在
改动 `count`/`capacity`/内容之前返回，保持失败原子性。

## 实现期确认的事实与偏差

1. `make(element_size)` 保留传入步长，所以「4 个字段为 0」只对
   `make(0)` 成立；测试按此断言。设计 §6 的表述按该解释落地。
2. 元素偏移用 `value.data + offset`（`offset u64`），实测语义正确（`tmp/ptr-probe.yh`：
   16 字节步长的第 3 个元素落在 48 字节偏移），避免 `libc/sort.yh` 里
   `offset.to_type(int)` 的 int 截断。
3. `libc.qsort` 的回调实参必须带 `@[extern]`（编译器诊断「C ABI 回调实参必须是
   extern 函数」）；README 与设计 §9 已补该说明。
