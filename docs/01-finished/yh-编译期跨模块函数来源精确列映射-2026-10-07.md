# yh 编译期跨模块函数来源精确列映射

日期：2026-10-07。状态：CT5B `.s.ct` 重写函数体的来源列映射首片已完成。

## 交付内容

- `.s.ct v1` 在 `yh-ctloc` 路径/行号元数据前可带 `yh-ctcol v1` 注释。它记录每处正文改写的
  sidecar 生成范围、原函数体范围及函数体左花括号列号；没有该扩展注释的旧 sidecar 仍可按路径和行号导入。
- 导出映射覆盖跨模块/私有 CT 调用名、局部复合类型、模块限定类型、可达常量名和直接具名类型名的
  改写。导入器在解析函数正文时临时映射 token 行列，`ct_register` 捕获后，恢复 sidecar 的原 token
  位置，确保同一输入的两遍解析不会互相污染。
- 后续改写记录覆盖之前对同一行生成的累计偏移。编译期语义错误以及执行期
  `$assert/$compile_error/$compile_warn` 都能将列号映射到定义源码。
- `comptimecross` 将 `OFFSET` 与 `$point_size()` 两处改写放在同一行诊断之前，断言错误的原始路径、行、列；
  另一条用例验证被改写的常量引用发生类型错误时也回到原列。畸形列映射元数据会被拒绝。
