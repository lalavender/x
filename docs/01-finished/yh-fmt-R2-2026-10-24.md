# yh fmt R2 实施记录（2026-10-24）

## 交付

- `40_float.yh`：f64 位型读取、NaN/±Inf/负零、默认 g（6 位有效数字）、
  `f/F` 定点、`e/E` 科学计数、`g/G` 自动切换；`.N` 去尾零、`.Nf` 保留；
  指数至少两位；符号/宽度/零补齐复用浮点文本路径。
- `30_render.yh`：`append_value` 的 f64 分支接通 `append_float`。
- `99_tests.yh`：新增 3 组 R2 测试（默认 g、精度/类型、符号/宽度/特殊值），
  总计 13 项。

## 边界

- 定点路径 `scaled > 1e18` 或 precision > 17 返回 `status_unsupported`
  （实现上限，已在代码与 README 标注）。
- 非 f/F 的浮点零统一输出 `0`（负零为 `-0`）；不输出科学计数零。
- 未做 V 1.x 实测差分；golden 为手写示例，差额未宣称完全一致。
- print/sprint 与语言插值未开始；未跑全量门，未滚种子。
