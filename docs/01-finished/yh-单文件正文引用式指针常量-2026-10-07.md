# 单文件 CT 正文也认引用式指针常量（追链函数下沉到 gen）

日期：2026-10-07。状态：已完成。第 43 轮对称项的另一半。

## 问题

第 43 轮让 `.s.ct` 发射认引用式指针常量，但**单文件**侧仍报「编译期求值不支持指针常量」：

```yh
pub const BASE *char = "hi";
const ALIAS *char = BASE;        // kind 3（引用式）
@[comptime]
fn head_of_alias() int { return (*ALIAS).to_type(int); }   // ← 报「编译期求值不支持指针常量」
```

原因在 `comptime/ct_ir.yh:313`：字符串指针常量的只读池登记要求
`const_expr_kind == 2`（字面式），kind 3 落到 326 行的诊断。

## 关键约束：模块依赖方向

`comptime/ct_ir.yh` **只** `import gen;` —— 不能调用 `parse` 模块里的 `iface_ct_lit_text`。
所以第 43 轮那个「共用函数」不能留在 `parse/`，必须下沉到**公共底层** `gen/`：

- 移到 `compiler/gen/symbols.yh`，改名 `gen.sym_ct_lit_text(sym_id, out_off, out_len)`
  （同模块内直接用 `g_state`，不再需要 `gen.G()`）；
- `parse/iface_ct.yh` 删掉本地副本，改调 `gen.sym_ct_lit_text`；
- `parse/iface.yh` 同样改调；
- `comptime/ct_ir.yh` 第四次接线（本次新增）。

一份实现、三个调用侧（`.s.i` 导出、`.s.ct` 发射、单文件 CT 求值）。

## 单文件侧的改动

```yh
let elem int = ct_pool_elem_of(expr.type_id);
let lit_off int = 0;
let lit_len int = 0;
if (gen.sym_ct_lit_text(expr.sym_id, &lit_off, &lit_len) == 0
    && lit_len >= 2 && elem >= 0) {
    let addr i64 = ct_pool_register(gs.np_data, lit_off, lit_len, elem,
        0 - (lit_off.to_type(i64) + 1));   // 去重键改用追链后的偏移
    ...
```

去重键（`ct_pool_register` 的第 5 个参数）跟着改用**追链后**的偏移 —— 否则 `ALIAS` 与 `BASE`
会因不同偏移而重复登记同一份字节。

## 效果

| 写法（单文件 CT 正文里引用指针常量） | 之前 | 现在 |
| --- | --- | --- |
| `pub const T *char = "hi";`（字面式） | 可用 | 可用 |
| `const A *char = B;`（引用式，B 是字面式） | **拒绝** | **可用** |
