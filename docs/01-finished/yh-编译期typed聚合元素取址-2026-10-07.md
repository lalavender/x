# yh 编译期 typed 聚合元素取址

## 交付内容

- typed 编译期函数可对当前帧内的**整数聚合元素**取址：`&array[i]`、`&slice[i]`
  （含切片视图元素）与 `&struct.field`，得到的指针与局部变量指针同权，
  可解引用读写、可作为整数指针形参传给更深的编译期调用。
- 指针目标校验从「局部槽区间」扩展为「局部槽区间 + 存活帧拥有的聚合元素块」：
  `ct_ir_pointer_target` 遍历存活调用帧链与其聚合块（含非拥有视图块），
  按该位置元素的实际类型校验；越界或类型不符仍拒绝。
- 仍拒绝：非整数元素/字段取址（结构体、数组、切片元素）、临时值取址
  （函数返回的数组/结构体）、`&*p` 重取址、指针算术、指针返回与聚合逃逸。
- 切片视图元素取址写回底层父聚合，别名语义与运行期视图一致。
- 新增 `tests/yh-run/run/133-comptime-element-address.yh`，反例
  `fail/135-comptime-element-address-noninteger.yh`、
  `fail/136-comptime-element-address-temporary.yh`。
