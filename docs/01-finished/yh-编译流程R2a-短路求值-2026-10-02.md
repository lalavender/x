## 切片内容

本切片把逻辑或 `||`、逻辑与 `&&` 与逻辑非 `!` 接入 typed SSA 与 arm64
后端，并把条件语义统一归一化：

1. **表达式降低线程化**：`ast_ir_lower_expr`、`ast_ir_lower_call_expr`、
   `ast_ir_lower_assign_stmt` 等签名从「指令数组 + 计数指针」改为直接
   接收 `AstIRBuilder`，表达式降低从此可以创建条件块（短路需要）。
   builder 结构体随之补 `types` 字段（指向 lower_function 持有的
   13 项固定类型表）并在初始化时清零。
2. **短路求值**：`a || b` 在 `a` 为真、`a && b` 在 `a` 为假时跳过
   `b`——条件块 + 右臂块 + 合流块三段 CFG，短路常量定义在条件块内
   保证支配对应合流边，合流点用双前驱 phi。**嵌套短路**（如
   `a > 0 || b > 0 && c > 0`）的 phi 第二前驱必须取降低右臂后的
   实际汇入块（`rhs_end`），而非最初分配的右臂块——否则 verifier
   的 phi 前驱检查拒绝。
3. **条件归一化 `ast_ir_b_cond`**：bool 直接使用；整数按「非零为真」
   与零常量比较生成 bool，匹配旧发射器语义。`if`/`for` 条件与短路
   操作数统一经此入口，使 `if (flag)`（bool）、`if (n)`（整数）、
   `!(x) || y`（混合）都能进入 SSA。
4. **逻辑非**：`!x` 降为 `x` 与 false 常量的相等比较。旧语义层把
   bool 的 `!` 结果升为 i32，IR 一律产生 bool（值 0/1 语义一致）；
   操作数必须是 IR bool，源结果类型只需可映射。
5. **verifier 值编号唯一性改位图**：构造器允许块区间与编号顺序不同
   后，原有的「前缀扫描查重」在乱序布局下会把当前指令误判为重复
   （扫描区间含自身）。改为 value_count 大小的位图标记，对任意布局
   正确且为 O(n)。

## 过程中发现并修复的缺陷

- **短路 phi 前驱错误**：嵌套短路合流后实际分支到外层 join 的块不是
  最初分配的右臂块，verifier 拒绝（`irfront` 逻辑用例、自举 cc3）。
- **发现趟类型表悬挂**：循环发现趟的独立 builder 未初始化/挂接
  `types` 表，发现趟走 `b_cond` 读垃圾指针导致 fork worker 静默
  SIGSEGV、模块构建无声失败（单文件模式不受影响，曾长期误导定位）。
- **b_if 条件归一化补丁静默未落盘**：早期补丁打在已搬移的旧副本上，
  `if (is_digit(b))` 这类整数条件在自举 cc3 的 `is_hex_digit` 中以
  int 结果直接作为条件终结符，verifier 拒绝。此后关键补丁均改用
  带断言的方式应用。
- **测试期望错误**：`logic_guard(0,1,0)` 实际为 100，语料初版误写
  `!= 0`，由项目验收捕获后修正。

## 性能

Apple M1 冻结 25 文件、13,338 行语料，各场景独立测量 20 轮，计入外部
汇编与链接（新种子 `0a28dd5e…`）。中位数/p95 为：无改动 40.8/49.5ms、
单函数修改 743.5/817.8ms、冷编 2203.0/2765.1ms；汇编/链接调用依次为
0/0、1/1、4/1。函数修改场景被修改函数本身进入 SSA（ir=1，前几轮为 0），
冷编进入 SSA 的自编函数由 5 增至 8；端到端数字与上一轮在噪声范围内
持平，本切片不构成编译提速证明。无改动 50ms 中位数目标保持达标，
单函数 200ms 与冷编 1s 目标未达到。

## 边界

- 负数字面量实参（一元减号表达式作实参）未支持，含该形态的函数
  （如 unsigned_score 的 `divide_signed(-21, 4)`）整体回退。
- switch、goto/label、for-in、无限循环 `for {}`、嵌套循环仍走旧
  发射路径；浮点、聚合/内存、间接/变参调用尚未接入 SSA。
- R2a/R2b 整体未完成：函数级 check/IR 缓存、真正线程池与性能目标
  继续实施。
