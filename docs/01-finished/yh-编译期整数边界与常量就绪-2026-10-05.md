# yh 编译期整数边界与常量就绪

日期：2026-10-05。状态：**CT0 整数与就绪状态切片完成**。

## 交付

- 在 `compiler/gen/sem_expr.yh` 增加按目标整数类型折叠的边界检查：有符号/无符号
  比较、除法与右移遵循类型语义；一元负号、加减乘溢出、除零/模零、最小负数除
  `-1`、移位计数越界和左移溢出均干净报错。编译期有符号负数左移采用保守拒绝。
- 受限 `@[comptime]` 单条 `return` 求值器在 `compiler/comptime/ct_eval_expr.yh`
  复用同一折叠实现，覆盖其当前支持的 `+ - * / %`；未扩大函数体语法或求值范围。
- `CSym.const_ready` 独立记录常量是否已完成初始化。前向全局 const 和 pass1 中
  尚不可用于布局的数组长度不再读占位零，统一以“编译期常量尚未就绪”拒绝；按
  声明顺序初始化的全局标量 const 仍可被后续常量使用。全局数组长度求值仍属 CT5A。
- 就绪状态不进入通用符号 `flags`，避免局部 const 初始化后使冻结的模块 AST 绑定
  快照失配。回归 `tokenreplay` 项目覆盖局部 const 与 AST 绑定验证。
- `tests/yh-run/check.py` 支持可选 `// fail-contains:`，本切片新增失败用例可以
  验证诊断类别，而不改变旧失败用例的约定。

## 用例

- 新增 `fail/71`–`fail/79`：前向 const、数组长度未就绪、i32/u64 溢出、移位边界、
  有符号最小值除法、编译期函数体加法与一元负号溢出。
- 新增 `run/60`–`run/61`：有序全局常量就绪，以及 `u64` 最大值比较和除法。
- 所有新增源用例均使用 `.yh`。
