# yh test 项目外单文件（YT1.1）实施记录

日期：2026-10-23。范围：`yh test <项目外文件>` 用临时单模块上下文跑单文件测试，
不装入相邻文件，允许导入工具链标准库。

## 语义

- **判据**：选择器是源文件路径，且该文件所在目录向上 32 层内没有
  `project.toml`（`tc_file_has_project`）。文件在项目内时仍走项目模式；
  项目内但不属于该项目仍报「测试文件不属于当前项目」，不静默降级。
- **临时项目**：根为 `<源文件目录>/tmp/yh-test/single/`，写入
  `[project] os="host" arch="host" name="yh_test_single" source="<源文件目录>"`。
- **只装入一个文件**：`GenState.c_scan_file_off/len` 让源码扫描只接受被选中的
  绝对路径，并且不进入任何子目录；相邻 `.yh` 不会被编译。
- **模块名**：文件头 `module X;` 优先；缺失时由文件名派生
  （`pj_synth_module_name`：去目录/去 `.yh`、非法字符转 `_`、数字开头前置 `_`）。
- **依赖**：只允许标准库（`YH_STDLIB` 或安装布局）；第三方依赖仍需项目清单。
- **产物**：仍然在该临时项目的 `tmp/yh-test/` 下（入口模块、对象、测试二进制、
  日志）。
- 其余行为与项目模式一致：`--list` / `--no-run` / `--filter` / `--timeout` /
  `--emit-llvm`，逐例 fork/exec、`YHTP`/`YHTF`/`YHTS` 协议与汇总。

## 交付

- `compiler/gen/state.yh`：`c_scan_file_off/len`（-1 = 全量扫描）。
- `compiler/cmd/project_index.yh`
  - `pj_scan_is_target`：单文件模式下只接受目标文件；
  - `pj_scan_entry`：单文件模式不递归子目录；
  - `pj_synth_module_name`：无 `module` 头时派生模块名；
  - `pj_index_file`：单文件模式允许缺少 `module` 头。
- `compiler/cmd/test_cmd.yh`
  - `tc_file_has_project` / `tc_single_file_project`（临时清单与扫描过滤）；
  - `mb_run_test_command` 增加单文件分支，用 `realpath` 取绝对路径；
  - `tc_rel_path` 在单文件模式下显示文件名（否则会是临时项目根之外的绝对路径）。

## 语料与门禁

- 新语料目录 `tests/modules/single/`：
  - `standalone.yh`：无 `module` 头，两条测试（含私有函数）；
  - `with_import.yh`：带 `module` 头并 `import string`，验证标准库可用；
  - `neighbour.yh`：有意写坏（引用未声明名字），证明相邻文件不被装入。
- `tests/modules/test-check.py` 增至 38 项：
  - `single-file-test`（2 passed、身份含文件名）；
  - `single-file-options`（`--list` 两行、`--no-run` 不执行）；
  - `single-file-stdlib-import`；
  - `single-file-skips-neighbours`。

## 边界

- 单文件模式没有 `[link]`/`[c]` 配置，只能用默认链接环境；需要外部库时仍要
  建项目清单。
- 临时项目根固定为 `<源文件目录>/tmp/yh-test/single`，同一目录并发执行会互相
  覆盖（命令级运行目录隔离仍未做）。
- 平台源文件筛选（`checks.linux.yh` 之类）在单文件模式下没有意义——只有一个
  文件。
