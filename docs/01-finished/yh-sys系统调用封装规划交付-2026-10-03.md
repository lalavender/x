## 主要决定

1. 首期 Linux/arm64，复用已有 linux_syscall6；不修改语言语法。
2. sys 保留 -errno，不分配、不自动重试；os/io/time 保留既有上层契约。
3. mmap 错误在转指针前判定，close 不重试；fork 仅实现当前单线程 fork/COW
   worker 所需 clone 语义；明确 wait/exec/dup/exit 的差异。
4. 编译器采用显式项目依赖，区分宿主 OS 与输出目标；导入 sys 不自动改写
   旧 prelude。静态 ELF、自有入口和连续自编由 SYS6 与 TC4/TC5/TC6 联合验收。
5. Darwin OS 桥后续逐项补齐，披露 dyld/libSystem，不使用假变参原型或假成功桩。
