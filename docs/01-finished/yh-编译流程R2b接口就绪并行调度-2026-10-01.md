# yh 编译流程 R2b：接口就绪并行调度过渡切片

日期：2026-10-01。状态：已完成进程 worker 过渡实现；真正线程池、任务私有线程上下文和完整 R2b 仍未完成。

## 交付

- 新增构建协调器，最多运行四个模块 worker。父进程用 `fork`/`execvp` 传显式 argv 启动 worker，不经 shell；裸 `argv[0]` 会解析为稳定可执行路径。
- 每轮构建用 `.session-<pid>` 后缀暂存新接口。接口写入临时文件并原子改名后，依赖模块可立即读取并开始编译，不等待提供模块的私有函数或汇编结束。
- 缓存命中直接读取已校验的持久接口。新接口在 worker 全部成功后原子提交到持久路径，再提交 manifest；worker 失败时停止派发、回收本轮 worker、清除会话文件并跳过最终链接。
- 构建统计增加 `workers_peak` 与 `iface_early`，用于观察实际并发度和提前推进次数。

## 回归与验证

新增 scheduler `.yh` 项目语料：provider 含 600 个私有函数以制造接口就绪后的工作窗口；provider/consumer DAG 达到 `workers_peak=2`、`iface_early=1`。另加菱形 DAG：共享 provider 的接口就绪后左右分支并发，汇合模块随后推进，实测 `workers_peak=3`、`iface_early=3`，最终程序返回 42，会话接口已清理。provider 私有函数报错时不得生成或链接最终程序；另覆盖 `PATH` 启动，以及工作目录含空格和单引号的显式 argv 路径。

验证通过：`make`、`make test`（语法正例 66/66、反例 29/29、运行 63/63）、模块项目门 42/42、`make selfhost-native`（10 个模块产物固定点、33 个源文件自解析及全量自举语料）、滚种子后的 `make` 与再次 `make selfhost-native`，以及 Python 语法检查和 `git diff --check`。菱形 DAG 的新增回归之后又单独运行项目门 42/42；其真实构建计数为 `workers_peak=3`、`iface_early=3`。

滚动后的根 `yh` SHA-256：`26a7838a6727492288223bba448ea9a1b03243f07c905d5dca1c51c7a5e19687`；macOS arm64 种子 `bin/yh` SHA-256：`51204b7025f7269428c046738d79f344107944006b5c7250a51602eff59b3f36`。

## 性能

Apple M1 冻结 25 文件语料、每种场景 20 轮、含汇编和链接。无改动构建中位数/p95 为 196/354 ms，函数体变化为 905/975 ms，冷编为 2,278/2,642 ms；峰值子进程 RSS 分别为 15.7、50.9、50.8 MiB。对应模块缓存命中/重编数为 4/0、3/1、0/4；汇编/链接调用为 0/0、1/1、4/1。

本轮设定的 50/200/1,000 ms 目标仍未达到。该调度切片证明依赖接口可提前推进，不证明冻结语料已从并行获得端到端加速。

## 未完成边界

这是进程调度迁移桥，不是线程池；编译器可变全局尚未全部迁为任务私有上下文。增量仍以模块对象为单位，函数 IR 仅覆盖窄 lowering 子集且未驱动后端；同一项目并发构建下的持久产物协调、自有运行时、Linux arm64 汇编器/静态链接器、macOS Mach-O 工具链以及 x64/Windows 均未交付。目录与环境查询、最终汇编/链接仍有 shell 或外部工具依赖，脱离系统依赖目标未达成。
