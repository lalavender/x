# yh 编译期 typed 浮点指针

## 交付内容

- 编译期指针目标从整数槽放宽到**标量槽**（整数或浮点）：
  - `&` 取址支持浮点局部变量与浮点聚合元素（数组元素、切片视图元素、结构体浮点字段）；
  - `*p` 解引用读与写（含 `*p += x` 浮点复合赋值）支持 `*f64`/`*f32`；
  - `*f64`/`*f32` 形参可跨帧写回调用方槽并二次转发。
- 安全不变：指针与其目标类型必须逐类型相等（`*f32` 不指向 `f64` 槽），
  `ct_ir_pointer_target` 的存活帧校验（局部槽区间 + 帧拥有聚合元素块）保持原样，
  指针仍不能逃出帧。
- 解引用读写路径直接搬运 `CtValue`（IEEE754 位模式），无需浮点特判；浮点赋值与复合
  赋值沿用 STORE 路径的浮点归一。
- 诊断文本从「整数局部变量 / 整数聚合元素 / 整数局部值 / 整数指针」改为「标量…」，
  comptime 形参诊断保留「首版 comptime 函数形参只支持整数」前缀以免破坏既有匹配。
- 用例：`tests/yh-run/run/137-comptime-float-pointer.yh`；`fail/104` 改为指向指针的指针
  仍拒绝，`fail/137` 改为浮点指针返回仍拒绝，`fail/138` 改为结构体浮点指针字段仍拒绝，
  `fail/135` 更新为「非标量聚合元素取址」；`comptimelocal` 增加跨源文件 `*f64` 形参写回断言。

## 边界

- 仍拒绝：指向指针的指针（`**int`）、指针元素数组/切片、结构体指针字段、指针返回值逃逸、
  浮点指针常量（CT5B：非字面量指针的常量闭包）。
