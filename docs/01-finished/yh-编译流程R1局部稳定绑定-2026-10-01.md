# yh 编译流程 R1：函数内稳定绑定（2026-10-01）

check worker 的 AST 现在为每个函数参数和局部声明分配函数内稳定编号，按
`(file_id, owner_decl, binding_id)` 区分绑定。表达式引用保存直接绑定行，语句节点
关联局部声明；此身份不依赖旧符号表槽位，因而作用域回收、槽位复用和同名遮蔽不会
把两个变量合并。for-in 的元素/下标隐式绑定也走同一条记录路径。

赋值语句 AST 保存实际赋值 token，以便后续 lowering 分辨 `=` 与 `+=` 等复合赋值。
token replay 语料覆盖参数引用、多名声明、局部常量、嵌套同名遮蔽、复合赋值和 for-in。

阶段边界保持诚实：AST 仍随旧 parser/语义遍历构造，仅 `yh check` worker 启用；这一切片
没有拆出独立语义/check、线程私有上下文、接口就绪调度、函数级缓存或 SSA 构造。
