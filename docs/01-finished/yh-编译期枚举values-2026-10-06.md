# yh 编译期枚举 values 首片

日期：2026-10-06。状态：完成；CT4 的 `T.fields` 轻量反射仍待按实际用途规划。

`$for item in Enum.values { ... }` 现在只允许出现在函数体中，按枚举声明顺序展开。
循环变量提供只读的 `item.name` 与 `item.value`：名称作为 NUL 结尾静态字符串物化，
值保留枚举类型；重复判别值不会合并，空枚举执行零轮。非枚举来源、未知成员、裸用
迭代变量和修改元信息均给出普通诊断。整数区间 `$for i in (lo..hi)` 的语法与语义不变。

普通函数在解析时逐轮做语义检查和代码展开；`@[comptime]` 函数在 typed AST 准备期
保存每轮独立语句块，调用时由编译期 IR 按顺序解释。枚举成员以符号标记保存，查询
逻辑位于 `compiler/comptime/ct_enum.yh`；名称字符串由现有静态数据段机制输出。

新增 `tests/yh-run/run/93-comptime-enum-values.yh`，覆盖声明顺序、自动判别值、重复值、
名称、空枚举和 typed 编译期函数；`fail/109–110` 覆盖非枚举与只读规则。
正式语法由 `tests/yh/positive/72-comptime-enum-values.yh` 锁定；
