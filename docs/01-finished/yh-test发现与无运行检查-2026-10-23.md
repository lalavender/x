# yh test 发现与无运行检查（YT1）实施记录

日期：2026-10-23。范围：测试发现、doctest 目标绑定、模块/文件选择、
测试专用导入分类、`yh test --list` 与 `--no-run` 语义检查。执行器、运行时
`$assert`、`testing.fail/skip` 与逐例进程仍属 YT2；项目外单文件属 YT1.1，未实现。

## 交付

- `compiler/cmd/test_cmd.yh`
  - `TCase`/`TDecl` 会话内索引；稳定身份为
    `模块::项目相对路径::test|decltest::名称`；
  - 发现按模块名、相对路径、行列、种类、名称排序；
  - 文档测试目标支持本模块函数/常量/全局变量/type/struct/union/enum，
    跨文件、前向与私有声明均可绑定；缺失目标、同模块歧义、导入模块名被拒绝；
  - 同文件同种类同名拒绝；字符串测试与同名文档测试可共存；
  - 模块选择器与项目内文件选择器；文件选择仍索引所属模块全部文件，
    以保证跨文件文档目标可解析；
  - `--list` 只发现/绑定；`--no-run` 与默认 `yh test` 检查测试体语义，不执行。
- `compiler/parse/parse_decl.yh`
  - 新增测试模式：pass2 的 test 体按临时无参 `void` 函数上下文做完整语义检查；
  - 检查后回滚符号、作用域、函数/循环/ABI 状态，不进入 AST、受检快照或接口；
  - `$assert` 在测试体内按运行期条件解析（不强制常量折叠、不立即报编译错误），
    为 YT2 运行时断言留出语义位置。
- 测试专用导入
  - `project_index` 在项目扫描后按 token 区间分类 `p_imp_test_only`；
  - 生产构建跳过该导入的绑定、topo 依赖边、接口加载与未使用诊断；
  - 测试模式只对目标项目绑定测试专用导入；依赖/标准库的测试与测试专用依赖
    不进入本轮测试图。
- `compiler/cmd/driver.yh` 增加 `yh test` 分派与 usage；
  `gen/state.yh` 增加测试模式、目标项目/模块/文件过滤与 `p_imp_test_only`。
- `compiler/cmd/module_worker.yh` 在普通函数完成后、受检快照前检查目标项目
  测试体；测试模式下入口模块允许没有 `main`。
- `compiler/cmd/module_build.yh` 让测试检查使用项目 `tmp/yh-test/check`，
  与生产 `.build` 隔离。

## 语料与门禁

- 新 fixture：`tests/modules/projects/ytest`（跨文件私有目标、函数/常量/全局
  变量/类型目标、测试专用导入、darwin-arm64 平台文件）、`ytestbad`（无效目标）、
  `ytestdup`（重复名称）、`ytestsem`（仅测试模式报错）、`ytestempty`（零用例）。
- 新 runner：`tests/modules/test-check.py`，16 个断言，覆盖：
  - 全项目/模块/文件选择与稳定排序；
  - `--filter` 列表过滤；
  - `--no-run` 与默认检查；
  - 测试专用导入不进入生产 build（生产不编译 helper）；
  - 零用例 `--list` 成功、`--no-run` 失败；
  - 无效目标、重复名称、导入别名目标；
  - 测试体语义错误只在 `yh test` 报错，生产 build 仍成功；
  - darwin-arm64 平台文件只在对应宿主出现。
- `Makefile` 的 `make test` 与 `make selfhost-native` 已接入该 runner。

## 边界

- `yh test` 不执行测试；`--no-run` 也仅完成语义检查，不发射测试对象。
- `$assert` 在测试体内只被接受为运行期条件，尚不产生运行时失败与位置报告。
- `--filter` 仅过滤 `--list`；执行过滤、超时、逐例进程与结果协议属 YT2。
- 项目外单文件选择器当前明确报错（不会装入相邻文件或临时模块）。
- 未滚种子；编译器源码仍不含 test 块，种子迁移按 T3 执行。
