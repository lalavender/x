# yh os/sys OS3 环境查询

日期：2026-10-21。状态：**OS3 完成**（跨平台，不发起系统调用）。

依据：[os/sys 联合设计](../03-design/yh-os与sys标准库设计.md) 6.4、
[联合实施方案](../02-plan/yh-os与sys标准库实施方案.md) 第 6 节。

## 1. 交付内容

| 文件 | 内容 |
| --- | --- |
| `libs/os/environment.yh` | `EnvResult`（found/value/error）与 `get_env(envp **char, name *char)` |
| `tests/modules/projects/osenv` | 合成 envp + 真实进程 envp 的跨平台用例 |

契约：

- `get_env` 只扫描入口 `envp`，不调用 getenv 系统调用、不分配、不读写全局环境。
- `name` 不能为空、不能包含 `=`，否则返回 `error_invalid_argument`（native 0）；
  `envp == 0` 或 `name == 0` 同样按非法参数处理。
- 按完整 `=` 前缀匹配，`"A"` 不会命中 `"AA=1"`；重复键返回首项。
- 缺失返回 `found = false`、`value = 0`、`error_none`；空值返回 found=true 且
  value 指向空串。值借用 envp 生命周期，调用方需要长期保存时复制。
- 值内部可以包含 `=`，只按第一个 `=` 分割。
- 未提供 set_env/unset_env、全局懒初始化或可编辑环境对象。

## 2. 测试

`tests/modules/projects/osenv` 使用三参数 `main(argc, argv, envp)`：

- 合成 `["A=1", "EMPTY=", "DUP=first", "DUP=second", "PREFIX=no",
  "LONG=a=b", 0]`，覆盖普通值、空值、重复键首项、前缀不匹配与值内等号。
- 缺失键、空名、含 `=` 的名字、空 envp、空 name 指针。
- 真实进程 envp 由 `build-check.py` 的 `envp-run` 注入
  `YH_ENV_TEST=present`，验证入口环境可直接查询。

用例接入 `build-check.py` 的 `os3-env-query`（`envp-run`）。该类型现在同时注入
`YH_STDLIB`，供 osenv 导入 os；envp-api 不受影响。

## 3. 验证记录

```sh
make
make test
YH_ENV_TEST=present yh run   # osenv, Darwin/arm64
yh -target x86_64-unknown-linux-gnu check   # osenv
```

- Darwin/arm64：osenv 原生运行通过；`make`、`make test` 通过。
- Apple Container `debian:trixie`（Linux/arm64，入库种子）：一次运行
  sysresult/osmodel/sysraw/sysfiles/osfiles/sysdirs/osdirs/osenv 八个 fixture
  全部退出 0（osenv 注入 `YH_ENV_TEST=present`）；容器使用
  libxml2/build-essential 与 gcc-13 兼容符号链接，仅为验证设备。
- Linux/x64 仅完成语义检查，未宣称原生运行。
- 未修改编译器语义、语法、种子或默认后端。
