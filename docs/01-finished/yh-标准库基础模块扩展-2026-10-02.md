# yh 标准库基础模块扩展

按用户要求，标准库直接放在仓库 `libs/` 根下，清单使用 `source = "."`，没有
`src/` 子目录。保留已有 `io`，同步新增 `memory`、`string`、`os`、`math`、`time`
五个模块。分配与释放为显式函数；数学接口通过固定参数 extern 调用宿主 C 符号，
未接入 libc 裸变参 `printf`。

`tests/modules/projects/libsbase/` 通过 `YH_STDLIB` 导入并真实运行所有基础模块，
覆盖字符串 UTF-8 字节长度/比较、显式分配/复制/释放、文件创建/读写/重命名/删除、
目录创建/移除、进程号/睡眠/退出、数学函数和单调时钟。目录清理由用例自身完成，
项目验收重复运行不残留 fixture 状态。

验证：`make` 通过；`make test` 通过（语法 67/67 正例、39/39 反例，运行/失败/通过
语料 50/32/8，总计 90/90）；模块项目验收 78/78；`make selfhost-native` 通过
（12 个模块产物固定点一致、52 个 `.yh` 源文件自解析、模块语法 17/17、项目验收
78/78）；`git diff --check` 通过。当前仅在 Darwin 主机验证；未运行 `make seed`。
