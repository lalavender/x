# yh 编译流程 R3：自有运行时与性能

日期：2026-10-01。状态：自有运行时切片完成，R3 与 R0–R6 仍在实施。

## 自有分配器

`malloc/free` 改为 yh 后端发射的 arm64 本地入口。每次 `malloc` 都申请一段独立 OS 映射；映射开头保存实际映射长度，用户指针从基址偏移 16 字节，满足 16 字节对齐。`malloc(0)` 至少申请 1 字节，`free(null)` 直接返回。`free` 从用户指针回退 16 字节，读取长度并解除整段映射。

Darwin arm64 通过已审核的 libSystem `mmap/munmap` OS API；Linux arm64 后端直接发射 mmap 222、munmap 215 两个系统调用，不依赖 libc 符号。分配器没有空闲块池或回收策略，按次系统调用是刻意采用的最小实现；后续只有测量证明它影响构建性能时才增加分配池。

`tests/modules/projects/runtimebytes/main.yh` 验证 33 字节分配的 16 字节对齐、首尾读写、直接释放、`free(null)`、零长度分配及 malloc/free 函数值调用。`tests/selfhost/runtime-memory.py` 运行 Darwin 程序，确认普通程序与自编编译器不导入 `malloc/free/memcpy/strlen`，确认 Darwin 映射 API 导入；并生成 Linux arm64 汇编、交叉组装 ELF 对象，检查 mmap/munmap syscall 且无未定义符号。

## 自有格式化与按需发射

同一 arm64 运行时文件新增 `printf` 入口，支持 `%%`、`%d/%i/%u`、`%lld/%llu`、`%s` 和 `%c`。格式文本与字符串按 UTF-8 字节原样输出；有符号整数支持负值，格式参数遵循 Darwin 与 Linux arm64 的变参 ABI。256 字节输出缓冲区通过审核后的 OS `write` 或 Linux `write` syscall 分段刷新，并处理短写。当前不支持宽度、精度、浮点格式和 locale。

prelude 只登记入口，不立即把 stub 写入每个对象。直接调用或取运行时函数地址时标记该入口，模块编译结束后按标记发射。`runtimebytes` `.yh` 用例核对负数、整数变参、字符串/字符、`%%` 和 299 字节字符串刷新；独立 `runtimeplain` 项目只返回常量，导入审计确认它没有 `malloc/free/memcpy/strlen/printf/mmap/munmap/write`。

这个延迟发射逻辑需要同时覆盖两种编译收尾：单文件 `sem_compile()` 与并行项目 `module_worker`。项目 worker 首轮漏掉该收尾，表现为汇编引用了 `printf/strlen` 而无定义；回归定位后在 worker 写出汇编前调用同一 runtime stub 发射器，定向脚本和完整自举门均通过。

滚种子后 `nm -u yh` 的 Darwin 导入为：

```text
_clock_gettime _close _execvp _exit _fork _getattrlistbulk _getpid _kill
_mkdir _mmap _munmap _open _read _rename _unlink _usleep _waitpid _write
```

这些名称按 OS API 审核，不以 `libSystem` 库名代替符号审计。普通程序若主动使用 `printf`，只会带入本地格式化入口与 OS `write`，不会导入 C `printf`；Linux 原生运行、线程 API 和完整 OS API 允许清单验收仍待完成。

## 自举固定点迁移

当前入库种子早于 allocator 发射逻辑。使用它构建 cc2 时，cc2 的模块汇编尚未带本地 `malloc/free` 入口；cc2 再构建 cc3 时，新入口出现于 5 个模块汇编文件。cc3 与 cc4 的全部 10 项 `.s/.s.i` 产物逐字节一致。

据此将 `make selfhost-native` 和 `tools/selfbuild-gate.py` 调整为三代构建：校验每代产物完整性，记录种子到候选的一次迁移变化，并要求最终候选 cc3/cc4 达到固定点。候选 cc4 执行自解析、固定点探针和完整语料。滚种子前后主门及扩展门均通过，没有跳过产物差异检查。
