# yh 前端浮点常量折叠

## 交付内容

- 前端常量折叠支持浮点：`const A f64 = 1.5 + 2.25;`、`* /`、比较、一元正负号、
  显式转换（整数↔浮点、浮点↔浮点、f32 窄化）都能在常量声明里求值；
  普通函数中的 `$assert` 也可以直接比较浮点常量。
- 位模式统一：浮点常量值同时写入 `Res.ival` 与 `Res.fval_bits`（字面量、折叠结果、
  编译期函数物化三处一致），const 初始化按 `ival` 保存、浮点使用点读 `fval_bits`。
- 新增 `fp64_from_bits`/`fp64_norm_bits`（gen 模块）、`sem_fold_float_binop`、
  `sem_fold_float_convert`，并给 `sem_fold_const_unary` 加浮点分支。
- 顺带修复：`const A f64 = 1.5;` 之前引用读到 0（字面量只写了 `fval_bits`，未写 `ival`）；
  浮点常量的一元负号此前会落到整数一元分支并把类型改写成 `int`。
- 冻结子集：一元负号走符号位翻转，浮点转无符号整数按有符号截断，不生成
  `fneg`/`fcvtzu`。
- 用例：`tests/yh-run/run/135-float-const-fold.yh`、`fail/139-float-const-modulo.yh`；
  `comptimelocal` 增加浮点常量折叠（`1.25 + 0.75`）与浮点常量物化（`FLOAT_TOTAL == 4.0`）
  断言。

## 边界

- 浮点取模等非算术运算仍拒绝（报「浮点不支持该运算」）。
- 无符号整数目标的浮点转换按有符号截断（冻结子集不含 `fcvtzu`）。
