# yh 编译流程重规划 R3：输出捕获与目录 OS API

日期：2026-10-01。状态：本次迁移切片完成；R3 和 R0–R6 整体仍未完成。

后续环境向量切片已移除 `printenv` 依赖；当前状态与更新后的验证记录见
[环境向量报告](yh-编译流程R3环境向量-2026-10-01.md)。本报告保留该次交付时的历史状态。

## 改动

- `cmd_process_capture` 用 `open/dup2` 捕获外部进程 stdout，所有参数仍作为独立 argv 元素传入；目录扫描和环境读取不再经过 shell 重定向。
- 捕获文件的创建/截断标志按运行编译器的宿主 OS 选择，目标 ABI 与宿主调用环境分开。`.yh` 项目验收在 macOS 宿主执行 `-target linux check`，确保交叉目标不会改变宿主文件标志。
- 新增 `mkdir` OS 接口与 `cmd_mkdirs`。构建目录和项目索引临时目录不再启动 `/bin/mkdir`；路径按分隔符逐段创建，已存在目录经 `open(path/.)` 验证。
- 滚动自举移除对 `--legacy-system` 的主动传递。新种子在默认隐藏 `system` 的配置下自举；旧种子仍按自身旧默认配置工作。显式兼容选项仍保留给迁移期用户代码。
- 新增 `tests/modules/projects/mkdir-api/main.yh`，验证首次创建成功、重复创建失败。项目验收矩阵扩展到 47 项。
