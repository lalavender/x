# yh 编译期结构展开规模预算首片完成记录

日期：2026-10-05。状态：**完成（稳定 typed AST 展开仍在后续阶段）**。

## 修改内容

普通函数的 `$for` 由解析器直接重复解析并发射代码，现有保护只限制迭代次数，无法限制每轮主体很大的情况。编译期注册模块现在对每轮按循环体 token 数累计规模，超过 100000 时在解析该轮前报告错误；已有单区间 1024 轮和编译单元 100000 轮限制继续生效。实现集中于 `compiler/comptime/ct_registry.yh`，解析器只传入待展开主体范围。

该计数是 token 数上界，不是精确 typed AST 节点数。嵌套 `$for` 可能保守超计，因此本记录只交付膨胀保护首片；普通函数 `$if/$for` 从直接重复解析迁移到稳定 typed AST、按实际实例节点数限额并统一 check/build/SSA 路径仍未完成。

新增 `tests/yh-run/fail/97-comptime-expansion-size-budget.yh`。先用旧编译器验证其错误地编译通过，再确认新编译器因总展开规模超限拒绝；既有 1024/1025 边界及 typed 函数 `$for` 用例通过。
