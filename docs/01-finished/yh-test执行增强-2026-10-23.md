# yh test 执行增强（YT2c）实施记录

日期：2026-10-23。范围：执行过滤、逐例超时、`testing.fail/skip`、断言位置
与消息报告、SKIP 汇总。并行、独立日志文件与测试缓存键隔离归 YT2d。

## 交付

- `compiler/cmd/test_cmd.yh`
  - `--filter` 同时作用于 `--list` 与执行：按完整测试身份的子串选择用例，
    过滤后零用例明确报错；构建范围不因过滤改变。
  - `--timeout <秒>`（1..3600，缺省 15）：父进程 `waitpid(WNOHANG)` 轮询 +
    `cmd_clock_ns()` 单调计时，超时 `kill(pid, 9)` 并回收，记 FAIL「用例超时」。
  - 记录解析扩展为 72 字节：`magic + line + col + 60 字节消息`；
    `YHTS` 记 SKIP，`YHTF` 记 FAIL，`YHTP` 记 PASS。
  - 失败输出新增「断言消息: …」；`testing.fail` 不写行/列时不再打印 0:0。
  - 汇总改为 `结果: N passed; M skipped; K failed`。
  - 输出改用 `tc_out` 按 strlen 写出，避免手写字节数截断中文。
- `libs/testing/`（新模块）
  - `fail(message *char) void`：写 `YHTF` 记录（行/列 0）后 `exit(1)`。
  - `skip(reason *char) void`：写 `YHTS` 记录后 `exit(0)`。
  - 只依赖 prelude `write`/`exit`，不 import os/io/string。
- `compiler/backend/llvm_runtime.yh`
  - `__yh_test_assert` 记录扩展为 72 字节，消息区先清零再按 NUL 上限 60 字节
    拷贝，保持短消息不暴露未初始化字节。

## 语料与门禁

- 新 fixture：
  - `tests/modules/projects/ytestskip`：通过、`testing.fail`、`testing.skip`、
    带消息的断言失败、跳过之后继续；
  - `tests/modules/projects/ytesttimeout`：死循环用例 + 超时之后继续。
- `tests/modules/test-check.py` 增至 27 条断言，新增 `execute-filter`、
  `execute-filter-no-match`、`execute-skip-and-fail`、`execute-timeout`；
  `run()` 显式给出 `YH_STDLIB`，使 FAST_STAGE 暂存副本也能解析 `testing`。

  输出 `断言消息: helper 拒绝继续` 与 `断言消息: bump 结果不对`。
- `ytesttimeout --timeout 1`：`FAIL … 死循环用例 / 用例超时`，
  `PASS … 超时之后继续`，`结果: 1 passed; 0 skipped; 1 failed`。

  `test-check` 27/27；TOML 6/6；代码统计 6/6。
