# yh 编译期跨模块 CT 函数来源映射

日期：2026-10-06。状态：已完成。

## 交付内容

- `.s.ct v1` 在每个隐藏编译期函数前写入注释元数据，记录定义源码路径与函数体起始行；路径按十六进制
  编码，避免路径字符影响 sidecar 语法。导入器解码元数据后，在重新解析正文时切换到定义文件路径和
  原始行偏移。
- 导入正文的语义诊断，以及执行期 `$assert`、`$compile_error`、`$compile_warn` 诊断，都会指向定义
  函数的源文件与对应行。无来源元数据的旧 sidecar 仍按 sidecar 路径报告；sidecar 格式错误继续指向
  sidecar 本身。
- 正文导出期间对模块函数名、类型名的替换保留原有换行数量，因此行号稳定。列号仍基于改写后的
  sidecar token 字节列，精确列映射留待后续 token 级来源信息。
- `comptimecross` 覆盖导入函数正文的语义类型错误和实际执行 `$compile_error` 两种诊断路径。
