# yh 编译期数组长度局部值早期探测

日期：2026-10-06

## 交付内容

- `CtReader` 为每次 token 求值单独保存最多 64 个局部整数值；参数和局部槽按标识符查找，嵌套调用创建各自的解释帧。
- CT5A 安全子集允许显式内建整数类型的顶层已初始化 `let`，其算术初始化式可读取形参和更早声明的局部值；条件与返回表达式也可读取这些槽。
- 局部声明不得遮蔽形参或先前局部值，只允许出现在函数最外层；不支持局部赋值/复合赋值、分支内声明、局部聚合、循环及全局值读取。探测器按源码顺序验证声明，并且仅当调用图无环、所有路径穷尽返回时提前执行。
- 新增 `tests/yh-run/run/115-comptime-array-length-local-values.yh`，通过嵌套 `$double_value` 验证调用帧局部值和后续全局结构体/数组布局；新增 `fail/116` 锁定局部赋值不进入早期探测。更新 `fail/108`，改为锁定分支内局部声明仍拒绝。
- 此能力只服务 pass1 布局前的安全早期求值，不代替现有 typed IR 执行器，也不解决待完成的 typed 布局请求与依赖环检测。
