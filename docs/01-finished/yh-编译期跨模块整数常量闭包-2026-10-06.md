# yh 编译期跨模块整数常量闭包

日期：2026-10-06。状态：**CT5B 可达正文引用的已就绪整数常量闭包首片完成；CT5B 整体仍进行中**。

## 结果

`.s.ct v1` 现在会扫描公开编译期函数可达的本模块函数正文，将其中引用的已就绪整数常量
序列化为隐藏 `const`，并把正文中的引用重写到同一隐藏名。初值写出已折叠的值，避免导入方
重新解析原模块的初始化表达式。导入时先执行全局声明 pass 使隐藏常量就绪，再重置 token 游标，
重新检查并捕获 CT 函数正文 typed IR。

`comptimecross` 的 `math.base.plus_one` 使用私有 `OFFSET`。模块验收检查 base 的 `.s.ct` 包含
`const __yhct_OFFSET__ctmath__base_ int = 1;`，并把 `OFFSET` 从 1 改成 2，验证消费者缓存失效、
编译期结果随之更新。此次调试也补正了 `iface_ct_load` 的遍历顺序：全局声明解析会把 token 游标
推进到 EOF，函数正文 pass 必须显式从文件头重启。

同一项目验收保留有效 `.s.ct` 正例，并覆盖公开隐藏正文签名篡改、错误版本、正文截断和语法损坏；
导入方均明确拒绝无效 sidecar。

支持范围限于编译期正文闭包引用的、已经初始化并可通过现有整数类型检查的模块级常量。浮点、
指针、字符串、聚合常量及模块私有具名类型尚未纳入；遇到不支持的常量会拒绝导出。
