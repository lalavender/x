# yh 编译期 typed 数组/切片下标写入完成记录

日期：2026-10-05。

## 结果

编译期函数可更新当前调用帧中的本地整型数组或切片元素，支持 `values[i] = value` 和已支持的整数复合赋值。赋值目标通过 `CtPlace` 区分标量局部槽与聚合元素；下标读取和写入共用基址、元素类型、聚合长度及负数/越界校验。

实现拆分在 `compiler/comptime/ct_ir_place.yh`，执行器更新位于 `compiler/comptime/ct_ir.yh`，位置结构定义在 `compiler/comptime/ct_00_model.yh`。数组/切片参数与返回、指针基址、切片表达式、结构体/联合体和非整型元素仍不支持。
