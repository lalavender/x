## 效果与边界

| 写法 | 之前 | 现在 |
| --- | --- | --- |
| `const P Point = Point{ ... };` | 拒绝 | 可用（上一轮） |

## 顺带实测到的既有前端限制（非本轮引入）

**嵌套数组字面量不被接受**，对 const 与变量都一样：

```
const GRID [2][2]int = [[1, 2], [3, 4]];
let   G    [2][2]int = [[1, 2], [3, 4]];
→ 数组/切片字面量需要目标类型上下文（let 初始化或同型赋值）
```

这是数组字面量的目标类型上下文判定没处理嵌套层，与 `const` 放宽无关；已记入 todo。
