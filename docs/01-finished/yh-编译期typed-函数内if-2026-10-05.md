# yh 编译期 typed 函数内 `$if`

日期：2026-10-05。状态：**typed `$if/$else` 首片完成；typed `$for` 与完整 CT3 仍在实施**。

## 交付内容

- `@[comptime] fn` 准备期不再按形参提前求值 `$if`；保存条件表达式和两支语句树到 typed IR，
  每次 `$f(...)` 调用使用当前调用帧值执行对应分支。
- 两支都会在准备期进行名字和类型检查，准备阶段不执行诊断，也不发射目标代码。无 `$else`
  时条件为假会继续执行后续语句。
- 普通函数 `$if` 继续使用原有常量选择规则，顶层 `$if` 仍拒绝；`$for` 区间展开未迁移。
- 新增 `run/70-comptime-typed-if.yh`、`fail/93-comptime-typed-if-checks-both.yh`，并在
  `comptimelocal` 项目覆盖跨文件正/假选支。
