# yh V 风格编译诊断 D0–D2：源片段 + 精确 caret（2026-11-15）

计划：`docs/02-plan/yh-V风格编译诊断实施方案-2026-11-11.md`（阶段完成后按约定删除）。
规范：`docs/03-design/yh-编译诊断规范.md`（格式/回退/位置规则契约）。

## 交付内容

### D0：观测骨架（`tests/diagnostics/`）

- `check.py`：语料扫描（片段 / caret / 列号越界 / 末字符 / 跨文件）与夹具断言；
  输出稳定、无时间戳；`--snapshot` 生成 `baseline.md`，`--max-line-end` 可作硬门。
- `cases/`：6 个单文件夹具 + 1 个多文件项目夹具，`.expect` 断言头行行列、
  caret 起始显示列、下划线宽度、片段行数、头行文件与片段来源。
- `README.md`：重新生成命令与指标口径。

### D1：渲染器 + 源槽 + token 跨度

- `errors/api.yh`：`DiagCtx.plain`、`set_source_slot`、`bind_source_path`、
  `err_span`/`warn_span`（`err_lc`/`warn_lc` 变兼容层，跨度按 1 字节）。
- `errors/render.yh`：`fmt_diag` + `fmt_snippet`。头行拼装与 D1 之前**同一段代码**
  （同一 2047 字节截断点），plain 回退逐字节不变；片段含上下各 2 行、行号栏最小宽 5、
  tab→4 空格、CRLF 去 `\r`、CJK 按显示宽 2、长行围绕 caret 开窗并补 `…`、
  4 KiB 缓冲写满仍以换行结束。
- `support`：`state_init`/`session_reset` 登记源槽；`read_source` 绑定源码归属路径。
- `token`：`err_at`（按 token 宽度）、`err_range`、`index_at_offset`、`real_index`。
- `cmd/yh/common.yh`：`YH_DIAG_PLAIN=1` → `errors.set_plain(1)`（内部保险）。

### D2：位置审计

- 新增 `compiler/check/diag.yh`：`file_span`/`file_span_code` 切路径 + 源码 + token
  快照，报完恢复；快照缺源码时关闭片段（绝不显示错文件）。`convert.yh` 的
  `diag_file_at`/`tok_line_at`/`tok_col_at` 全部迁入并删除该文件。
- `token.real_index`：诊断不落在合成 token（换行补的隐式 `;`、EOF）上——这是旧
  「caret 落在行尾 +1」的主因；`err_at`/`err_range` 统一回指最近真实 token。
- `check/value_kernel.sem_report`：位置取 `support.fc().c_expr_first`
  （`parse_expr_iso` 记录），值内核错误（类型不匹配/字面量越界/bool 转换/运算）落回
  表达式起点。
- `comptime.ct_err`：位置取 `ct_pos_*` 登记的 `$f(...)` 调用 token（`check.ct_gate.ct_call`
  负责进入/退出），编译期引擎内部的越界、预算、不支持构造等诊断全部落回调用点。
- 逐点修正：函数/枚举/字段/类型/返回语句/`$if` 表达式/`$for`/`len`/`sizeof`/结构体字段/
  重定义/依赖环等约 30 处调用点，改报构造首 token、字段名 token 或表达式起点。
- `errors.bind_source_path` + `source_path_matches`：路径被单独切换（CT 来源映射等）
  时片段自动退回单行头——**修掉一处真实缺陷**：模块构建里「函数未使用」曾用
  `extra.yh` 的行号配上 `main.yh` 的源码。

## 与计划的偏差（明确记录）

1. **D2 指标口径细化**：计划写「列号 = 行长度或行长度+1」，交付把硬指标定为
   `col > 行宽`（越出行尾），`col == 行宽`（指向末字符）单列人工审阅——因为
   `let y int = z` 的 `z` 恰在行尾，`col == 行宽` 可能是正确位置。两种口径的数字都
   写进快照与规范。
2. **单元测试是结构断言 + 逐字节断言混合**：短片段用完整字符串比对（ASCII/多字符/
   tab/CJK/CRLF/警告/跨度夹取），长行开窗与缓冲截断用 caret 相对列与换行数断言。
3. **`.s.ct` 来源映射**：没有新增 `.s.ct` 专项夹具（现有模块/CT 语料已覆盖
   `line_bias` 回退），改为在规范 §2/§4 固化回退规则，并用 `bind_source_path`
   保证「路径与源码不同源时不给片段」。
4. **`check/convert.yh` 被删除**：两个函数迁到 `check/diag.yh` 后该文件只剩注释，
   按「删除自己造成的孤儿文件」处理。
