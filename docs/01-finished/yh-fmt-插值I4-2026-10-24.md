# yh 字符串插值 I4 收口记录（2026-10-24）

## 范围

I0–I3 之后的收口：View 支持、O2 正例、语法模式、全量门与依赖检查。

- `string.View` 插值：parser 比较表达式类型与 `fmt.of_str` 形参类型，
  相同则直接调用；`string.String`/结构体仍报“不支持”。
- O2：`tests/fmt/interp.py` 增加 fmtinterp 的 `-O2` 正例，输出逐字节比对。
- 语法模式：`--syntax-check` 不再要求 import/类型/spec 语义，只验证插值
  token 结构与表达式语法；新增 syntax-only 用例。
- 参考语法：`docs/yh.g4` 注明 `${...}` 是 STRING 内部细化、ANTLR 不解析
  内部；`\$` 加入转义集合注释。
- 依赖检查：fmtinterp 产物 `nm -u` 无 printf/LLVM/lld；`otool -L` 只有
  libSystem。
