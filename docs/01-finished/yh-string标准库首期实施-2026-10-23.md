## 关键契约

- 单位统一为字节（`u64`）；`View` 借用，可含 NUL/非法 UTF-8；`String` 独占
  私有状态，零句柄为空串，显式 `clone`/`move`/`release`。
- 已分配 `String` 始终维护额外结尾 NUL；内容内允许 NUL；`c_str` 对内嵌 NUL
  返回 `status_embedded_nul`。
- 成功的可变操作与 `release` 使旧视图/C 指针失效；失败保持内容、长度、容量
  与既有视图。扩容先分配并复制，全部成功后才交换并释放旧块。
- 自追加/`assign` 识别自身子区间偏移；`assign` 重叠复制使用方向感知字节循环。
- 最大内容长度 `0x7ffffffffffffffe`；求和/倍增先做边界检查；溢出返回
  `status_overflow`，分配失败返回 `status_out_of_memory`。
- 容量按几何增长（至少 16），容量足够时不分配；`reserve` 直接按请求值。
- UTF-8 按 RFC 3629 严格解码：拒绝截断、错误续字节、过长编码、代理项和
  超过 U+10FFFF 的值；接受 U+0000 与 U+FEFF；不静默替换为 U+FFFD。
- 查找/切分/替换首版最坏 `O(n*m)`，未引入 SIMD/KMP；Unicode 大小写折叠、
  规范化、字素边界、正则与格式化后置。
