# 编译期不受支持正文的具体诊断

日期：2026-10-07。状态：已完成。方案：[yh-编译期不受支持正文具体诊断实施方案](../02-plan/yh-编译期不受支持正文具体诊断实施方案.md)。

## 背景

编译期函数正文不在 typed IR 支持子集内时，此前统一报
「编译期函数正文不在受支持的 typed IR 子集内」，无法判断是哪个构造不支持。

## 改动

| 位置 | 改动 |
| --- | --- |
| `comptime/ct_ir.yh` | `ct_ir_is_supported` 改为 `ct_ir_support_code`，返回首个不受支持构造的原因码（100 类型声明、200 goto、300 标签、400 编译期语句、500 其他语句、600 未知表达式种类、700 表达式缺少类型），0 表示受支持 |
| `comptime/ct_00_model.yh` | `CtFunction` 增加 `ir_unsupported` 原因码字段 |
| `comptime/ct_ir.yh` | `ct_ir_import` 同时写入 `ir_supported` 与 `ir_unsupported` |
| `comptime/ct_registry.yh` | 登记时复位原因码；`ct_invoke_in_frame` 回退分支改调 `ct_unsupported_diagnostic(code)`，按类别给出具体文本 |

诊断仍延迟到实际调用时发出（未被调用的编译期函数不误报），位置沿用调用处
`file:line:col`。

## 复用约束

- 新增不受支持的语句/表达式构造时，在 `ct_ir_support_code` 里给出新的原因码，
  并在 `ct_unsupported_diagnostic` 中补一条具体文本；未知码保留统一兜底文本。
- 不给函数体内行列：`CtExpr.first`/`CtStmt.first` 是源 token 索引，与函数体 token
  快照索引域不同，跨模块转发后源 token 表也不再是定义文件。
