# LLVM LL9：统一入口、缓存与失败发布

日期：2026-10-17  
目标：完成单文件和项目构建的 LLVM 入口统一、缓存身份隔离、对象/链接产物校验及失败发布恢复。

## 实现

- 单文件 `check`、`--syntax-check`、`--emit-asm`、`--emit-llvm`、单文件链接，以及项目
  `check/build/run` 和模块 worker 都使用显式后端/target/优化级别。`check` 不启动 LLVM
  工具，也不产生对象；LLVM 入口统计 checked/emitted 函数数，runner 检查零 fallback。
- LLVM 中间目录为 `.build/targets/<triple>/llvm/O<level>/`，含 `llvm/`、`iface/`、`obj/`、
  `manifest/` 和 `ir/`。迁移期 legacy 仍使用旧 `.build` 平面目录。最终项目文件保持在
  `.build/<project.name>`，每个配置在独立目标目录保存链接 manifest 和可执行文件摘要。
- 模块缓存身份包含源文件、依赖接口、编译器指纹、target triple/layout/ABI、优化级别、
  LLVM bridge 版本和 bridge ABI；manifest 同时校验对象机型、对象摘要及持久接口摘要。
  对象身份包括汇编工具路径/内容；链接身份包括 linker 路径/内容、target、优化级别、
  输出路径、模块顺序、对象内容和 C 输入。`YH_CC` 可显式指定 linker；Linux LLVM x64
  缺省使用 `/usr/bin/gcc`，避开 PATH 中的 ARM64 crossbin 包装器。
- LLVM 对象、链接产物和 manifest 均先写临时路径，通过 machine 校验后 rename 发布。
  失败的目标切换或错误架构对象不会覆盖原可执行文件；成功后切换目标会验证并替换同名
  输出。Linux 校验 ELF64 little-endian 的 x86_64/AArch64 machine；Darwin 校验 64 位 Mach-O。
- `tests/yh-run/check.py`、`tests/modules/check.py` 和 `tests/modules/build-check.py` 支持
  显式 `--backend`、`--target`、`--opt-level`。x86_64 LLVM 不运行仅适用于 AArch64 汇编的
  寄存器同名符号检查。
