# yh 编译期 typed 聚合返回

日期：2026-10-06

`@[comptime]` 函数的嵌套 typed 调用现在可以返回执行器已支持的定长整数数组和受支持结构体。被调帧在释放本地存储前将返回值深复制到调用方帧；调用方可继续读取、复制和修改，返回值不会指向已释放的帧。

没有 typed 调用方帧的顶层 `$f(...)` 仍只允许标量结果。切片返回因可能引用被调函数的局部数组而被拒绝；联合体、非整数数组叶元素和其他未支持聚合类型仍不开放。

新增 `tests/yh-run/run/85-comptime-aggregate-returns.yh` 覆盖数组/结构体返回、结构体形参直接返回和修改隔离；新增 `fail/105` 与 `fail/106` 分别固定切片返回和顶层聚合结果的拒绝。`tests/modules/projects/comptimelocal/` 覆盖跨源文件定义和调用。

实现位于 `compiler/comptime/ct_registry.yh`、`ct_ir.yh`、`ct_ir_place.yh`；`compiler/parse/parse_decl.yh` 只放宽受支持数组/结构体返回签名。
