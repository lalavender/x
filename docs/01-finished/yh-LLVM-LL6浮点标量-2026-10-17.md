# LLVM LL6 浮点标量 lowering 完成记录

日期：2026-10-17

## 交付内容

- `CheckedModule` 类型映射和 SSA verifier 支持 f32/f64 标量及浮点基础算术、比较和数值转换。
- LLVM scalar emitter 以 `float`/`double` 发常量和函数签名；f32 常量从保存的 f64 IEEE 位型
  重解释后窄化，每个 f32 运算保留独立舍入点。比较使用 IEEE 有序谓词，`!=` 使用
  unordered-not-equal；浮点运算不加 fast-math、nnan 或 ninf。
- 浮点转整数先调用 LLVM 饱和 fptosi/fptoui i64 intrinsic，再按 yh 源类型截断；整数转浮点
  按源符号性选 sitofp/uitofp。f32/f64 转换、浮点参数和 COPY 均保持规定的位型语义，避免
  加零复制破坏负零。
- f32/f64 局部存储支持 alloca/load/store。LL5 的全局浮点字段和全局初始化拒绝边界没有变化。
- 新增 `tests/yh-run/run/llvm-float-lowering.yh`、`tests/selfhost/llvm-float.py` 和
  `tests/modules/projects/llvmfloat/`。覆盖 NaN、正负零、IEEE 比较、动态算术、f32 中点舍入、
  有符号/无符号转换、NaN/无穷饱和、整数到浮点、CT 与运行期一致性、局部浮点内存及模块调用。

## 边界

- 不实现 printf 浮点格式化；相关运行时覆盖归 LL8b。
- 全局浮点字段/初始化仍按 LL5 规则拒绝；此交付只覆盖 LLVM 浮点标量和局部标量内存。
- 完整驱动、缓存命名空间与事务发布仍归 LL9；yh/C 完整调用 ABI 仍归 LL7。
