# R1 单文件语义检查入口

日期：2026-10-02。状态：已交付本阶段切片，R1 总体验收仍未完成。

`yh check <file.yh>` 现在可独立检查一个源文件。它先读取源文件并初始化语义表，再执行词法分析、类型/声明登记、全局初始化检查与函数体遍历。此模式不要求 `main`，因此可检查库文件；成功时打印“检查通过”，失败时保留源位置诊断并返回非零。

增加了无入口的有效库函数与引用未声明名称的无效函数两个 `.yh` 用例。自举验收复制用例到空目录运行命令，确认两者都不产生文件；PATH 中的 gcc/clang 包装器没有被调用。项目形式 `yh check [module]` 继续使用原路径。

实现中曾先调用 lexer 再加载输入，导致空 token 流误报通过；回归用例暴露问题后，顺序调整为读取源文件、初始化语义表、再词法分析。此入口仍使用现有多遍 parser 和语义/代码发射共享逻辑，未实现一次解析、独立完整 AST/CheckedFunction 或任务私有前端，因此不能据此宣告 R1 完成。
