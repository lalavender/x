# yh 编译流程重规划 R3：直接从入口读取环境向量

日期：2026-10-01。状态：环境读取迁移切片完成；R3 和 R0–R6 整体仍未完成。

## 改动

- 自举编译器入口改为 `main(argc, argv, envp)`，把 OS 传入的环境字符串向量存入本次进程的只读入口状态。
- `pj_env_fetch` 直接比较 `KEY=value` 字符串，只把值 intern 到编译器字符串池；缺失变量保持空值行为。`PATH` 的 worker 定位和 `YH_STDLIB` 查找不再启动 `/usr/bin/printenv`。
- `main` 语义检查继续接受 `main()` 与 `main(argc, argv)`，并新增标准三参数形态 `main(argc, argv, envp)`。
- 新增 `tests/modules/projects/envp-api/main.yh`，设置 `YH_ENV_TEST=present` 后运行目标程序，检查程序入口第三参数包含对应环境项。

## 验证

- 滚种子前与滚种子后 `make test` 和 `make selfhost-native` 均通过：语法正例 66/66、反例 29/29、运行语料 63/63、模块语料 17/17、项目矩阵 48/48。
- `make selfhost-native` 的固定点检查确认 10 个模块产物一致，自解析检查覆盖 36 个编译器源码；并发项目扫描、check、IR/对象/链接缓存及 worker PATH 回归均通过。
- `make seed` 后 `make -B` 成功。Darwin arm64 种子 SHA-256：`a99fceeb2cc4e8483a7871d6b7406f8a62de666d3dfc87d43701da7aac3252ae`；根 `yh` SHA-256：`c588cd670c344d4135080992ab2cf9d8a0f53b21662087ce7b64eb42f14a3609`。
- `nm -u yh` 仍显示系统导入 `_malloc`、`_free`、`_memcpy`、`_strlen` 等通用 C 服务；当前记录不把它们算作已满足的 OS API 依赖。

## 剩余边界

目录枚举仍调用 `/bin/ls`；汇编与链接仍使用系统工具。自有 runtime、导入 API 分类与替换、Linux arm64 原生门尚未完成，因此这次不能验收 R3 或宣布脱离系统依赖。验证仅运行于 Darwin arm64。
