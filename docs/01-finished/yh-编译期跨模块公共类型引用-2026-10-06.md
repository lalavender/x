日期：2026-10-06。状态：实现完成并滚种子复验通过。

## 改动

- `CtFunction` 快照保存其定义文件的已绑定导入别名和模块编号；每个函数各自持有绑定，避免同模块不同
  源文件之间串用最后处理文件的导入表。
- `.s.ct` 导出时，将模块限定公共类型在结构体字面量、`.to_type`、`sizeof`（含连续指针星号）中的
  `alias.Type` 改写成 `.s.i` 提供的规范类型名。局部类型原有语义类型发射路径继续处理完整数组/指针类型。
- `comptimecross` 加入 `types` 模块和第二个 `base` 源文件；两个函数分别使用 `geometry` 与
  `dimensions` 别名，消费者只导入 API 模块即可重建并执行 CT 闭包。
