# yh 编译期 typed 整数切片返回

日期：2026-10-06

`@[comptime]` 函数现在可以在嵌套 typed 调用中返回整数切片。调用返回前，执行器将视图可见元素复制到调用方帧；结果不再引用被调方局部数组或原切片底层存储。调用方能读取、修改，并把结果继续传给嵌套编译期函数。

只接受整数元素切片，且必须有 typed 调用方帧；顶层 `$f(...)` 仍只产生标量常量，`[]Point` 等非整数元素切片继续拒绝。切片字段和其他借用关系没有开放。

新增 `tests/yh-run/run/88-comptime-slice-returns.yh` 覆盖局部数组切片返回、后续聚合分配和嵌套切片形参写入；`fail/105` 改为验证非整数元素切片仍拒绝，`fail/107` 验证顶层切片结果拒绝。`tests/modules/projects/comptimelocal/` 增加跨源文件声明与调用回归。

实现主要位于 `compiler/comptime/ct_ir_place.yh`、`ct_ir.yh` 和 `ct_registry.yh`，返回类型检查在 `compiler/parse/parse_decl.yh`。完整范围见[方案](../02-plan/yh-编译期typed切片返回实施方案.md)。
