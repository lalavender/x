## 交付

- 语法采用单组 `@[extern, noreturn]` 列表，至多一组且位于可选 `pub` 前。
  属性顺序不影响含义；空列表、尾逗号、连续列表、未知/重复属性和声明错配
  均拒绝。删除 `heap`，分配语法不在本轮范围。
- `extern fn` 无体声明引用 C 符号，有体声明导出裸名 C ABI 定义。C ABI 元数据
  与模块导入身份分离；opaque struct/union 仅能经指针使用；共享数据布局和
  extern enum 的 i32 映射有语义及运行测试。
- C 固定参数 ABI 支持已验收的标量、指针、extern enum 和固定标量签名回调。
  回调参数要求直接传入 extern 函数。结构体、数组、切片和函数指针返回等
  未支持形态会在编译期拒绝。
- `noreturn` 进入前端控制流、SSA unreachable、接口属性和后端 trap；变更属性
  会刷新接口并使调用方 IR 按新控制流重新生成。
- `inline` 复用受限 SSA 内联：可展开的小型单块标量函数内联，复杂形态保留
  普通调用；参数只求值一次，私有 callee 函数体变化会使调用方缓存失效。
- 项目 `[c]` 接受 C 源、对象和库；C 源每次构建重编，因此头文件修改会生成
  新对象；C 对象和预编译对象内容参与链接缓存键。构建失败、恢复、空格路径均
  有项目验收。
- yh 的 `printf` 仍是现有 runtime intrinsic，本轮没有把它改成 libc 裸变参。

## 运行边界

上述原生验证运行于当前 Darwin/Mach-O 主机。Linux AArch64 原生运行需要可用的
Linux yh 种子和执行环境，本轮没有用交叉目标汇编结果替代原生运行证据。
