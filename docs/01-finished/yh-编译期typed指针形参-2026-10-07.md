# yh 编译期 typed 指针形参

## 交付内容

- typed 编译期函数的 `*T`（`T` 为整数）形参可接收调用方帧的局部槽地址，
  被调方通过 `*param` 读写该槽，也可把该指针继续传给更深的编译期调用；
  `comptimelocal` 项目新增跨源文件指针形参写回断言，
  `comptimecross` 项目新增跨模块导出正文的 `write_back(target *int, delta int)`，
  覆盖 `.s.ct` 正文/签名携带指针形参与导入方取址写回。
- 新增存活调用帧链：`CtFrame.live_next` + `ct_live_frames` 登记/注销，
  `ct_eval_ir_body` 统一经 `ct_ir_frame_release` 收缩帧。
- 新增 `ct_ir_pointer_target`：解引用与指针形参绑定都必须先在存活帧局部槽
  区间内验证地址，越界即报「编译期指针必须指向当前存活调用帧的整数局部值」。
- **附带修复**：`let text *char = "abc"; return *text;` 以前会让编译器段错误
  （字符串字面量的标签值被当作宿主 `CtValue` 地址解引用），现在给出上述诊断。
- 仍拒绝：指向指针/浮点/聚合的指针形参、指针返回与聚合逃逸、指针算术、
  成员/下标取址、全局与字符串指针常量求值；空指针解引用保留专有诊断。
- 新增 `tests/yh-run/run/132-comptime-pointer-param.yh`，反例
  `fail/132-comptime-pointer-to-pointer-param.yh`、
  `fail/133-comptime-string-pointer-deref.yh`、
  `fail/134-comptime-null-pointer-param.yh`；`fail/104` 改为指向浮点的指针形参，
  `fail/129` 的诊断片段随声明消息更新。
