# yh 编译期函数调用链首片

日期：2026-10-05

## 交付

- `@[comptime]` 函数的单条整数 `return` 表达式现在可显式调用其他编译期函数，
  调用结果可参与外层整数表达式。前向定义和嵌套实参按调用时的参数值执行。
- 编译 CT 函数体时只检查 `$g(...)` 的目标签名、实参数量和参数类型，不提前执行
  依赖形参的表达式；真正调用时复用同一解释器路径。
- 嵌套执行共用 64 层调用帧限制。直接递归超限会给出普通语义诊断，不耗尽宿主栈。
- 多文件项目用例验证调用者与被调用函数可位于同一模块的不同 `.yh` 文件。

## 实现位置

- `compiler/comptime/ct_eval_expr.yh` 解析受限 return 表达式内的 `$g(...)` 并按名字
  找到已登记的编译期函数。
- `compiler/comptime/ct_registry.yh` 负责统一参数转换、签名校验、调用帧限制和函数体执行。
- `compiler/parse/parse_expr.yh` 在 CT 函数定义检查期间延迟求值，只做调用类型检查。

本切片仍使用函数 token 快照；typed CT 表示、局部值、普通 `if/for`、赋值、短路、
步数预算和按路径执行的诊断仍待后续 CT3 增量。
