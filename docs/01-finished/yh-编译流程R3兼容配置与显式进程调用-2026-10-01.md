# yh 编译流程重规划 R3：兼容配置与显式进程调用切片

日期：2026-10-01。状态：R3 首个迁移切片已完成；R3–R6 未完成。

## 改动

- 默认语义 prelude 不登记 `system(cmd)`；CLI 的 `--legacy-system` 显式开放过渡兼容接口。
- 配置位进入模块 manifest、函数 IR 缓存键和链接缓存键。项目 `.yh` 用例验证默认拒绝、兼容 build/check/run，以及切回默认模式时不会复用兼容缓存。
- 无 `system` 调用的 `.yh` 项目验证从兼容配置切换到默认配置时可复用对象但重新链接；再次使用相同配置命中链接缓存。
- 新增 `compiler/cmd/process.yh`，以 `fork/execvp/waitpid` 和独立 argv 启动进程。模块汇编、最终链接、单文件链接、`yh run` 与构建目录创建不再拼 shell 命令；含空格和单引号路径的项目回归通过。
- 自举启动器探测入库种子是否认识 `--legacy-system`，使旧种子继续使用其隐式兼容语义，新种子显式传入选项。

## 未完成边界

项目目录枚举和环境读取仍经 `system` 加 shell 重定向；构建目录创建仍启动 `/bin/mkdir`。因此 `yh` 本身仍有 shell/外部程序依赖，当前编译器也仍依赖系统汇编器与链接器。新种子暂未登记 `dup2`，这是目录输出重定向迁移的滚动自举边界。自有 runtime、真正 OS 目录/环境/线程服务和导入 API 审计仍待 R3；R4–R6 工具链未开始完成。
