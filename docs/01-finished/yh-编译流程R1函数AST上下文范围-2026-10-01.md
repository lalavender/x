# yh 编译流程 R1：函数 AST 上下文范围切片

日期：2026-10-01。状态：已完成函数级 AST arena 范围记录与 lowering 接入；完整 CheckedFunction、任务私有编译状态和线程池前置改造仍未完成。

## 交付

- 新增 `AstFunctionContext`，记录文件/声明身份、token 范围、表达式/语句/语句表达式边/绑定四个 arena 的半开区间以及函数体根。
- 函数语义遍历结束时封存上下文；模块准备期为文件声明建立 O(1) 基址索引，避免每个函数在线性声明数组中重复查找。
- 新 verifier 检查上下文范围不重叠、表达式子节点与局部绑定、语句/边/绑定均属于本函数。
- `ast_ir_lower_module` 改为遍历函数上下文；参数检查只扫描该函数绑定，表达式 lowering/cache key 拒绝越界引用，临时指令缓冲按当前函数表达式数分配。缓存语义版本升到 v3。
- 新增 `local_left` 与 `local_right` 两个 `.yh` 函数，均声明同名局部变量；build 和 `yh check` 统计必须捕获 10 个上下文，且 check 仍在 IR 前结束。入口返回行为保持 58。

## 未完成边界

AST arena 仍由模块级全局指针拥有；函数上下文只是只读切片描述。语法/语义解析继续操作共享解析游标、符号表、类型表、诊断和发射全局，因此尚不能在线程中并发运行 parser 或 check。完整 CheckedFunction、函数级 check 缓存、SSA 的局部变量/调用/通用 CFG、平台后端、线程池、自有运行时与汇编/链接工具链仍按 R1–R6 待办推进。
