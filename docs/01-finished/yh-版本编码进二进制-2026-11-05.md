# yh-版本编码进二进制-2026-11-05

## 概述

`yh --version` 直接输出版本号，**不读 project.toml**：编译器版本以常量
编码进二进制（VCONST）。`yh version` 子命令保持项目语义不变（打印用户
项目的 name + version，外部契约见 build-check.py「清单精简」用例）。

## 变更

1. `compiler/cmdline/cmdline.yh`
   - 新增 `pub const YH_VERSION_TEXT *char = "yh 0.0.11"`（唯一版本真源，
     必须与 `compiler/project.toml` 的 `project.version` 一致）。
   - `cli_common_add` 增加 `--version` 参数（`action = cli.version`、
     `version_text = YH_VERSION_TEXT`）；经 inherit 进入根 parser、六个
     子命令 parser 与单文件 parser——**任何位置都能写** `--version`，
     与 `-h/--help` 同权。
2. `libs/cli/commands.yh`
   - **修复 `argument_from_row` 丢字段**：inherit 深复制参数时未带回
     `row.version_text`，导致继承后的 `--version` 回退成只打印 prog 名。
     补 `spec.version_text = row.version_text`。
3. `libs/cli/commands.test.yh`
   - 新增回归测试「子命令：inherit 保留 version_text」（parent 声明
     version_text → inherit → 子/根 parser 解析 `--version` 断言模板文本）。
4. `tools/arch-check.py`
   - 新增版本一致性断言：`project.toml` 的 version 与
     `cmdline.YH_VERSION_TEXT` 不一致即违规（滚版本只改一处会被抓住）。
5. `AGENTS.md` 使用清单补 `./yh --version` 行。

## 语义对照

| 命令 | 行为 | 依赖 project.toml |
|------|------|-------------------|
| `yh --version` | `yh 0.0.11`（编译器版本常量） | 否 |
| `yh build --version` 等 | 同上（inherit 全覆盖） | 否 |
| `yh version` | `<项目名> <项目版本>` | 是（用户项目语义，保持不变） |
| 裸 `yh` | 帮助 +（有项目时）项目版本 | 否（quiet） |
