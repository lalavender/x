# yh 普通函数编译期 `$for` typed AST 模板首片

日期：2026-10-05。状态：**受限模板实例化已实现；当时的 81/82 项目门失败已于 2026-10-06 修复**。

## 交付内容

- 模块 worker 中，循环体不含嵌套 `$` 指令及局部 `const`/类型声明的普通 `$for` 只捕获首轮 typed AST；其余循环继续逐轮捕获。
- `AstComptimeFor` 保存循环范围、只读迭代绑定、模板 block、模板绑定范围与逻辑节点成本。SSA 对每个区间值发出 i32 常量并降低同一模板，模板局部绑定在轮间复用且不泄漏出块作用域。
- 后续轮按模板语句、表达式和绑定数批量计入原 100000 AST 节点预算。parser 继续逐轮检查语义并为旧后端发码，unsupported SSA 形态可安全回退。
- 新增模块回归在旧种子上语义运行通过但只有两个函数进入 SSA；当前实现三个函数进入 SSA，运行结果退出码为 0。已有带嵌套 `$if` 的展开测试与 AST 节点越界测试继续通过。
