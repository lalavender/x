## 交付内容

### 语法（docs/yh.g4）

`comptimeCall` 增加独立备选（`$is_type` 的第二实参是类型引用，expr 不能以
类型名开头，因此与普通调用备选无歧义）：

```antlr
comptimeCall
    : '$' comptimeTarget '(' callArgs? ')'
    | '$' 'is_type' '(' expr ',' typeRef ')'
    ;
```

`$is_int(x)` / `$is_float(x)` 实参是普通表达式，走既有 `callArgs` 形态，
由语义层按内建谓词名拦截。

### 语义（compiler/parse/parse_expr.yh）

- `parse_comptime_call` 在诊断内建分派后按谓词名分派
  `parse_comptime_pred_kind` → `parse_comptime_pred`（kind 1/2/3）。
- 谓词**只看静态类型、不求值实参**：实参以 `c_em_suppress` 静默发射做完整
  语义检查；折叠上下文（如 `$if` 条件）下临时把 `c_fold` 清零再解析——否则
  实参里的变量引用会误报「变量不是编译期常量」。
- 结果**恒为编译期布尔常量**（`sem_res_const` + 常规发码 + AST PRIMARY 常量
  节点捕获）：普通路径直接折叠；typed 路径记入常量节点后由执行器经 PRIMARY
  常量路径返回——**无需新增 typed IR kind**。
- 判定：`$is_type(x, T)` = `x.type_id == T`；`$is_int(x)` =
  `ty_is_integer(x.type_id)`（含 bool/char/enum）；`$is_float(x)` =
  `ty_is_float(x.type_id)`（f32/f64）。

## 已知边界（首片）

- 谓词实参是**静态类型引用**：typed 正文中依赖运行时值的类型分派（如
  `$is_type(p.x, T)`）可用（字段/元素静态类型已知）；「按值类型」分派
  （运行期判类型）不在设计内（无运行时反射）。
- 动态字段（`$field`）与 `T.fields` 元信息 for-in 待 P1b/P1c。
- 仅单文件语义完整；跨模块 `.s.ct` 闭包中的谓词常量折叠结果序列化沿用
  既有常量闭包路径（谓词是常量，无新正文形态需要重写）。
