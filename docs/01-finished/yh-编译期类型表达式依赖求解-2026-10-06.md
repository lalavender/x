- pass1 数组长度遇到 `$` 调用、未就绪整数 const 或 `sizeof` 时保存当前文件的 token
  范围，创建显式 pending 数组；普通可折叠长度仍走原常量表达式路径。
- typed CT IR 把 pending `sizeof(T)` 保存为目标类型编号，不填临时大小。布局调度沿
  typed CT 的嵌套 `$` 调用链检查依赖；类型布局 READY 后才执行读取 `sizeof` 的函数。
- 单文件与模块 worker 反复执行可运行的布局 const/数组长度表达式，并推进数组、结构体
  布局。普通前向全局 const 仍按原顺序拒绝；真实常量依赖环显示常量闭链，值/布局互相
  阻塞时报告布局依赖环类别。目前混合依赖诊断不输出完整节点路径。
