# yh CLI1：最小可用命令行（2026-10-19）

计划见[实施方案](../02-plan/yh-cli标准库实施方案.md)的 CLI1，
接口语义见 [cli 设计](../03-design/yh-cli标准库设计.md)，
语言能力基线见 [CLI0 完成记录](yh-cli0语言能力与ABI基线-2026-10-19.md)。

## 目标

在 `libs/cli/` 交付可运行的最小命令行库：声明、注册、冻结、严格解析、
结果命名空间与类型化查询、基础 usage/help、argc/argv 适配与 0/1/2 退出契约。
未实现的能力在 `freeze` 或解析时给出明确诊断，不静默按另一套规则处理。

## 交付物

| 文件 | 职责 |
| --- | --- |
| `libs/cli/cli.yh` | 公开数据模型、容量常量、构造函数、模块私有分配池与状态类型 |
| `libs/cli/schema.yh` | `init`/`add_argument`/`add_alias`/`freeze`/`last_error`/`destroy` |
| `libs/cli/values.yh` | 命名空间、值深复制、`contains`/`provided`/`occurrences` 与类型化 getter |

- `libs/project.toml` 的 `[lib]` 增加 `cli = { path = "./cli" }`。
- `libs/cli/test/clibasics/`：验收项目，`--selftest` 跑语义断言，
  其余参数走 pack 入口形态。
- `libs/cli/test/run.py`：自有 runner（构建后用显式 argv 运行程序，断言退出码与
  stdout/stderr 子串），本阶段用例为 `cli1-basics-selftest`、`cli1-pack-run`、
  `cli1-pack-help`、`cli1-pack-missing`。

## 已实现的公开 API

- 值：`value_none/text/i64/u64/f64/bool/sequence`、`default_of`、
  `suppress_default`、`inherit_default`。
- 数量：`infer_arity`、`single`、`exactly`、`optional`、`zero_or_more`、
  `one_or_more`、`remainder`、`no_values`（后三者在 `freeze` 时按阶段拒绝）。
- 声明：`parser_config`、`option`、`positional`。
- 注册：`init`、`add_argument`、`add_alias`、`freeze`、`last_error`、`destroy`。
- 解析：`parse`、`parse_main`、`parse_main_or_exit`、`release`。
- 查询：`namespace_init`/`namespace_set`/`namespace_destroy`、`contains`、
  `provided`、`occurrences`、`get_value`、`get_text`、`get_i64`、`get_u64`、
  `get_f64`、`get_bool`、`get_list`。
- 帮助：`format_usage`、`format_help`、`release_text`、`render(text *TextResult, fd int)`。

## 行为契约（CLI1 实测）

- **默认值**：`inherit` 用 parser 级策略；`explicit` 用给定值（缺席也创建键，
  `provided=false`）；`suppress` 不创建键。action 固有缺省为
  `store_true=false`、`store_false=true`，其余 none（缺席的 `count` 因此是
  none 键，`get_i64` 返回 -2）。
- **出现记录**：`provided`/`occurrences` 只统计显式出现；默认值与
  `namespace_set` 不计数。
- **optional 选项**：`--tag` 无后续非选项 token 时写入 `const_value`；
  有值（含等号附着）时按 `value_kind` 转换。
- **附着值**：`--output=out.bin` 接受显式空串；零参数 action 带 `=` 报
  usage_error。
- **`--`**：其后 token 全部按位置参数处理。
- **类型转换**：text 原样；integer/natural 为严格十进制（允许数字之间单个
  下划线并检查溢出）；real 为十进制与科学计数；boolean 只接受 `true/false`。
  转换失败是 usage_error，不静默接受文本。
- **控制 action**：`--help`/`--version` 返回 `help_requested`/`version_requested`
  并在结果里带 `control_text`；控制 action 不创建 dest 键。
- **退出契约**：`parse_main_or_exit` 成功才返回；帮助/版本退出 0，
  usage_error 退出 2（stderr 打印 `prog: 错误: ...` 与 usage），
  config_error/resource_error 退出 1。
- **生命周期**：结果文本与列表都在结果自己的池里，parser `destroy` 之后仍可读；
  `release` 释放结果全部存储；零值 `destroy`/`release`/`release_text` 安全。
- **粘滞配置错误**：`add_argument` 首次失败后保留诊断，后续注册不再修改声明，
  直到 `destroy` 后重新 `init`。

## 容量上限（CLI1）

`MAX_ARGS=64`、`MAX_NAMES=4`（每参数名称数）、`MAX_ENTRIES=128`（结果键）、
`MAX_LIST=64`（单列表元素）、`MAX_ARGC=128`、`MAX_TEXT=1024`、`MAX_HELP=8192`。
超出上限返回带诊断的失败，不静默截断。

## 未实现（后续阶段）

- CLI2：`append`/`append_const`/`extend`/`boolean_optional`/`custom`、

  suppress 与类型查询错误矩阵、等号/短选项组合 `-vvv`、负数特判、唯一缩写。
- CLI3：子命令、inherit、组与互斥、`parse_known`/`parse_intermixed`、initial。
- CLI4：converter/validator/自定义 action、参数文件。
- CLI5：完整 HelpFormat、metavar 列表、deprecated、颜色与终端检测，
  以及 Result 级 `render(result, out_fd, error_fd)`/`print_usage`/`print_help`/`exit_code`。
- CLI6：与 Python 3.14 子集的差分、全门、文档冻结。
