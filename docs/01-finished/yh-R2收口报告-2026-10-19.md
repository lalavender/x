# yh R2 收口报告（2026-10-19，RS5）

## 1. 范围与依据

本报告对应 `docs/02-plan/yh-R2收尾实施计划.md` 的 RS5 切片：优化覆盖与提交协议复核、
R2 收口声明。R2 收尾整体仍按 RS0–RS6 执行；本报告记录当前达成边界，不把未完成项
宣称完成。

## 2. R2 已完成（达成）

- **RS1 任务私有上下文**：RS1a 域标注、RS1b 诊断缓冲私有化、RS1c `TaskCtx` 收敛
  199 字段（种子 `5b34a067…`）；RS1d 显式传参并入 R2c。
- **RS4 缓存键收口**：编译器指纹、汇编器/链接器身份、目标/优化级/后端、源文件与
  依赖接口内容均在键中（`link_cache.yh:868/991/462`、`module_build.yh:629-705`）。
- **R2a 对账回填（RS0）**：switch/goto/for-in/无限循环、一元与浮点、聚合/内存、
  间接调用与变参、单文件与 `--emit-asm` 共用、负数字面量实参均已关闭或归位；
  仅“默认优化覆盖与缓存提交协议复核”归 RS5，“双平台 arm64 ABI”移交 F1/F2。
- **过渡能力**：fork/COW 快照 worker、InterfaceReady 调度、对象/链接缓存、受限函数
  IR 缓存（SSA 子集）、缓存指纹/阶段计时。

## 3. R2 未完成（仍缺）

- **RS2**：LLVM 模式函数级 check/IR 缓存（真缺口；legacy 仅窄子集）。
- **RS3**：文件级对象（设计定稿，待实施）。
- **R2c**：并发标准库之后的多模块线程并行（宿主线程桥 → libs/sys 线程原语 →
  编译器线程池），推迟到并发标准库完成之后。

## 4. 提交协议复核

- 失败事务：worker 失败停止派发、回收运行 worker、跳过最终链接；yh run 不运行旧程序
  （既有模块语料与失败注入门覆盖）。
- 原子发布：新接口先在本轮后缀命名空间发布，消费者不必等生产者私有函数/汇编结束；
  worker 完整成功后才原子提交持久接口与 manifest。
- 缓存损坏拒绝并重建：legacy SSA 与对象缓存均有 corrupted 拒绝回归（build-check）。
- 确定性：同输入两轮构建产物逐字节一致；输出独立于调度顺序（既有门）。

## 5. 优化覆盖现状

- LLVM 路线 fallback=0（asm 4 模块 298/298 checked/emitted，link 6 模块 197/197）。
- 默认优化：O0 为默认，O2 显式；LLVM 优化由内嵌桥/LLVM 管线承担，yh 侧不重复实现
  NP4 机器 IR。
- 性能：单函数修改 743.5/817.8 ms、冷编 2203.0/2765.1 ms（中位数/p95），
  200ms/1s 目标未达；主要受限于外部汇编器与模块级对象粒度，RS2/RS3 是主要后续工作。

## 6. “首个完整 SSA 版本”达成边界

**包含**：
- LLVM 后端 LL1–LL10 全覆盖（控制流、内存/聚合、浮点、调用/ABI、运行时/宿主桥、
  驱动/缓存/提交、内嵌 lld、x64 原生自举）。
- 受检前端快照与模块 IR 交接（LL2）。
- 任务私有上下文收敛（RS1）。
- 缓存键完整性（RS4）。
- 对象/链接缓存与失败事务。

**不包含（明确排除）**：
- 真正线程池 / 任务私有上下文显式传参（R2c，推迟到并发标准库）。
- LLVM 模式函数级 check/IR 缓存（RS2）。
- 文件级对象（RS3）。
- 双平台 arm64 LLVM ABI 验收（F1/F2）。

## 7. LL11 阻挡状态

LL11 默认切换仍以 **RS2 + RS3 + R2c 全部关闭** 为前提（todo.md 已记录）。
本报告不解除该阻挡；仅把当前达成边界与剩余缺口写清楚，供后续会话按切片实施。
