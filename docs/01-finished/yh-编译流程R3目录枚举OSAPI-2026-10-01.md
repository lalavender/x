# yh 编译流程重规划 R3：项目目录枚举 OS API

日期：2026-10-01。状态：目录枚举迁移切片完成；R3 与 R0–R6 整体仍在实施中。

## 改动

- 项目扫描移除 `/bin/ls`。Darwin arm64 使用已登记的 `getattrlistbulk` OS API；Linux arm64 使用目标专属 `linux_syscall6` intrinsic，直接发射 `svc #0` 调用 `openat/getdents64/close`。
- Linux syscall 函数同时可直接调用和取函数值。后者需要可寻址入口，因此后端为 intrinsic 生成本地 ABI stub，避免产出未定义的外部符号。
- 公共扫描逻辑把文件名和目录类型复制到本次扫描拥有的动态向量，跳过点文件，按字节序排序后递归。名字在复用 OS 缓冲区前复制，避免悬空引用。
- `.yh` 项目用例覆盖空格、引号、非 ASCII 与换行文件名、隐藏项过滤以及超过 512 项的大目录；另覆盖 Darwin API 与 Linux syscall 的目标隔离、直接调用和函数指针调用。

- 滚种子前后 `make test` 通过：语法正例 66/66、反例 29/29、Darwin Mach-O 运行 63/63。
- 滚种子前后 `make selfhost-native` 通过：相邻两代 10 个模块产物一致、39 个 `.yh` 源文件自解析、固定点探针通过、并发项目扫描 8/8、模块 17/17、项目 52/52。

## 剩余边界

Linux arm64 原生目录扫描、自有 runtime、线程 API 和完整 OS 导入审计仍待完成。编译器目前仍使用系统汇编器/链接器，并依赖 `malloc`、`free`、`memcpy`、`strlen` 等通用 C 服务；因此不能把此切片视为 R3 完成或自有工具链闭环。
