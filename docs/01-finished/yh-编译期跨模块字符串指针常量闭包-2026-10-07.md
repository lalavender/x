# yh 编译期跨模块字符串指针常量闭包

日期：2026-10-07。状态：已完成（直接字符串字面量 `*char` 首片）。

## 交付内容

- `CSym` 为可重放的直接常量字面式记录类型，当前区分浮点数字面式与字符串字面式。全局私有
  `*char` 常量若由单个字符串 token 初始化，会将原始 token 字节保存到名字池。
- `.s.ct v1` 为可达该常量的 CT 闭包输出隐藏 `const` 声明和原始字符串 token。导入侧重新解析，恢复
  正确的指针类型与字符串常量检查，不把提供方数据标签复制到消费者。
- `.s.ct` 加载期间会恢复 `.data` 缓冲长度和数据标签计数，丢弃隐藏字符串常量解析产生的运行期数据，
  避免消费者汇编包含只属于编译期闭包的字符串。
- 只支持直接字符串字面量初始化的 `*char` 常量。其他指针常量表达式、指针求值和解引用仍不支持；
  typed 求值路径读取指针常量时明确报错，避免把数据标签误当整数。`comptimecross` 覆盖闭包正例、
  非字面量指针常量拒绝和选中分支中的指针常量求值拒绝。
