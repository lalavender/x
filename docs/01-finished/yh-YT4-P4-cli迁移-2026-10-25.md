# YT4-P4：cli 测试迁移（2026-10-25）

## 范围

把 `libs/cli/test/` 五个 `--selftest` 主体（clibasics/cliactions/clicommands/
cliextensions/clihelp，约 3625 行）迁入 `libs/cli/zz_tests_*.yh`；保留真实
argv/退出码/stderr 的 `libs/cli/test/run.py` 与 Python argparse 差分
`libs/cli/test/diff.py`。

## 分片与对照

| 片 | 旧夹具 / `case_*` | 新文件 / test 数 |
| --- | --- | --- |
| P4a | `clibasics`: `selftest()` | `zz_tests_basics.yh`（5） |
| P4b | `cliactions`: 12 个 `case_*` | `zz_tests_actions.yh`（12） |
| P4c | `clicommands`: 9 个 `case_*` | `zz_tests_commands.yh`（9） |
| P4d | `cliextensions`: 15 个 `case_*` | `zz_tests_extensions.yh`（9） |
| P4e | `clihelp`: 8 个 `case_*` | `zz_tests_help.yh`（8） |

合计 **43 个 `test`**（`yh test cli` 43/43）。

说明：

- 文件名必须 `zz_` 前缀：`cli` 的类型声明在 `cli.yh`，`99_` 会排在它之前导致
  “未知类型（类型必须先定义）”。
- 迁移时去掉每个错误分支里的 `release`/`destroy` 重复与编号返回，改成
  `$assert`；失败中止该 test，父进程继续下一例。
- `cliextensions` 的参数文件用例改用 `/tmp/yh-cli-*.txt`（含嵌套/循环/上限），
  逐例 `os.remove_file` 清理；不再依赖 CWD。
- 只调用 `cli` 的 pub API（含 `test_alloc_count`/`test_fail_alloc_after`
  这两个测试注入接口）。

## 删除/保留

| 项 | 处置 |
| --- | --- |
| `cliactions`、`clicommands`、`cliextensions`、`clihelp` | 整目录删除（只有 `--selftest`） |
| `clibasics` | 保留，仅 `build_pack_parser`/`run_pack`/`main`（86 行） |
| `libs/cli/test/run.py` | 10 → 5 例：climodel、clibasics ×3（run/help/缺参）、cliwarnings |
| `libs/cli/test/diff.py` | 保留（Python argparse 差分，91/94 一致 + 3 已知差异） |
| `libs/cli/zz_tests_*.yh` | 新增 5 个文件、43 test |

`make libs-test` 的缺测试提示改为匹配 `*tests*.yh`（`zz_tests*` 也算），
cli 不再被误报。
