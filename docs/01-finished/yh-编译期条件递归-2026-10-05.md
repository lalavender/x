# yh 编译期条件递归

日期：2026-10-05

## 交付

- 扩展编译期函数执行器，解释整数比较条件、普通 `if/else` 和 `return`；分支以当前
  调用帧里的值选择，只执行选中块，未选块中的调用和诊断不会触发。
- 复用既有定宽整数折叠检查完成比较；递归调用继续共用 64 层帧限制。
- 新增 `tests/yh-run/run/65-comptime-conditional-recursion.yh`，计算 `factorial(6)`，
  并验证未选负数分支里的 `$compile_error` 不会报错。

## 实现位置

- `compiler/comptime/ct_eval_expr.yh`：比较值、未选块跳过、if 分支和返回状态解释。
- `compiler/comptime/ct_registry.yh`：复用前一切片的统一调用帧和参数绑定。
- `compiler/parse/parse_expr.yh`：CT 函数定义检查继续验证分支和调用签名，不执行形参条件。

当前执行器尚不支持普通 `for`、局部声明/赋值、短路逻辑、执行步数预算，以及
`@[comptime]` 函数中的诊断按选中路径执行。
