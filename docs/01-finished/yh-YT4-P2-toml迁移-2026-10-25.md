# YT4-P2：TOML 测试迁移（2026-10-25）

## 范围

把 `tests/modules/projects/toml{model,strings,scalars,tables,errors,files}` 的
160 个 `ok()`（运行时断言点 154 个，另 6 个是 `fn ok` 定义）迁入
`libs/toml/99_tests.yh`，同版本删除 6 个纯断言夹具与 `tests/toml/run.py`；
一致性/注入/安装门保留。

## 断言对照表

旧夹具的 `main()` 是平铺 `ok()`，运行时断言点与新文件 `$assert` **154 = 154**
一一对应。

| 旧夹具 | 覆盖点 | 新 `test` |
| --- | --- | --- |
| `tomlmodel` | 空文档、借用输入、多文档共存、复制视图、空句柄、位置 | `模型：空文档、借用与多文档` |
| `tomlstrings`（转义部分） | 转义全集、`\xHH`→UTF-8、解码 NUL | `字符串：转义、hex 转义与 NUL` |
| `tomlstrings`（其余） | 字面量、多行裁剪/续行、引号/空/NUL 键、非法字符串 | `字符串：字面量、多行与键语义` |
| `tomlscalars`（整数） | i64 边界、二/八/十六进制、下划线与非法写法 | `标量：整数边界与进制` |
| `tomlscalars`（浮点） | 位模式、inf/nan/负零/次正规、上溢/下溢 | `标量：浮点位模式与特殊值` |
| `tomlscalars`（布尔/时间/out 契约） | true/false、四种时间、`as_*` 失败不改 out | `标量：布尔与时间` |
| `tomltables`（前半） | 点键/隐式表/顺序、数组与嵌套、空数组、越界 | `表：点键、顺序、隐式表与数组` |
| `tomltables`（后半） | 内联表、数组表、冲突矩阵、引号表头、CRLF | `表：内联、数组表与冲突矩阵` |
| `tomlerrors`（前半） | 参数/UTF-8/BOM/语法/输入/嵌套/键/有效位预算 | `错误：编码、语法与预算` |
| `tomlerrors`（后半） | 查询边界、空输出参数、缺失键 | `错误：查询边界` |
| `tomlfiles` | 真实文件读取、I/O 错误分类、空路径、坏文件、双文档 | `文件：读取、错误分类与生命周期` |

说明：

- 断言只调 toml 的 pub API；`io` 仅用于在 `/tmp` 写测试文件（测试专用导入），
  文件用 `/tmp/yh-toml-test-*.toml` 并在用例内 `unlink`。
- `tomlfiles` 的 `$if (linux)/$if (darwin)` `native_code` 分支原样保留。
- 旧 `tomlstrings`/`tomlscalars`/`tomltables`/`tomlerrors` 里的 `bytes_eq`、
  `cstr_eq`、`value_text`、`int_at`、`nested_int`、`f64_bits` 收敛为
  `tt_*` 前缀的模块私有 helper；错误断言用 `tt_rejects`/`tt_rejects_bytes`
  合并“拒绝 + 错误码 + 无半成品文档”。
