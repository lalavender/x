# yh fmt R0 实施记录（2026-10-24）

## 交付

在 `libs/fmt/` 落地 V 风格插值运行时的第一阶段（R0）：

- `00_model.yh`：`Kind`、`Value`、`Status`（含 `status_unsupported`）、
  `TextResult`。
- `10_value.yh`：`of_int`/`of_i64`/`of_u64`/`of_f64`/`of_bool`/`of_str`/
  `of_cstr`、`value_invalid`、`kind_of`；NULL C 字符串按空串处理。
- `30_render.yh`：`append_text`、`append_value` 的空 spec 默认渲染；整数
  十进制（含 i64 最小值）、无符号十进制、bool、字符串与 `<nil>`。
- `99_tests.yh`：7 个 yh 内建测试；`libs/project.toml` 登记 fmt；
  `make test-lib-tests` 追加 fmt。
- `docs/03-design/yh-fmt标准库设计-2026-10-23.md` 状态改为 R0 已实施；
  设计补 `status_unsupported`。

cd libs && ../yh test fmt --timeout 60

`make` 冷编成功（种子 `bin/yh-darwin-arm64`，内嵌 LLVM 桥）；本轮未改编译器、
未改语法、未滚种子。

## 边界

- `append_value` 的非空 spec 仍返回 `status_invalid_spec`（R1 接通）。
- `of_f64` 的默认渲染返回 `status_unsupported`（R2 接通）。
- print/sprint/render 与 `of_string` 尚未实现（R3）。
- 语言层 `${}` 插值与编译器降级尚未开始（I0–I5）；fmt 当前只能由 `.yh`
  代码直接调用。
- 未运行 `make test` 与 `make selfhost-native`；R0 只改标准库模块，最终
  收口时统一跑全量门。
