# 0.0.8-rc.2 — 换行终结语句预发布（首个可发布候选）

本 Release 分发支持「换行终结语句」的种子：简单语句、`module`/`import`、
类型别名、结构体字段与枚举成员可以省略行尾分号；同一行相邻语句仍用 `;`
分隔。rc.1 的 tag 落在 CI 迁移之前（该提交里没有 `.gitea/workflows`），发布流水线从未启动、没有产出资产；rc.2 是同一份代码在 Gitea Actions 上的首个可发布候选，用于 0.0.8 的候选验收，也作为后续批量删除源码分号的种子来源。

## 内容

- `\n` 参与语句边界：词法归一化在换行处、`}` 前与 EOF 前补入零长度
  `TK_SEMI`，解析器复用原分号扫描，用长度区分隐式/显式终结符。
- 严格续行：括号/方括号内允许自由换行；括号外的运算符必须写在上一行末尾，
  行首运算符属于下一条语句。裸 `return` 在行尾结束。
- 参考语法新增 `tokens { IMPLICIT }` 与 `stmtEnd`，语料门禁按同一规则归一化
  token；编译器与 ANTLR 对同一份语料判定一致。
- 编译器源码、语料与标准库完成严格续行排版迁移（编译器 201 处、语料与
  标准库 82 处），迁移前后模块产物逐字节相同。
- 空语句、块后多余的显式分号、字面量缺逗号仍按原规则拒绝。

详见[设计](../03-design/yh-换行终结语句设计.md)与
[完成记录](yh-换行终结语句-2026-10-22.md)。
