# yh LLVM LL5 结构体切片：字段、嵌套、字面量与联合体（2026-10-15）

**状态：**结构体/联合体字段切片完成并验收；切片、全局/CT 数据、聚合参数/返回
按后续切片推进，LLVM 默认未切换、种子未滚。

## 1. 范围

- 结构体/联合体绑定 ALLOCA 字节存储（沿用数组切片的 ALLOCA/GEP/MEMCPY）；
- 字段读写 `p.x`、复合赋值 `p.y += v`、嵌套 `b.inner.x`；
- 字段取址 `&p.x`、指向结构体的指针解引用 `(*pp).y`；
- 结构体字面量 `Pair{ x: 1, y: 2 }`（含嵌套字面量与结构体数组元素）；
- 按值复制 `let q = p;` / `q = p;`（MEMCPY）；
- 联合体共享存储（写 `i` 读 `b` 取低位字节）；
- 未初始化 `let`（标量/聚合，与旧后端一致）：`let x int;`、`let p Pair;`、
  `let v Val;`。

不在此片：切片、全局/字符串/CT 数据、聚合参数与返回（LL7）、`for-in`。

## 2. 实现（`compiler/ast/checked_module_lower.yh`）

- `checked_lower_member_field`：`AST_EXPR_MEMBER` 不携带字段下标，按成员名 token
  的源码字节与快照字段名池比对，在 `CType.sub/len` 指定的字段表内查找；
- `checked_lower_lvalue_ptr` 增加 MEMBER 分支：基址可为聚合存储（递归取址）或
  指向结构体的指针（按值加载）；字段地址 = 基址 + `SField.offset` 的常量 GEP，
  结果指针带字段 canonical 元素类型；
- `checked_lower_struct_literal`：按 `AST_EXPR_STRUCT_FIELD` 节点链逐字段写入
  （`op` 是字段表绝对下标，`child1` 是值）；标量字段 STORE、聚合字段递归；
- `checked_lower_aggregate_store` 放行 STRUCT/UNION：字面量逐字段、变量/左值
  MEMCPY；`checked_lower_expr_inner` 增加字段读取；赋值左值分类加入 MEMBER；
- 函数序言的聚合存储放行结构体/联合体；
- **未初始化 let**：标量保持未定义 SSA 值、聚合存储已 ALLOCA。带长度/类型引用
  的类型（`let a [3]int;`）会先挂类型表达式边，因此用语句 token 范围内是否有
  `=`（`checked_stmt_has_assign`）判断是否真的初始化。
