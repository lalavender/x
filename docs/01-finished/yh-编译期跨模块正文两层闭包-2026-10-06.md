# yh 编译期跨模块正文两层闭包

日期：2026-10-06。状态：**CT5B 整数接口的两层跨模块闭包首片完成；CT5B 整体未完成**。

## 结果

`.s.ct` 中的公开编译期函数可以调用另一模块的公开 `@[comptime]` 函数。导出时，
`$alias.function(...)` 被重写为依赖模块稳定的隐藏函数名；导入时 typed IR 函数切片追加到
当前编译期 arena，表达式、语句、边和局部绑定索引同步重定位。该机制解决了多个 sidecar
各自从 AST 编号 0 开始解析、与当前模块 IR arena 编号冲突的问题。

新增的 `comptimecross` 项目从 host 调用 `math.api.double_after_bump(20)`，由 api 私有 helper
调用 `math.base.plus_one`，编译期结果为 42。测试确认 `.s.i v3` 和 `.s.ct v1` 发布、隐藏函数
未生成运行期汇编符号。测试再把 `plus_one` 的增量从 1 改为 2，要求消费者缓存失效并重新求值，
结果变为 44（host 程序以退出码 2 验证）。
