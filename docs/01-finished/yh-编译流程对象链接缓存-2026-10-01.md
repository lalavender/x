# 编译流程重规划切片：模块对象与链接结果缓存

日期：2026-10-01。此切片在现有模块汇编输出上加入内容校验对象缓存和最终程序
缓存，为完整 SSA/file-object 管线提供增量行为基线。对象清单同时记录汇编输入键
和对象内容键；链接清单同时记录链接输入键和最终程序内容键。缺失或损坏的对象
会重新汇编；最终程序被删除或覆盖时会重新链接。缓存键使用 64 位 FNV-1a。

新增 `tests/selfhost/link-cache.py`：对两个模块的 `.yh` fixture 包装 gcc/clang
记录实际命令，并验证冷构建、热构建、损坏对象、损坏可执行文件和依赖函数体变化。
同时检查 `--stats` 的汇编/链接计数，确认热构建为 0/0，损坏对象修复为 1/0，
损坏程序修复为 0/1，函数体修改为 1/1。仅被修改的 `mathx` 模块重新汇编，运行
结果由 42 更新到 63。

## 固定语料测量

环境与输入同 [R0 基线](yh-编译流程R0性能基线-2026-10-01.md)：Apple M1、
macOS 27.0、25 个 `.yh`、13,338 行、464,518 字节，每场景 20 轮。计时覆盖
编译器进程、汇编器与链接器。当前编译器 SHA-256：
`cabd1a089f0cced53a0b695f5b2f5db76e71f302dc32488c173c1855e4d3f0ad`。

| 场景 | 中位数 | p95 | 峰值子进程 RSS | 模块重编/命中 | 汇编/链接 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无改动 | 186 ms | 223 ms | 14.14 MiB | 0 / 4 | 0 / 0 |
| 单函数体变化 | 894 ms | 958 ms | 50.66 MiB | 1 / 3 | 1 / 1 |
| 冷编 | 2,199 ms | 2,287 ms | 50.78 MiB | 4 / 0 | 4 / 1 |

最终版本每次构建只计算一次编译器二进制指纹，并把链接缓存逻辑拆到
`cmd/link_cache.yh`。相较上一 R1 切片，无改动中位数降低约 89%，函数体变化
降低约 52%；冷编降低约 0.8%。热构建不再启动 gcc/clang，因此峰值子进程 RSS 主要
反映 yh 本身，不能与启动汇编器的样本直接视为同一种子进程构成。50/200/1,000 ms
目标目前均未达到；无改动、函数体变化和冷编中位数分别是目标的约 3.7、4.5、
2.2 倍。

这仍是过渡期模块级 `.s/.o` 缓存：每次命令仍扫描并词法索引全部 25 个文件；
变化模块仍检查整个模块，完整 AST、函数级 check/IR、文件级对象、线程池和接口
提前推进尚未实现。对象键记录汇编内容、目标方言和命令参数；外部工具升级身份
目前不是键的一部分，切换到自有工具链时必须纳入工具版本。冷编和完整门需要
后续阶段继续验收。
