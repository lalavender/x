## 1. 交付内容

### `examples/os-demo`（YH_STDLIB 显式加载）

- 文件：创建/截断、写入、读取、关闭。
- 文件复制：64 字节缓冲循环 read/write，显式处理短读写与关闭。
- 目录枚举：`open_dir/next_entry/close_dir` 流式打印名称，名称借用读取器缓冲。
- 环境：三参数 main 接收 envp，`get_env` 查询 PATH。
- 进程：`spawn(argv[0], ["child"], envp)` 启动自身子模式，`wait` 取 exit(7)。
- README 给出运行命令与 Linux 文件 API 限制；临时文件在开始/结束清理。

### `examples/os-demo-explicit`（项目依赖）

- `project.toml` 声明 `yh_libs = { path = "../../libs" }`。
- `import yh_libs.os as os;` / `import yh_libs.io as io;`，不依赖 YH_STDLIB。
- 演示 env 查询、旧 sleep_us 契约与 io 输出，作为应用绑定标准库的推荐写法。

## 2. 验证

```sh
# Darwin/arm64（显式依赖示例）
cd examples/os-demo-explicit && ../../yh run

# Linux/arm64 容器（两个示例）
cd examples/os-demo && YH_STDLIB=/work/libs /work/bin/yh-linux-arm64 run
cd examples/os-demo-explicit && /work/bin/yh-linux-arm64 run
```

- Darwin/arm64：`os-demo-explicit` 输出 `os demo explicit ok`，退出 0。
- Apple Container `debian:trixie`（Linux/arm64，入库种子）：
  `os-demo` 输出 `.build/main.yh/...` 目录项与 `os demo ok`，退出 0；
  临时文件已清理。
- `os-demo` 使用 Linux 文件/目录/进程 API，Darwin 新接口接入前只在 Linux 运行；
  README 已注明。
- 未修改种子、未执行 `make seed`。
