# 跨模块引用式指针常量实参（接口追链重放）

日期：2026-10-07。状态：已完成。承接第 40 轮 todo 里留下的「非字面量初始化指针常量」一条。

## 背景

第 40 轮让跨模块 `$mod.f(...)` 接受「以字符串字面量初始化的 `pub const` 指针常量」，
而 `pub const A *char = B;`（初始化式是**另一个常量名**）当时仍拒绝，原因是接口的
`F_ADDR` 分支只重放 `const_expr_kind == 2`（**单个 `TOK_STRING`** 的初始化式）。

## 本轮探针（先摸边界）

| 探针 | 写法 | 结果 |
| --- | --- | --- |
| D | `$weigh($make(1, 2))` 顶层聚合结果再作实参 | `rc=0` 可用 |
| E | `$weigh(Point{ x: 3, y: $two() })` 字面量字段值来自 CT 调用 | `rc=0` 可用 |
| F | `const P Point = $make(3, 4);` 顶层 const 聚合接收 CT 结果 | `rc=0` 可用 |
| G | CT 正文里 `len(a)` 与切片视图 `a[0..3]` | `rc=0` 可用 |

（切片语法是 `[start..end]`，不是 `[start:end]`。）

## 改动（两处，对称设计）

**① 记录引用**：`compiler/parse/parse_global_init.yh` 在 `TOK_STRING` 的 kind 2 旁边，
新增对称的 **kind 3** —— 指针常量的初始化式是**单个 `TOK_IDENT`** 时，记下该标识符
（`const_expr_off/len`），供接口追链。

**② 追一层链**：`compiler/parse/iface.yh` 的 `F_ADDR` 分支，`const_expr_kind == 3` 时用
`gen.sym_lookup_off(lit_off, lit_len)` 找被引用的常量，若它是 `SYM_CONST + F_ADDR +
const_expr_kind == 2`，就重放**它**的字面式；否则维持原诊断。

关键理由：消费者看不到提供方的私有常量名（`TEXT_ALIAS_BASE` 并不导出），重放引用本身会在导入
侧解析失败，所以必须重放到最终字面式。

```yh
if (gs.c_syms[si2].const_expr_kind == 3) {
    let src_sym int = gen.sym_lookup_off(lit_off, lit_len);
    if (src_sym >= 0 && ... && gs.c_syms[src_sym].const_expr_kind == 2) {
        lit_off = gs.c_syms[src_sym].const_expr_off;
        lit_len = gs.c_syms[src_sym].const_expr_len;
    } else {
        return gen.sem_err("pub 指针常量（字符串）暂不支持跨模块导出");
    }
} else if (gs.c_syms[si2].const_expr_kind != 2) { ... }
```

## 效果

| 写法 | 之前 | 现在 |
| --- | --- | --- |
| `pub const A *char = "hi";`（字面式，跨模块） | 可用 | 可用 |
| `pub const A *char = B;`（引用式，B 是私有字面式常量，跨模块） | **拒绝** | **可用**（接口重放 `"hi"`） |
| `A = B` 且 B 也是引用（两级链） | 拒绝 | 仍拒绝（只追一层） |
| `= base.TEXT`（跨子模块限定名） | 拒绝 | 仍拒绝（名字池里不是裸名） |
