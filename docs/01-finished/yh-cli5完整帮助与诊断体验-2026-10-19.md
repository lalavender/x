# yh CLI5：完整帮助与诊断体验（2026-10-19）

计划见[实施方案](../02-plan/yh-cli标准库实施方案.md)的 CLI5，
接口语义见 [cli 设计](../03-design/yh-cli标准库设计.md) 第 14 节。

## 目标

把 CLI1 起的基础帮助升级为设计要求的完整体验：正交的 `HelpFormat`、
固定段落顺序、互斥组与子命令的 usage 表达、默认值/choices/deprecated 展示、
控制字节与非法 UTF-8 转义、颜色策略与终端降级、有限建议，
以及 `print_usage`/`print_help`/`render`/`exit_code` 输出 API。

## 已实现的行为

- **布局**：固定顺序 usage → description → positional arguments → options →
  用户组 → commands → epilog；空段省略，段内按注册顺序。
- **usage**：可选片段 `[...]`、required 选项不加括号、互斥组 `[a | b]` 或
  `(a | b)`（required 组用圆括号）、可变数量后缀 `...`、子命令槽
  `[COMMAND]`/`COMMAND`。
- **占位名**：显式 `metavar` 优先；`metavar_from_type` 时按值类型推导
  （INT/UINT/FLOAT/BOOL），否则用 dest；`metavars` 供 exactly(n) 使用。
- **说明与标注**：按 `width` 折行（`max_help_column` 可覆盖起始列上限）、
  `show_defaults` 追加 `(default: x)`、choices 追加 `(choices: a, b)`、
  `deprecated` 追加 `(deprecated)`；hidden 参数不出现在 usage/help，但继续参与匹配。
- **转义**：说明与默认值中的控制字节、非法 UTF-8 字节输出为 `\xHH`；
  折行按字节宽度近似（合法 UTF-8 序列不拆开）。
- **颜色**：`Color.never` 无色、`Color.always` 强制 ANSI、`Color.automatic`
  用 `os.is_terminal` 检测，失败或非终端时无色降级；当前用于 `usage:` 前缀与段标题。
- **建议**：`suggest_on_error` 打开时，未知选项在编辑距离 ≤ 2 的长名称里给最优候选，
  诊断消息追加「是否想用 --xxx？」；没有候选时保持原消息。
- **输出 API**：`format_usage`/`format_help`/`release_text`/`render_text`、
  `print_usage`/`print_help`（写 fd，失败 -1）、`render(result, out_fd, error_fd)`
  （控制文本 → out_fd，诊断与 usage → error_fd，不退出不释放）、
  `exit_code`（ok/help/version→0、usage_error→2、config/resource→1）。
- **失败结果自足**：解析失败时结果自带 `usage_text` 与 `prog_text`，
  `render` 不依赖 parser 仍能输出。

## 本版本限制

- `warnings` 通道未实现（设计里 `render` 的 warnings 输出留待后续）。
- 折行按字节宽度近似，中文等宽字符不保证等于终端列宽（设计已声明不作为硬依赖）。
- 颜色目前只用于 `usage:` 前缀与段标题，未做逐字段着色。
- `Color.automatic` 的终端检测基于 `isatty`，失败时按无色处理。
