# yh 编译期 `$if` 输出目标标记

日期：2026-10-05。状态：**首版目标标记切片完成；CT0 其他条目仍待办**。

## 交付

- `$if` 条件中的 `linux`、`darwin`、`arm64` 由 `compiler/comptime/ct_target.yh`
  解析为布尔常量。操作系统标记读取当前输出方言（包括 `-target`），不读取编译器
  宿主；当前后端支持 AArch64，因此 `arm64` 为真。
- 标记只在 `$if` 条件中有内建含义，不加入保留字。同名局部变量在 `$if` 条件里
  不能遮蔽标记，在条件之外仍然按普通 yh 名称解析。解析器通过 `GenState` 的
  临时上下文位限定该行为，表达式结束后恢复原值。
- 为支持设计文档中的组合目标条件，常量折叠路径现在能合并 `&&` 与 `||` 的布尔结果；
  运行期短路发射路径保持原样。
- `tests/yh-run/run/58-comptime-target.yh` 覆盖 `linux/darwin/arm64` 组合、OS 标记
  互斥和同名普通局部变量。目标程序在 Darwin/arm64 返回 0，并分别以 Linux 与 Darwin
  输出方言通过汇编生成。
