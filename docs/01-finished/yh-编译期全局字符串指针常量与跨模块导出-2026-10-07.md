# 编译期全局字符串指针常量与跨模块导出

日期：2026-10-07。状态：已完成。方案：[yh-编译期全局字符串指针常量与跨模块导出实施方案](../02-plan/yh-编译期全局字符串指针常量与跨模块导出实施方案.md)。

## 背景

字符串字面量指针常量的只读字节池此前只在函数体内的字面量上登记，因此
`const TEXT *char = "abc";` 在编译期函数里引用报「编译期求值不支持指针常量」，
`pub const TEXT *char = "..."` 报「pub 指针常量（字符串）暂不支持跨模块导出」，
顶层实参 `$f(TEXT)` 因值是数据标签号而通不过形参校验。

## 改动

| 位置 | 改动 |
| --- | --- |
| `comptime/ct_00_model.yh` | `CtPoolSpan` 增加来源键 `key`（函数体字面量用源字节起点，全局常量用 `-(intern 偏移 + 1)`） |
| `comptime/ct_ir.yh` | `ct_pool_register` 增加键参数与查重复用；`SYM_CONST` + `F_ADDR` 分支按 `const_expr_off/len` 的原样字节登记池并返回池地址（非字符串指针常量保持原诊断）；新增 `ct_pool_elem_of` 与 `ct_pool_adopt_label` |
| `comptime/ct_registry.yh` | 调用入口对实参副本做 `ct_pool_adopt_label`：值仍是数据标签号的字符串指针常量按 `cval == value && F_ADDR && const_expr_kind == 2` 反查并换成池地址 |
| `parse/iface.yh` | `F_ADDR` 且 `const_expr_kind == 2` 的常量在接口里**原样重放**声明（`pub const NAME <type> = "原样字节";`），导入方走与用户源码相同的登记路径 |

池段复用是必需的：循环里反复引用同一常量会不断登记新段，64 段上限很快耗尽。

## 边界

- 只支持元素为 `char`/`u8`/`i8` 的指针常量；`*u8` 由字符串字面量初始化本身不合法
  （`*char` 不隐式转 `*u8`），实际可用形态是 `*char`。
- 直接写字的顶层实参（`$f("abc")`）仍不支持：字面量实参不产生符号，无法按标签号反查。
  函数体内构造字面量再按形参传递是支持路径。
- 非字符串指针常量（全局数组地址等）仍拒绝，诊断不变。
