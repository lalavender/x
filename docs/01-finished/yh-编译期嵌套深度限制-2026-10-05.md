# yh 编译期结构嵌套深度限制

日期：2026-10-05

`$if` 与 `$for` 共用最多 32 层结构嵌套限制。超过上限时，编译器在当前过深的
编译期控制语句处报告“编译期结构嵌套超过 32 层”。计数器位于 `comptime` 模块，
每次编译单元重置；两个解析入口都在返回前恢复深度，避免解析或语义错误污染后续状态。

新增运行语料覆盖 32 层可编译并返回、33 层 `$if` 被拒绝，以及空 `$for` 中再嵌套
32 层 `$if` 时按混合总深度拒绝。后者也验证未展开分支仍受解析递归深度保护。

实现文件：

- `compiler/comptime/ct_00_model.yh`
- `compiler/comptime/ct_registry.yh`
- `compiler/parse/parse_comptime.yh`
- `tests/yh-run/run/62-comptime-control-depth-limit.yh`

- `tests/yh-run/fail/81-comptime-for-control-depth.yh`
