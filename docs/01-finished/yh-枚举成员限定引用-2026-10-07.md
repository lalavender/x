# 枚举成员限定引用 EnumName.member

日期：2026-10-07。状态：已完成。

## 缺口

枚举成员只能用**裸名**引用，限定写法在任意位置都报「引用了未声明的名字」：

```yh
pub enum Palette { red; green = 7; }

const TOP int = Palette.green;      // 错误: 引用了未声明的名字
fn main() int { let v int = Palette.green; ... }   // 同上
```

根因：`Palette` 是**类型名**，符号表里没有对应的值符号（符号表只有
`SYM_VAR`/`SYM_CONST`/`SYM_FN`），标识符解析按值名查找失败即报错，`EnumName.member`
这种「类型名限定」写法没有解析路径。裸名可用只是因为没有同名冲突时成员常量恰好能被
裸名查到。

## 实现

`compiler/parse/parse_expr.yh` 的标识符解析：在模块限定名分支之前加枚举成员分支 ——

- 条件是 `标识符 . 标识符`，且基名**不是**任何符号（词法作用域优先，局部变量遮蔽时
  保持原路径）；
- 用 `ty_lookup_name` 查基名，命中且类型种类是 `TY_ENUM` 时，用成员名查符号表；
- 成员必须是 `F_ENUM_MEMBER`、`const_ready`、且 `type_id` 等于该枚举类型（避免不同枚举
  的同名成员串味）；
- 命中则消费 `Name` `.` `member` 三个 token 并走 `sem_ident_val`，与裸名引用完全同路径。

## 边界

- 基名被局部/全局符号占用时不走该分支（词法作用域优先）。
- 成员名必须是该枚举的成员；否则回落到原来的「引用了未声明的名字」。
- 枚举成员仍不被 `const` 复合初始化等聚合场景接受（语言层面的既有边界）。
