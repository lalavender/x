# yh test 编译器内嵌测试（YT3b）实施记录

日期：2026-10-23。范围：滚宿主种子、给 `compiler/` 模块加内建 test 块、新增
`make test-compiler-tests` 门禁。剩余 YT2d（并行/日志/缓存键）与 YT1.1
（项目外单文件）未实施。

## 滚种子（前置条件）

- 旧种子不认识 `test` 语法，`make` 会用种子冷编 `compiler/`，因此在
  `compiler/` 写 test 块之前必须先让种子支持该语法。
- 本机在 `make test` 与 `make selfhost-native` 全绿后执行 `make seed`，
  把本代 `yh` 写入 `bin/yh-darwin-arm64` 并更新哈希。按仓库规则种子不入库，
  所以这一步只影响构建机；其他机器需按 rc/tag 流程产出带 test 语法支持的种子。
- 加入 test 块后又滚了一次种子，并用新种子重新 `make` 与跑两大主门，确认
  冷编、固定点与全部语料仍然通过（最终种子 SHA-256
  `379a1edb9e97044494c84887c61e8224f7b7c9064b44dec3b90f905ab0654f0e`）。

## 内嵌测试

| 模块 / 文件 | 用例 |
| --- | --- |
| `gen/buffer.yh` | `hexval` 十进制与十六进制；`is_assign_op` 边界 |
| `lex/layout.yh` | `lex_can_end` 可/不可结束语句；点号后放行成员名 |
| `parse/parse_type.yh` | `is_member_name` 放行/拒绝集合；`is_type_start` |

测试体可以直接调用同模块的私有函数（`is_member_name`、`lex_can_end` 等），
不需要为了测试扩大 `pub` 导出面。

## 门禁

- 新增 `tools/compiler-tests.py`
  - 按宿主选择 `tools/llvm-darwin-host.py` / `tools/llvm-host.py` 的 `shim`
    记录，准备 `PATH`（shim 目录）、`YH_CC`、`YH_LLVM_SELFHOST=1`、
    `YH_LLVM_SELFHOST_FLAGS`，Darwin 另补 `SDKROOT`；
  - 逐模块执行 `yh test <模块> --timeout 120`，要求退出码 0 且输出含
    `结果: … 0 failed`；
  - 缺省模块 `gen lex parse`，可用 `--modules` 覆盖。
- 新 make 目标 `test-compiler-tests`，并接入 `make test` 与
  `make selfhost-native`。

测试二进制需要与编译器相同的自举链接闭包；工具复用 seed-build 的 shim 记录，
避免在 Makefile 里重复闭包路径（Zig 式：闭包属于构建环境，不烘焙进种子）。

## 验证

- `make test`：`PASS compiler-tests/gen: 结果: 2 passed; 0 skipped; 0 failed`、
  `lex: 3/3`、`parse: 3/3`，`compiler-tests: 通过 3/3`；其余门全绿
  （语法 81/81、49/49；run 211/212；fail 136/136；pass 9/9；test-check 27/27；
  string 内建 5/5；TOML 6/6；代码统计 6/6）。
- `make selfhost-native`：模块固定点一致、cc4 自解析 114 个源文件、
  project cases 121/121、compiler-tests 3/3。
- 生产隔离：`compiler/.build/.../obj/*.o` 与 `iface/*.s.i` 中
  `__yh_test_` 符号数为 0，说明测试体没有进入生产输出与模块接口。

## 边界

- 种子滚动只在本机完成；其他平台/机器需发布带 test 语法支持的种子后，
  才能在 `compiler/` 添加新的 test 块。
- 只给三个纯函数模块加了测试；其余模块按需追加，并把模块名加进
  `tools/compiler-tests.py` 的默认列表（或 `--modules`）。
- YT2d（并行执行、逐例日志文件、测试缓存键隔离、超长消息提示）与
  YT1.1（项目外单文件）仍未实施。
