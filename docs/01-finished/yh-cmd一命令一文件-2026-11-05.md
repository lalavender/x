# yh-cmd一命令一文件-2026-11-05

## 概述

P1 阶段（docs/03-design/yh-模块架构目标设计-2026-11-05.md §4）落地：`cmd/`
从「driver + api 两文件混合分派与实现」重组为**一命令一文件**，共 10 个文件，
`api.yh` 删除。无行为变化，cmd 模块导出面收缩为只有 `main`。

## 变更清单

| 文件 | 内容 |
|------|------|
| `cmd/driver.yh` | 只剩 `main`：会话前奏调用、内部子进程协议识别（`--emit-module` 上界 23 项、`--lld-link`）、全局选项落状态、按命令一行分派；req 生命周期归 driver 统一释放 |
| `cmd/common.yh`（新） | 退出码契约注释、`API_*` 五形态常量、`cmd_session_init`（state_init → proj.init → bind_cfg → argv0 → envp 的固定次序）、`api_open_source` 单文件共用前奏 |
| `cmd/cmd_build.yh`（新） | `yh build` / `yh check`（项目态共享实现，`c_check_only` 置位迁入，rc==2 补印用法迁入） |
| `cmd/cmd_run.yh`（新） | `yh run` |
| `cmd/cmd_test.yh`（新） | `yh test`；`--timeout` 1..3600 校验自 driver 迁入 |
| `cmd/cmd_list.yh`（新） | `yh list` |
| `cmd/cmd_version.yh`（新） | `yh version` / `--contracts` |
| `cmd/cmd_single.yh`（新） | 单文件五形态（--syntax-check / --emit-asm / --emit-llvm / -o exe / check 源文件）；形态选择自 driver 迁入 |
| `cmd/cmd_emit_module.yh`（新） | 内部子进程协议 `--emit-module`，选项解析原样迁移 |
| `cmd/cmd_lld_link.yh`（新） | 内部子进程协议 `--lld-link` 薄壳 |
| `cmd/api.yh` | 删除 |

`api_*` 全部转模块私有（无 `pub`），新增命令 = 新增一个 `cmd_<命令>.yh` +
driver 一行分派 + cmdline 声明。

## 预算

`tools/arch-check.py` `max_module_lines` 387 → 458：增量 71 行全部为 9 个新
文件的头注释（每文件保留完整契约说明），逻辑行数不变；依赖边 55 条不变；
main 占比仍 1%。

## 验证

- Windows/x64 本机冷编通过；`yh --syntax-check` / 单文件编译链接运行
  （examples/main.yh → `Hello, World!`）/ `yh check`（examples/os-demo-explicit）/
  `yh version` 冒烟全通过。
- `just test` 全量门禁在本机执行（含 testkit 全语料 + build-cache 验收）。
- 后续按设计文档 §9 由 `just selfhost-native` + 固定点 + seed 收口。
