# yh test 执行器与结果协议（YT2b）实施记录

日期：2026-10-23。范围：测试入口模块生成、测试二进制链接、逐例 fork/exec、
结果协议与汇总。执行过滤、`testing.fail/skip`、`--timeout` 与断言消息报告
仍属 YT2c，未实现。

## 交付

- `compiler/cmd/test_cmd.yh`
  - 每个含测试的模块生成入口模块 `yh_test_<mod>`，写入
    `<root>/tmp/yh-test/gen/<mod>/entry.yh` 并用 `pj_index_file` 登记到项目
    （每模块独占目录，避免「每目录一个模块」冲突）；入口模块 import 被测
    模块，`main(argc, argv)` 按 `argv[1][0] - 'a'` 选择用例；
  - 用例号只在本模块内编码，顺序与 `--list` 一致；
  - 入口模块在调用测试函数并正常返回后写 4 字节 `YHTP` 到 fd 3；
  - 逐例 fork/exec：父进程打开记录文件（必要时 `dup2` 到 fd 3），
    等待子进程，读取记录并结合退出码判定；
  - 判定规则：退出码 0 且记录为 `YHTP` → PASS；`YHTF + line + col` 或
    非零退出 → FAIL 并打印「断言位置: 行:列」；记录缺失/损坏、崩溃 → FAIL
    并标注「用例崩溃、超时或缺少结果记录」；无论失败与否都继续后续用例；
  - 汇总 `结果: N passed; M failed`，失败时命令退出码 1；
  - `--no-run` 保持只构建（输出「--no-run，未执行」）。
- `compiler/backend/llvm_runtime.yh`
  - 发射 `__yh_test_assert` 弱定义：条件为假时向 fd 3 写 12 字节
    `'Y''H''T''F' + line(int32) + col(int32)`（小端）并 `exit(1)`，条件为真
    直接返回；
  - 只在模块未引用 `write`/`exit` 时补 `declare`，避免与用户调用重复声明；
  - `llvm_runtime_supplies_symbol` 与 `llvm.used` 同步，O0/O2 都保留。
- 语料：新增 `tests/modules/projects/ytestfail`（通过、断言失败、提前
  `exit(0)`、空指针崩溃、失败后继续执行），`tests/modules/test-check.py`
  增至 23 条断言（`execute-pass`、`execute-fail`、
  `execute-fail-early-exit-and-crash`、`no-run-does-not-execute`）。

## 验证

- `ytest`：8/8 PASS，`结果: 8 passed; 0 failed`，退出码 0。
- `ytestfail`：`结果: 2 passed; 3 failed`，退出码 1；输出含
  `断言位置: 12:5`，提前 `exit(0)` 与崩溃均判 FAIL，
  `test "失败后继续执行"` 仍 PASS。
- `make test`：语法 81/81、49/49；run 211/212、fail 136/136、pass 9/9；
  `test-check` 23/23；TOML 6/6；代码统计 6/6。
- `make selfhost-native`：模块固定点一致、cc4 自解析 114 个源文件、
  project cases 121/121 全绿。
