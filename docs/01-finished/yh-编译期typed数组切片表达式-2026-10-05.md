# yh 编译期 typed 数组/切片表达式完成记录

日期：2026-10-05。

## 结果

编译期函数现在可用 `base[start..end]` 从本地整型数组或切片创建左闭右开的切片视图。视图共享原有元素存储；对嵌套视图写入可修改原始数组。有效边界要求 `0 <= start,end <= len`；反向范围得到长度为零的视图。视图可继续用于 for-in、下标读取与写入。

`CtAggregate.owned` 区分拥有元素存储的数组/切片与仅保存偏移指针的视图。调用帧按创建链清理头节点，只释放自有元素区，确保嵌套视图不会重复释放底层存储。实现位于 `compiler/comptime/ct_ir.yh`、`ct_ir_place.yh` 和 `ct_00_model.yh`。
