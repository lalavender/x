# yh 编译期 typed 浮点聚合元素

## 交付内容

- 浮点聚合元素在编译期可用：定长数组元素（`[3]f64`）、切片元素（`[]f64`）、
  结构体浮点字段（含嵌套数组字段）都可构造、下标读写、切片视图别名写回、
  for-in 迭代、作为聚合形参与返回值，并可静态物化为顶层常量。
- 支持门放宽：`ct_ir_array_supported`、`ct_ir_slice_elem_supported`、
  `ct_ir_struct_field_supported` 从「整数叶」放宽为「整数或浮点叶」。
- 新增 `ct_ir_norm_scalar`（浮点按宽度窄化、整数按宽度与符号截断），统一替换
  元素克隆、字段写入、数组元素写入、局部声明与赋值路径里的 `sem_fold_norm`。
- 静态物化：`ct_ir_data_value` 增加浮点分支，f64 直接发位模式，f32 经
  `ct_ir_fp32_bits` 取单精度位模式（内部按 f64 位模式保存）。
- 诊断文本从「整数」改为「整数、浮点」（数组字面量、切片、结构体字段、comptime 形参），
  既有 `fail-contains` 前缀子串保持匹配。
- 用例：`tests/yh-run/run/136-comptime-float-aggregate.yh`；`fail/137` 改为浮点元素
  取址仍拒绝，`fail/103`、`fail/105`、`fail/129` 改为指针元素数组/切片字段与指针元素
  切片返回仍拒绝；`comptimelocal` 增加浮点数组形参、浮点切片返回与顶层浮点切片物化断言。

## 边界

- 仍拒绝：指针元素数组/切片、指针叶结构体字段、浮点元素取址（`&values[0]` 仍报
  「整数局部变量或整数聚合元素」）、浮点指针形参（`*f64`）、联合体。
- const 初始化不能直接以数组字面量作编译期实参（前端折叠限制），需在编译期函数体内
  构造后传入。
