# yh LLVM LL5 聚合首片：局部定长数组（2026-10-15）

**状态：**局部定长数组切片完成并验收；结构体/联合体/切片、全局数据与聚合
参数/返回按后续切片推进，LLVM 默认未切换、种子未滚。

## 1. 范围

- 局部定长数组绑定（标量或嵌套数组元素）一律 ALLOCA 字节存储；
- 数组字面量 `[a, b, c]`（含嵌套 `[[...], [...]]`）逐元素初始化；
- 下标读写 `a[i]`（含 `+=` 等复合赋值）与取元素地址 `&a[i]`；
- 按值复制 `let b = a;` / `b = a;`（llvm.memcpy，落到同对象 memcpy 弱定义）；
- 循环内数组字面量写入绑定存储（不产生每轮 alloca）。

不在此片：结构体/联合体/切片、全局/字符串/CT 数据、聚合参数与返回（LL7）、
越界检查与对齐证明。

## 2. IR 与后端

新增三条指令（`compiler/ir/ssa.yh`）：

| 指令 | 编码 | 语义 |
| --- | --- | --- |
| `IR_OP_ALLOCA` | `imm`=字节数、`aux`=对齐 | 局部字节存储，结果指针 |
| `IR_OP_GEP` | `a`=基指针、`b`=动态 u64 偏移（`b<0` 用常量 `imm`） | 字节偏移寻址 |
| `IR_OP_MEMCPY` | `a`=目的、`b`=源、`imm`=字节数 | 聚合复制，无结果 |

- verifier：ALLOCA 正 size/align；GEP 基址必须是指针、动态偏移必须 u64；
  MEMCPY 两个指针与正字节数、无结果；函数/模块 verifier 与序列化均按既有
  通用字段路径通过；
- LLVM 发射：`alloca i8, i64 N, align A`、`getelementptr i8`、
  `call void @llvm.memcpy.p0.p0.i64(...)`（LLVM 自动声明内建，最终落到
  LL8a 的弱 `memcpy` 或 libc）。

## 3. Lowering（`compiler/ast/checked_module_lower.yh`）

- 聚合绑定在入口按源布局发 ALLOCA（结构体/联合体暂拒，带来源诊断）；
- `checked_lower_lvalue_ptr`：变量存储、`*p`、`a[i]`（常量/动态偏移，步长取
  所选元素类型大小）统一求出元素存储指针；标量结果指针带 canonical 元素类型，
  聚合结果用不透明指针；
- `checked_lower_array_literal`：按源码顺序逐元素写；标量元素 GEP 结果必须
  是**指向该标量的 canonical 指针**（否则 STORE 过不了 verifier），嵌套数组
  递归写入；
- `checked_lower_aggregate_store`：字面量 → 逐元素写；变量/左值 → MEMCPY；
  先剥掉 PRIMARY 括号包装；
- `let`/赋值：聚合绑定走上述存储路径，标量路径不变；赋值左值分类扩展
  `a[i]`（含复合赋值）；
- `&a[i]`：UNARY AMP 扩展 INDEX/MEMBER/`*p` 分支。
