# yh 字符串插值 I0–I3 实施记录（2026-10-24）

## 交付

- **词法扩展**（`compiler/lex/interp.yh`）：普通 `TOK_STRING` 在
  `lex_layout` 前被重写为内部 token 序列
  `INTERP_BEGIN TEXT? (EXPR_BEGIN expr EXPR_END SPEC? TEXT?)* INTERP_END`；
  表达式 token 仍写回同一 token 表，AST 区间/快照不出现游离 token。
  新增内部 kind 200–205，用户源码不可写出。
- **raw-string 数据**（`gen/state.yh`、`gen/sem_value.yh`、快照）：
  `data_str_add_body` 把不含引号的源码区间 intern 进名字池，`quoted=2`
  让解码器处理转义但不剥引号；`sem_raw_string` 登记文本块/说明符。
- **解析与降级**（`compiler/parse/parse_interp.yh`）：parser 直接合成
  `fmt.text` / `fmt.value` / `fmt.value_spec` / `fmt.concat` 调用树，
  不新增 AST kind；按 `Res.type_id` 选择 `fmt.of_i64/of_u64/of_f64/
  of_bool/of_cstr` 并插入必要 cast。
- **编译期 spec 校验**：flags/width/precision/type 与静态类型兼容性在
  parser 内检查；非法 spec 在源码位置报错。
- **转义**：`$` 加入字符串转义集合，`\$` → `$`；`\$` 不会被识别为插值
  起点，`\${x}` 输出字面 `${x}`。
- **fmt 运行时契约**：`text/value/value_spec/concat`（`60_interp.yh`），
  `concat` 消费输入并返回合并 String。

## 已知边界

- 首版要求 `import fmt`（默认绑定名，`as` 别名未接通）与 `import string`。
- 支持整数、f64/f32、bool、`*char`；enum 按有符号整数；`string.View`/
  `string.String`、结构体/数组/切片不支持。
- 单行；`${}` 内不允许裸双引号（外层字符串会先终止）、花括号、顶层
  三元（需括号）；不允许嵌套插值；文本块内嵌 NUL 不支持。
- 旧发射器路径与 O2 的专项用例尚未单列；I4 收口处理。
- 未跑全量 `make selfhost-native`、未滚种子、未合并。
