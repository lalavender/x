# ADR-0016：yh 项目库文件分组链接

日期：2026-10-20；修订：2026-10-21。状态：**普通项目与编译器自举闭包迁移已实施**。

## 背景

用户要求 `project.toml` 的 `[link]` 写具体库文件，由 `yh build` / `yh run`
自动链入最终二进制；文件必须按目标平台选择，不能只支持 `.a`。

## 决策

- `[project]` 新增必填 `os` / `arch`：
  `linux|darwin|host`、`arm64|x64|host`；`host` 表示跟随编译器宿主平台。
  显式 `--target` 覆盖项目默认目标。
- `[link]` 是命名组，值是具体库文件路径字符串数组；相对路径基于
  `project.toml`，允许绝对路径，读取时规范化为 realpath。
- 只有根项目的 `[link]` 生效；依赖项目忽略。
- `[link-<os>-<arch>]` 只允许四个当前平台组合；同名组替换公共组并保持位置，
  新组追加；其他 `link-*` 节名报错。
- 默认链接全部有效组；`--link` 可重复，只选点名组，按首次出现顺序。
- 链接顺序为对象 → `[link]` 库 → `[c].libs` → 系统库；ELF 选中库放在
  同一个 `--start-group`，Darwin 按声明顺序。
- `.a` 默认按需加载；可选 `[link-options] whole` 指定整库加载（自举桥必须
  whole）；`.so` / `.dylib` 为动态链接；`.tbd` 为 Darwin 链接期 stub。
- `yh run` 临时把共享库目录加入子进程运行时搜索路径；不写 rpath。
- 只检查最终选中组；`check` / `list` 只校验 schema。库文件和摘要采用
  `.build` manifest 的 `mtime/size + 内容摘要` 快路径。
- 编译器自举闭包（F1）已迁移：归档进入 `[link]`，运行库参数经
  `YH_LINK_RUNTIME_FLAGS` 由构建机提供；新编译器 manifest-only，不再追加
  旧归档。

## 后果

`project.toml` 多两个必填字段；依赖项目也必须写平台。公共项目用 `host`
保持仓库在 Linux/macOS 双平台可构建。`[link]` 输入进入链接缓存键，不进入
模块编译键；选择和库内容变化只重链。

完整格式、诊断、缓存和自举迁移步骤见
[实施方案](../02-plan/yh-project-link静态库实施方案.md)。
