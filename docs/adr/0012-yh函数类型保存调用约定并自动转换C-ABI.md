# ADR-0012：函数类型保存调用约定并自动转换 C ABI

- 状态：已采纳
- 日期：2026-10-03

## 背景

只给符号添加 C ABI 标记无法正确处理回调变量、字段、函数指针返回和模块接口。
yh 聚合在函数体内以地址表示，C 的小聚合/HFA/大聚合采用不同的寄存器与栈
规则；直接使用 yh 调用路径会产生错误的机器接口。

## 决策

函数签名保存 ABI_YH 或 ABI_C，并参与类型去重、相容检查、接口、IR 与缓存。
`@[extern]` 函数按目标 C ABI 声明、定义和调用；extern 签名与 extern
struct/union 字段中的函数类型默认 C ABI。普通上下文以
`@[extern] fn(...)` 表示 C 函数指针，不引入其他类型属性。C/yh 函数类型
不能互赋或通过函数类型转换改变调用约定。

采用共享的 AArch64 参数/返回分类器，接收显式值描述与目标游标。直接发射的
调用方、入口、返回以及 SSA 整数路径消费同一套分类规则。HFA 先于普通大聚合
分类；普通小聚合与 HFA 不拆分到寄存器和栈；大聚合使用调用方独立副本，返回
地址使用 x8。Linux 与 Darwin 分别使用八字节槽和自然大小栈布局。

聚合在 yh 函数体内保持地址表示，仅在 C 边界转换。SSA 未覆盖的浮点、聚合和
间接调用回退到已有直接发射路径。固定参数互操作由独立 C 编译器双向验证，
无需手写 C 适配函数或 libffi。IR 序列化升级为 5，前端缓存键升级为 10。

## 后果

支持现有 C 标量、函数指针以及非空 extern struct/union 按值参数和返回值。
数组仅允许嵌入共享聚合，切片、顶层按值数组、不透明值、普通 yh 聚合、C
变参及尚未表达的 C 类型继续拒绝。原型与布局须由用户准确声明，所有权不由
extern 推断。普通 yh ABI 与运行时 printf 保持既有规则。

[实施方案](../02-plan/yh-extern自动C-ABI实施方案.md)。本决策扩展 ADR-0010
的固定参数边界，不改变其声明属性、符号可见性和 noreturn 契约。
