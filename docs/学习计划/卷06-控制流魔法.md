# 卷06 · 稍后再填的信

> **本卷目标**：掌握控制流的终极魔法——**回填（backpatch）**。学完后
> if/while/for/goto/&&/||/switch 在你眼里全是同一招的排列组合。
> **预计**：6 篇，约 1 周。

写 if 的时候，"跳到 else"的那个目标地址还没编译出来呢，怎么办？
答案：**先写"跳到 0"，把这条指令的位置记在小本本上；等目标出现了，
回头把那 4 个字节改成真地址**。小本本叫"跳转链"，回头改叫 `gsym()`。
这一招叫"寄一封地址留白的信"，TCC 的控制流全靠它。

---

## 6.1 gjmp 和 gsym：写信、寄信、贴地址

- **教什么**：
  - `gjmp(t)`：发一条 `jmp ???`（占位 5 字节：`E9 <4字节>`），返回"这条信的位置"（编成 t 链表头）；
  - `gsym(a)`：目标 `a` 终于知道了——把 a 地址写进那 4 字节，顺藤摸到链上下一封信，继续改。
  链表的"下一封"记哪？记在**信自己的 4 字节里**（先写旧链头当 next）——绝不绝？
- **你要写出**：`gjmp/gsym/gjmp_addr` 三函数 + `ind`（当前写地址）。
- **通关暗号**：`./mcc "{ goto l; x=1; l: ; }" --dump`，反汇编里两条 jmp 目标都正确。
- **TCC 对照**：`src/core/i386-gen.c:675` `gjmp()` 与 `:690` 的 `gsym()` 循环——
  信里藏链表的写法一模一样（`((int *) (ind - 4))[0] = (t-1) - (ind-4)`）。

## 6.2 if / else

- **教什么**：`if(c) A else B` 的组装流程：编译 c → `a=gvtst(1,0)`（假就跳，得链头）
  → 编译 A → `d=gjmp(0)`（跳过 B）→ `gsym(a)`（A 的出口贴到 else 入口）
  → 编译 B → `gsym(d)`。**两个链头变量 a/d 就是全部。**
  彩蛋：`if(1)` 这种编译期已知真假？直接**跳过整个 else 的编译**（`nocode_wanted` 开关），
  一行码都不发。
- **通关暗号**：`./mcc "int x; x=0; if(5>3) x=1; else x=2; x;"` → `CPU 说: 1`；
  且 `--dump` 里没有 else 分支的代码。
- **TCC 对照**：`src/core/tccgen.c:5891-5920` `block()` 的 TOK_IF 分支 +
  `condition_3way()`/`nocode_wanted`。

## 6.3 while / for / do / break / continue

- **教什么**：
  - `while(c) B`：`d=ind`（记住循环头）→ 编译 c → `a=gvtst(1,0)` → 编译 B →
    `gjmp_addr(d)`（回跳）→ `gsym(a)`（出口）；
  - `break/continue`：本质还是信——只是收信地址在**外层**。
    所以每个循环块把两个 `int*`（bsym/csym 链头）当参数传进去，
    语句级递归时层层传递，块结束时把整条链"上交"给外层。
  - `for(init;c;inc)B`：你自己在 while 前面和循环尾各补一笔。
- **通关暗号**：`./mcc "int i,s; s=0; for(i=1;i<=10;i++){ if(i==7) continue; s+=i; } s;"` → `CPU 说: 48`。
- **TCC 对照**：`src/core/tccgen.c:5921-5940`（while）和整个 `block()` 的签名
  `block(int *bsym, int *csym, int is_expr)`——就是那两个链头参数。

## 6.4 && 和 ||：值栈上的"纸牌屋"

- **教什么**：`a && b`：a 为 0 就跳去写 0，b 为 0 也跳去写 0，否则写 1——
  **真/假各有自己的一条 jmp 链**，结果 = "真链 + 假链"。
  TCC 用 `VT_JMP`（偶）/`VT_JMPI`（奇）编码：一张便利贴同时装两条链（奇偶位=选链）。
  短路求值 = 只编译一条链。
- **你要写出**：`expr_and/expr_or`（优先级链里插两层）+ `gvtst(inv,t)`（比较完转跳）。
- **通关暗号**：`./mcc "int f(){return 1;} (0 && f()) ; (1 || f());"`——
  反汇编里 `f` 一次都没被调用（短路）。
- **TCC 对照**：`src/core/tccgen.c:1605` `gvtst()`、`VT_JMP/VT_JMPI` 用法遍布 `unary()` 的 `!`。

## 6.5 switch / goto / 标签

- **教什么**：switch 的 TCC 做法——不建跳转表，生成一串 `cmp/jeq 下一case`
  （线性扫描），case 标签也是信（`Sym.c.jnext` 链），default 放最后兜底。
  `goto`：查标签栈（在函数内），找不到就 forward 登记，函数编译完统一 `gsym_addr` 结清。
- **你要写出**：`gcase()` + `label_push/label_pop` + `TOK_GOTO`。
- **通关暗号**：经典 FizzBuzz 用 switch(i%15) 写；`./mcc --run` 前 16 行输出正确。
- **TCC 对照**：`src/core/tccgen.c:5816` `gcase()`、标签处理在 `block()` 的 `{` 分支
  和 `unary()` 的 TOK_IDENTIFIER+冒号歧义（`unget_tok` 妙用）。
