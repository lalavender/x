# 卷09 · 把积木拼起来

> **本卷目标**：链接器。合并多个 .o、解符号冲突、定地址、按欠条"贴邮票"，
> 产出可执行文件；再理解"动态库/GOT/PLT"到底在干嘛。
> **预计**：5 篇，约 1 周。

编译器和链接器是两兄弟，分工明确：
编译器**只懂一个文件**，遇到不认识的名字就**记欠条**；
链接器**懂所有文件**，把欠条一张张兑掉。
你现在写的 mcc 已经会"记欠条"了（卷 8），这一卷写"兑欠条"的那半边。

---

## 9.1 节合并：同名纸带接起来

- **教什么**：两个 .o 各有一段 `.text`——拼到同一条大 .text 后面，
  每条纸带记下"每个输入的 .o 在我这里从哪个偏移开始"（平移表）。
  符号表合并后，"add 在文件1的第 0 字节"要翻译成"在大 .text 的第 64 字节"。
  注意：**对齐要重算**（函数入口要 16 对齐，这是真 ELF 的规矩）。
- **通关暗号**：`main.o + add.o → a.o`，readelf 看到 add 偏移正确、main 里 call 目标正确。
- **TCC 对照**：`src/core/tccelf.c:2283` `tcc_load_object_file()`
  （它把 .o 的纸带直接并进 mcc 自己的 Section——TCC 根本不需要"先落盘再链接"，这就是它快的原因之一）。

## 9.2 符号解析：谁说了算

- **教什么**：全局符号只有三种身份：
  **定义**（我这里有）、**引用**（我欠条上有）、**公共**（`int c;` 没初始化——谁先要谁定，尺寸取最大）。
  合并规则口诀："强定义 > 弱定义 > 公共 > 引用"；两个强定义 = 报错。
- **你要写出**：`set_symbol(name, val, bind, type)` 冲突合并；测试
  两个文件都 `int g;`（公共，合并）、一个定义一个 extern（OK）、两个都定义（报错）。
- **通关暗号**：三种情况错误/结果全对。
- **TCC 对照**：`src/core/tccelf.c:490` `set_elf_sym()`（注释就是规则本体）。

## 9.3 布局 + 重定位：贴邮票

- **教什么**：所有 .o 拼完后**一次性**给所有节定虚拟地址（代码区从 `0x400000` 起是 ELF 惯例）；
  然后遍历所有欠条：按类型（PC32/32S/64）取"符号最终地址"算差值，
  **回填进纸带的字节里**（小端！）。最后写 ELF 头 + 程序头表。
  `--` 彩蛋：TCC 用同一套代码处理"可执行/DLL/重定位目标"三种输出，
  区别只是某些步跳过。
- **通关暗号**：Linux 上 `./mcc a.c b.c -o ab && ./ab` 输出 42。
- **TCC 对照**：`src/core/tccelf.c:1563` `layout_sections`、`:779` `relocate_syms`、
  `:825` `relocate_section`——`relocate()` 调后端（`src/targets/x86_64-link.c` 里那个大 switch）。

## 9.4 GOT / PLT：函数名字也要能"后填"

- **教什么**：可执行文件里的 `printf` 在 libc.so 里，**地址要等运行时才定**。
  于是：每个"外面借来的函数"在 .data 里留一格（GOT 槽），调用方永远
  `call [GOT槽]`；动态链接器启动时往槽里填真地址。
  PLT 是给这个槽加的一个"跳板+懒加载"小函数（TCC 用 gotplt_entry_type 四种策略
  决定哪些符号建槽）。理解概念即可，实现列为选做。
- **通关暗号**：口头——"为什么函数指针比较 `&printf==&printf` 两个不同 so 里的结果相同？"
- **TCC 对照**：`src/core/tccelf.c:1018` `build_got_entries` +
  `src/core/tcc.h:1452` `enum gotplt_entry` + `src/targets/x86_64-link.c:55` `gotplt_entry_type`。

## 9.5 库与毕业考

- **教什么**：`.a` 归档 = 一堆 .o 装订成册 + 一张目录（索引）；
  链接器**按需取**（取一个成员可能引出新的未定义符号，循环到不动点）。
  `.so` = 已经链接好的成品 + 符号名单（mcc 简化：只从 .so 里"读名单"，运行时再解析——卷 10）。
- **通关暗号（毕业考）**：
  `mcc main.c -L. -lfoo` 链接你自建的 `libfoo.a`，跑通；
  再用真 gcc 编的 `.a` 链接跑通（证明你的格式是真的兼容）。
