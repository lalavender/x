> **本卷目标**：造 mcc 的"档案室"。学完你能：开/关作用域只用 1 步（不许查表！）、

这一卷是"数据结构设计"课。TCC 最省内存、最快速度的秘密武器：
**O(1) 的作用域切换** 和 **一个 int 装下所有类型**。

## 5.1 四个抽屉的名字柜：TokenSym

- **教什么**：同一个词 `foo`，可以是宏名、标号、结构体名、变量名——**互不打架**，
  因为 C 有四个"命名空间"。TokenSym 就是给每个词配 4 个抽屉。
  **神来之笔**：作用域退出时，把"上一个 foo"的指针塞回抽屉即可（O(1)！），
  不需要遍历删除。每个 Sym 上挂一根 `prev_tok` 链，就是抽屉里的"上一任"。
- **你要写出**：`Sym`（v/r/next/prev/prev_tok/type）、
  `sym_push(ns, tok, r, c)` / `sym_pop(old)`——进入 `{` 记下栈底，退出时整段弹回。
- **通关暗号**：`./mcc '{int x=1;} {int x=2;} ...'`——验证第二个 x 的 Sym 的
  `prev_tok` 指向第一个 x。
- **TCC 对照**：`src/core/tcc.h:381` `TokenSym`（四指针就是四抽屉）、
  `tcc.h:465` `Sym`、`src/core/tccgen.c:501/600` `sym_push2/sym_pop`。
  去读 `sym_pop` 里 `ts->sym_define/label/struct/identifier = s->prev_tok` 那几行——
  和你要写的一字不差。

## 5.2 一个 int 装下所有类型：CType

- **教什么**：C 的类型 = 基本类型（低 4 位）× 修饰（unsigned/const/volatile）×
  派生（指针/数组/函数/结构）。TCC 不建树，就塞进一个 int 的位，外加一根指针
  `ref` 指向"细节"（结构成员链/函数形参链）。
- **你要写出**：`typedef struct { int t; Sym *ref; } CType;` + 你的 VT 位定义
  （`VT_INT=3, VT_PTR=5, VT_FUNC=6, VT_STRUCT=7`、`VT_UNSIGNED=0x10`…照 TCC 抄）。
  写 `type_str(CType*)` 调试函数——把位打印回 `int*[]` 这样的字符串。
- **通关暗号**：`type_str` 对"无符号短整型的指针"输出 `unsigned short *`。
- **TCC 对照**：`src/core/tcc.h:405` `CType` + `:852-880` VT 位定义。

## 5.3 sizeof 与 struct 布局

- **教什么**：结构体就是"按偏移摆放"：成员偏移 = 对齐后的当前末尾；
  整体对齐 = 最宽成员对齐；`#pragma pack`/`packed` 可以打破；union 全体重叠 offset 0。
- **你要写出**：`struct_layout()`：解析 `{ int a; char c; double d; }` 算出
  `a=0, c=4, d=8, size=16(align=8)`；`alignof/sizeof` 编译期折叠成常量。
- **通关暗号**：`./mcc "struct {char c; int n;} s; sizeof s;"` → `CPU 说: 8`。
- **TCC 对照**：`src/core/tccgen.c:3489` `struct_layout`、`:2659` `type_size`。

## 5.4 指针就是带标签的数字

- **教什么**：`int *p; p = &x; *p = 5;`——指针就是"存了地址的 int"，
  类型标签决定"取货取几个字节"和"加法乘几倍"。
  接卷 3 的欠账：`p+n` → 生成 `n*sizeof(*p)` 再 `lea`；`p-q` → 除回来。
  数组就是 `p[0]` 的写法糖。
- **你要写出**：gen_op 的指针分支 + `&`（gaddrof：把 LOCAL 偏移变地址）
  + `*`（indir：LVAL 位翻转）+ `a[i]`。
- **通关暗号**：`./mcc "int a[4]; a[0]=7; a[3]=a[0]+1; a[3];"` → `CPU 说: 8`。
- **TCC 对照**：`src/core/tccgen.c:2179-2207`（gen_op 指针算术）、`mk_pointer`(:2754)。

## 5.5 全局变量 vs 局部变量：两个住址系统

- **教什么**：局部的家在"栈帧"（`[rbp-16]`，编译期已知偏移）；
  全局的家"要等链接才知道"（便利贴上写 `CONST|SYM` + 欠条：符号+偏移 0）。
  这就是为什么 TCC 把 `where` 和 `sym` 放同一张贴纸上——"值"和"欠条"可以是同一张纸。
- **你要写出**：全局 `int g=42;` 先在 .data 占位（.data 先记在内存里，卷 8 才输出）；
  引用 g 时便利贴写 `CONST|SYM`。静态/extern 先报错占坑。
- **通关暗号**：`./mcc "int g=40; int main(){return g+2;}"` → CPU 说 42。
- **TCC 对照**：`put_extern_sym()`（tccgen.c:338）+ `vtop->r` 里 `VT_SYM` 位的用法。

## 5.6 本卷毕业考：档案室验收

- **通关暗号（三合一）**：
  ```c
  struct P { int x, y; };
  int g;
  main(){ struct P p; int *q=&p.y; *q=5; g=p.y+1; return g; }
  ```
