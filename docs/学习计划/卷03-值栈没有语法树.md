## 3.1 便利贴：SValue 的设计

- **教什么**：一张"便利贴"（`SValue`）要写清楚 4 件事：
  1. 我是什么**类型**；2. 我**人在哪**（在 CPU 的哪个寄存器？还是只是个常量？还是栈帧里的某个位置？）；
  3. 如果是常量，**值**是多少；4. （预备）如果引用了一个还没算出来的地址，贴个"欠条"。
- **你要写出**：
  ```c
  typedef struct { int type; int where; long long val; } SValue;
  SValue vstack[256]; SValue *vtop = vstack - 1;   // 这摞便利贴
  ```
  `where` 的取值先定 3 种：`R_AX/R_BX`（在寄存器）、`CONST`（值在 val 里）、
  `LOCAL`（val=栈帧偏移）。这个枚举表，你以后会越改越像 TCC 的。
- **通关暗号**：口头回答——便利贴上的 `where=CONST, val=42` 是什么意思？
- **TCC 对照**：`src/core/tcc.h:424` `SValue` + `tcc.h:831-850` 的 `VT_CONST/VT_LOCAL/VT_CMP/VT_JMP`
  编码——和上面四件事一一对应，一字不差。

## 3.2 便利贴操作全套：vpush/vpop/vswap/vrot

- **教什么**：TCC 的"IR"就是这摞纸的操作：
  `vpushi(5)` 贴一张常量、`vswap()` 换最上面两张、`vpop()` 撕掉、
  `vrott(3)` 把下面第 3 张提到最上面——为什么需要"提上来"？
  因为**二元运算规定只看最上面两张**，参数顺序不对就转一下。
- **你要写出**：完整原语，并加一个 `--vtrace` 调试选项：每步打印栈上所有便利贴。
- **通关暗号**：`./mcc --vtrace "1+2"` 能看到：贴 1 → 贴 2 → 归约成贴 3。
- **TCC 对照**：`src/core/tccgen.c:630-797`——`vsetc/vswap/vpop/vpushi/vrotb/vrott`。
  注意 `vpop()`（:678）里那个 x86 特判 `TREG_ST0` 和 `VT_JMP`——这是 TCC 在给你剧透：
  浮点和短路的"便利贴"有暗记。

## 3.3 gen_op：归约的总指挥

- **教什么**：栈上有两张纸时，`gen_op('+')` 要干三件事，顺序不能乱：
  ① **类型检查/提升**（int+char→int，指针+整数→乘元素大小，浮点就转）；
  ② **都是常量？当场算完贴回去**（常量折叠，这是编译器唯一白送的优化）；
  ③ 否则发机器码（把需要的纸 `gv()` 进寄存器，调后端）。
  `a+2` 这种，TCC 会把常量 2 折叠进 `add rax, 2` 的立即数——你也要做。
- **你要写出**：`gen_op(op)` 完成上面三步；指针运算本卷先报错"等卷 5"。
- **通关暗号**：`./mcc "2+3"` 的汇编里**没有任何 add 指令**（直接 `mov eax,5; ret`）。
- **TCC 对照**：`src/core/tccgen.c:2154` `gen_op()`；
  折叠在它旁边的 `gen_opic()`（tccgen.c:1864）。TCC 和你现在唯一的区别：它还得处理 `VT_FUNC` 退化成指针那几行。

## 3.4 gv()：全世界最懒的寄存器分配器

- **教什么**：关键心态——便利贴上的位置是"**事实**"，寄存器只是"**临时工位**"。
  谁要工位了才去 CPU 那借（`get_reg`）；借不到，就把工位上还坐着的**旧纸**
  塞回它在内存里的家（溢出到栈帧）。永远不需要"提前规划"，所以叫"懒分配"。
- **你要写出**：`int gv(int rc)`：看 vtop → 若已在合适寄存器直接返回 →
  否则 `get_reg` + 发射装载指令（`load()` 后端函数）+ 把 `where` 改写成寄存器。
  溢出：`save_reg()`——把占用中的寄存器对应的那张贴纸 `where` 改成 `LOCAL`。
- **通关暗号**：`./mcc "(1+2)*(3+4)+5*(6-2)"` → `CPU 说: 29`，
  且 `--vtrace` 里能看见纸被"塞回家"再"抓回来"。
- **TCC 对照**：`src/core/tccgen.c:1253` `gv()`（100 多行，比你多了位域和浮点常量分支）、
  `get_reg()`（tccgen.c:1062）、`save_reg()`（:962）。**读到这你会起鸡皮疙瘩——你写的每一行都有原版。**

## 3.5 左值三件套：地址、解引用、赋值

- **教什么**：`x` 有两种身份——"它在哪"（左值）和"里面装什么"（右值）。
  `x+1` 要先"去取"（`indir()`），`x=1` 要"直接放"（`vstore()`）。
  便利贴上记一种状态叫"我拿着一个地址，但还没取货"——`LVAL` 位。
- **你要写出**：赋值表达式（栈顶两张纸归约成一张"我放在 x 里"）、
  局部变量 `int x;`（分配栈帧偏移，贴 LOCAL 纸）、全局变量先占位到卷 8。
- **通关暗号**：`./mcc "int x; x=(1+2)*4; x+x;"` → `CPU 说: 12`。
- **TCC 对照**：`src/core/tccgen.c` 里 `indir()`、`gaddrof()`、`vstore()` 三个函数；
  `lvalue_type()`（tccgen.c:4471）。
