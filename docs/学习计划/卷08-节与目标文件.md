# 卷08 · 会生长的纸带

> **本卷目标**：理解**节（Section）**——"一切输出皆纸带"是 TCC 的灵魂设计。
> 造出 mcc 自己的 .o 文件（ELF），并能用 readelf 验收。
> **预计**：5 篇，约 1 周。

编译器算完了，机器码往哪放？TCC 的答案：**所有输出都是"会生长的字节纸带"**，
每条纸带贴个标签：`.text`（代码）、`.data`（有人初始化过的数据）、
`.bss`（全 0 的懒人数据）、`.rodata`（只读）、`.symtab`（名字账本）、
`.rel.text`（欠条清单）。编译阶段只管往纸带上写，
**纸带怎么拼、地址怎么定——卷 9 链接器的事**。

---

## 8.1 Section 与三个写入原语

- **教什么**：一个 Section = `{名字, 字节数组, 当前写到哪, ELF属性}`。
  三个原语走天下：
  `sec_write(sec, bytes, len)`（写一段）、`section_add(sec, size, align)`（要 N 字节对齐空间，返回偏移）、
  `section_ptr_add`（= 前者+返回指针）。
- **你要写出**：`Section` 结构 + `new_section/find_section`；把 mcc 现有的
  代码发射改到 `.text` 纸带上；全局初始化值写 `.data`；未初始化局部变量照旧（栈帧），
  未初始化**全局**变量写 `.bss`（只记大小不记内容——这就是 .bss 省磁盘的原理）。
- **通关暗号**：编译 `int g=1; int h; int main(){return g;}` 后打印各纸带长度：
  .text≈几十、.data=4、.bss 登记 4 但文件里 0 字节。
- **TCC 对照**：`src/core/tcc.h:492` `Section`；
  `src/core/tccelf.c:192/275/291` `new_section/section_add/section_ptr_add`。

## 8.2 符号表：账本

- **教什么**：`.symtab` 是一排固定格式的小卡片：
  `{名字在 .strtab 的偏移, 类型(函数/数据), 在第几号纸带, 带内偏移, 大小}`。
  你写的全局函数/全局变量都要发卡；`.strtab` 是所有名字字符的堆。
  字符串去重（名字相同不重复写）是基本功。
- **你要写出**：`put_elf_sym()`；编译 `int add(int a){...}` 后 dump 你的符号表。
- **通关暗号**：你的 .o 里 `add` 条目显示 FUNC + GLOBAL + .text 偏移。
- **TCC 对照**：`src/core/tccelf.c:388` `put_elf_sym`、`:323` `put_elf_str`。

## 8.3 重定位：欠条清单

- **教什么**：`main` 里 `return add(1);`——call 的相对地址**现在还不知道**（add 在哪？
  链接后才知道）。做法：先把 call 指令地址那 4 字节填 0，同时在 `.rel.text` 里记一张欠条：
  **"纸带 .text 偏移 X 处，将来请填：符号 add + (-X-4)"**（减法是 PC 相对寻址的账）。
  三种最常用类型就够你毕业：`R_X86_64_PC32`（相对调用）、
  `R_X86_64_32S`（绝对地址塞 32 位）、`R_X86_64_64`（全局指针初始化）。
- **你要写出**：`reloc_add()`；把卷 7 的函数调用改成走 .text 符号+欠条；
  全局变量访问（`lea 符号(%rip)` 或直接地址）也走欠条。
- **通关暗号**：`./mcc -c` 输出的 .o，`readelf -r` 能列出你写的欠条（格式全对）。
- **TCC 对照**：`src/core/tccgen.c:429` `greloca()`（发射欠条）+
  `src/core/tccelf.c:577` `put_elf_reloca()`。

## 8.4 ELF 文件解剖 + 手写最小可执行文件

- **教什么**：ELF 文件 = `文件头(指向一切) + 程序头表(告诉 OS 哪几段要装进内存) +
  节头表(告诉链接器有几条纸带)`。
  **毕业任务**：不借工具，自己 `printf` 一个 ELF：64 位 Linux、
  `_start: mov eax,60; mov edi,42; syscall` 直接退出码 42——
  Linux 上 `./a.out; echo $?` → 42。macOS 上这步改成"给卷 9 用交叉验收"，
  用 Docker/qemu 或直接 `readelf -a` 验收结构合法。
- **通关暗号**：readelf 不报错 + 字段全对（或在 Linux 上退出码 42）。
- **TCC 对照**：`src/formats/elf.h`（就是这张格式表）、
  `src/core/tccelf.c:1977` `tcc_write_elf_file()` 和 `:1860` `tcc_output_elf()`。

## 8.5 本卷毕业考：mcc -c 正规化

- **你要写出**：`./mcc -c input.c -o input.o` 完整输出
  `.text/.data/.bss/.symtab/.strtab/.rel.* + 正确的节头表`。
- **通关暗号**：
  `gcc -c ref.c -o ref.o; ./mcc -c ref.c -o m.o; readelf -SW m.o`
  的节数量级一致（允许 gcc 多 .note 等）、`readelf -s` 你的符号都在。
