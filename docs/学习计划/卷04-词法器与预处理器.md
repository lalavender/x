## 4.1 每个词只记一次：interning

- **教什么**：源码里 `printf` 出现 500 次，编译器只需要知道"有 1 个 printf"。
  办法：哈希表去重——第一次见就登记（分配编号 1024），以后见到直接回号。
  关键字（`int/while/return`…）在开机时就登记好编号，所以 `int` 永远是号 3。
  **词变成整数**之后：比较变快了、存进数组变快了、后面所有表都变简单了。
- **你要写出**：`tok_alloc(name, len)`（哈希表，桶数 16384 抄作业），
  词法表的初始关键字列表（10 个就够），把 mcc 所有地方从"字符串比较"改成"整数比较"。
- **通关暗号**：`./mcc -t "int x = 1; int y = 2;"` 打印 `int(3) x(1024) =(61) ...`，
  两处 `int` 编号相同。
- **TCC 对照**：`src/core/tcc.h:381` `TokenSym` + `src/core/tccpp.c:448` `tok_alloc()`；
  关键字表是 `src/core/tcctok.h` 那 240 行 `DEF(TOK_xxx,"...")`。

## 4.2 宏就是一盘录音带：对象式 #define

- **教什么**：`#define N 10` 之后，源码里所有 N 都要"换成 10"。
  TCC 的骚操作：**宏的展开结果，是存成"一串整数 token 的录音带"（TokenString）**。
  用到 N 时，就"按下播放键"——从录音带里一个个吐出 token，吐完弹回正常读取。
  于是 `next()` 变成一个调度器：正常读 or 读录音带。
- **你要写出**：`TokenString`（int 数组+len）；`#define NAME 值` 把值录进去；
  `next()` 加"录音带栈"（begin_macro/end_macro）；`N*(N+1)` 展开正确。
- **通关暗号**：`./mcc -E "#define N 10\nint x=N*N;"` → `int x = 10 * 10;`
- **TCC 对照**：`src/core/tccpp.c:3529` `next()` 主调度器 + `:3282` `macro_subst_tok()`。
  看它怎么丢 `TOK_NOSUBST/TOK_PLCHLDR` 占位符——这个机制是 4.3 防递归的伏笔。

## 4.3 带参数、会拼接、防自噬：函数式宏

- **教什么**：三件事：
  ① `#define SQ(x) ((x)*(x))`：先把实参"各录一盘带子"，播放时形参换成对应带子；
  ② `#` 字符串化、`##` 拼接：把 token 拼回文本再重新过一遍词法器（"回炉重造"）；
  ③ **递归抑制**：宏自己展开出来的 `SQ` 不能再展开（否则死循环）——
  在录音带里给"已经展开过的词"插 `TOK_NOSUBST` 占位符，播放时丢掉它、但记得"它刚被展开过"。
- **你要写出**：以上三点（`##` 可以先支持最简情况：两个词拼成一个词）。
- **通关暗号**：
  `./mcc -E '#define SQ(x) ((x)*(x))\nint a=SQ(1+2);\n#define CAT(a,b) a##b\nint CAT(v,1)=7;'`
  → `int a=((1+2)*(1+2));` 和 `int v1=7;`
- **TCC 对照**：`src/core/tccpp.c:3006` `macro_arg_subst`、`:3124` `paste_tokens`。

## 4.4 复制粘贴文件的管家：#include 与 #if

- **教什么**：`#include` = 把那个文件的词法器接在当前文件中间（词法器栈！）；
  头文件被包 100 次怎么防？——`#ifndef GUARD/#define GUARD` 模式 +
  一张"这个文件=这个哨兵宏，已包含"的缓存表，第二次直接跳过（不读不展开，纯哈希查表）。
  `#if/#ifdef`：条件假的时候，整段源码直接**不进录音带**（跳过词法分析，最快）。
- **你要写出**：`#include "..."`（当前目录+搜索路径列表）、`#if 1/0`、
  `#ifdef/#ifndef/#else/#endif`（用 ifdef 栈）、include 缓存表。
- **通关暗号**：写一个有 `#ifndef MIO_H` 保护的头文件，被两个 .c 各 include 一次，
  `mcc -E` 输出里头文件内容只出现 1 次。
- **TCC 对照**：`src/core/tccpp.c:1560` `search_cached_include`、缓存结构 `src/core/tcc.h:597` `CachedInclude`、
  `#if` 求值复用解析器的 `expr_preprocess`（tccpp.c:1426）。
