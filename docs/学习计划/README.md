# 从零造出一个 TCC —— 总计划书

> 写给：一个懂一点点 C（会写 `for` 循环和结构体）、完全不懂编译原理的人。
> 目标：一年后，你自己写出一个 `mcc`——一个"小 TCC"：单遍编译、没有语法树、
> 直接把 C 翻译成机器码、能链接库、甚至能把代码装进内存直接运行。
> 学完你就能看懂本仓库 `src/` 里的每一行 TCC 代码，因为**你自己都亲手做过一遍**。

---

## 一、这套东西是什么

TCC 不是魔法，是一个 26 岁思路的程序员写的 **10 万行 C**。
它之所以能这么小，是因为它做了一个大胆决定：

> **不画语法树。读一个词，翻一个词，机器码当场写出来。**

整个学习计划就是把这条路重新走一遍：你每学一篇文档，就往你的 `mcc` 里装一块零件；
每块零件都能在 TCC 源码里找到"原版"。走到最后，你回头看 TCC，
像看一台你亲手装过的机器——每个螺丝在哪、为什么在那，你都知道。

## 三、怎么玩（规则只有 5 条）

1. **每篇文档三件套**：读（20 分钟）→ 写代码（40 分钟）→ 跑"通关暗号"。
   暗号输出不对，就算没通关，回去重做。
2. **不许跳关。** 每关都踩在前一关的肩膀上。
3. **每过一关，`git commit` 一次**，提交信息写你刚学会的那件事。
   学完你会有一本"自己的编译器进化史"。
4. **卡住 30 分钟，就来问 AI**（也就是我）。可以问"这关我卡在哪"，
   但先自己试着说清楚"我以为会发生什么、实际发生了什么"。
5. 每卷末尾有一节"**真 TCC 对照阅读**"：只有 15 分钟，
   目的是让你亲眼看到——你昨天写的玩具，和 TCC 里那几十行，长得几乎一样。

## 四、装备

- 一台能写 C 的电脑（本 mac 就行；计划里的实验做了 arm64/Rosetta 适配，Linux 更简单）。
- `gcc`/`clang`（对照用）、`objdump` 或 `otool`、`readelf`（Linux；mac 用 `otool`+说明文档）。
- 你的 `mcc` 单独放一个仓库：`~/mcc/`，一个文件起步：`mcc.c`。
  **整个 mcc 在毕业前都尽量只写在 mcc.c 一个文件里**——TCC 也曾经是。
- 本仓库：你的"参考答案书"。
  - 教师手册：[../TCC编译器实现详解.md](../TCC编译器实现详解.md)（看不懂某段 TCC 时先查它）
  - 交互式地图：`../graphify-out/graph.html`（浏览器打开，看函数之间怎么连线）
  - 源码：`src/core/`（编译器核心）、`src/targets/`（各架构后端）、`src/formats/`（ELF/PE/COFF）

## 五、几个重要约定

- **目标架构**：我们让 mcc 生成 **x86-64 机器码**。
  - 在 Linux 上：直接编译、直接运行，最爽。
  - 在这台 mac 上：用 `clang -arch x86_64` 编出 x86-64 版的 mcc（Rosetta 跑），
    重点靠"**内存执行**"（第 10 卷，TCC 的 `-run` 绝招）来验证正确性；
    文件输出（ELF）用反汇编工具验收，不要求运行。
- **mcc 支持的 C 子集**（毕业范围，恰好是 TCC 设计的核心）：
  整数/char、指针、数组、struct/union/enum、if/while/for/do/goto/switch、
  函数/递归/函数指针/varargs(printf)、全局局部变量、#define/#if/#include 基本款、
  链接静态库。不要求：浮点（作为选做）、VLA、位域（选做）、内联 asm（只读不写）。
- **"通关暗号"**：每篇文档末尾给一条命令 + 期望输出。输出对上，才算过关。
  这模仿的是真 TCC 的测试方式（`tests/` 目录里全是 `.c` + `.expect` 对照）。

## 六、节奏与毕业标准

- 建议每周 3~4 篇，**全程约 5~6 个月**；每周 7 篇的冲刺模式约 3 个月。
- 毕业标准（卷 12 的考试）：
  1. 一份 100 行的综合测试程序（递归+结构体+函数指针+switch+goto+变参 printf），
     你的 mcc 一次编译通过、运行输出正确；
  2. mcc 能处理至少 40 个从 `tests/tests2/` 移植的测试（含 .expect 自动比对）；
  3. 你能在白板前用 30 分钟，给一个外行讲明白
     "`int f(int a){return a+1;}` 这一行是怎么变成机器码的"；
  4. 选做加分：mcc 编译 mcc 自己的源码子集（自举），或者给 mcc 加上 `-run`。

1. 读完本 README（你正在做）。
2. 打开 [卷01](卷01-会算数的机器人.md)，从 `1.1` 开始。
3. 要哪篇课程文档，跟我说："**开写 1.1**"。
   我会按该卷规格里的详细大纲，用讲故事+动手的方式把整篇写出来，
   包括每一行示例代码、练习、常见卡点和通关暗号。
