# yh 编译期结构体整数切片字段实施方案

日期：2026-10-06。状态：**已完成**。

## 目标

让 CT3 typed 执行器支持结构体中的 `[]int` 字段，使其能与既有局部数组、切片视图、聚合复制、函数调用及静态数据物化组合使用。

## 语义

- 结构体按值复制时复制切片视图描述，副本共享同一底层整数元素存储，与普通结构体字段中的切片值语义一致。
- 结构体作为嵌套 CT 函数返回值时，递归复制切片可见元素到调用方帧，确保不引用即将释放的被调帧。
- 只开放整数切片字段；切片元素、指针字段、联合体、浮点元素及其他借用关系仍沿用当前限制。
- 继续使用聚合元素数、递归深度和执行步数预算；切片视图不重复计费底层元素，返回复制计入调用方帧元素预算。

## 实施步骤

1. [x] 新增 `.yh` 端到端正例，覆盖局部 backing array 返回、结构体副本共享、结构体形参共享写入、返回生命周期安全及全局静态物化；另加浮点切片字段拒绝用例。
2. [x] 在 `compiler/comptime/` 扩展结构体字段白名单、视图复制和返回时的切片元素复制；普通局部/形参副本与逃逸返回采用不同复制策略。
3. [x] 更新设计、待办与完成记录；`make test` 通过 215/215，`make selfhost-native` 固定点、自解析、语法/运行/模块/项目与其余探针全绿；执行 `make seed`、新种子冷编和 `git diff --check`。

## 验收

局部结构体副本和形参修改能观察到共享切片写入；函数返回的结构体切片在被调帧销毁后仍保持正确数据；全局初始化将切片描述和元素写入静态数据；浮点切片及其他不支持类型仍被拒绝。已由 `run/96`、`fail/129` 和全量门禁验收。
