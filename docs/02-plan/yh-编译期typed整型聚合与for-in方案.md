# yh 编译期 typed 整型聚合与 for-in 方案

日期：2026-10-05。状态：**已完成首片**。

## 目标与边界

让 CT3 typed 执行器能在一次 `@[comptime]` 调用帧内创建整数数组/切片字面量，保存到局部绑定，并由普通 `for-in` 逐元素读取。调用帧拥有这些临时聚合对象，函数返回或出错后统一释放；数组和切片统一为元素类型、长度及 `CtValue` 元素序列。执行器按声明的 `=` token 选择初始化表达式，跳过数组长度等类型表达式；数组元素链使用迭代遍历，避免大型字面量造成解释器递归栈耗尽。

本切片不开放数组参数/返回值、索引读写、聚合写入、结构体/联合体或浮点元素。它解决数组/切片 `for-in` 所需的局部值表示，后续再按用途扩展一般左值与其他聚合类型。

## 实施步骤

1. 新增 `tests/yh-run/run/73-comptime-forin-array.yh`，先确认旧 typed 执行器不能计算本地数组、切片与空切片循环。
2. 在 `CtFrame` 中加入本调用帧拥有的聚合 arena/链表，以 `CtAggregate` 存储元素类型、长度和值；限制单帧最多分配 100000 个元素。
3. 在 `ct_ir_eval_expr` 中执行已类型化的 `AST_EXPR_ARRAY` 元素链，并支持局部聚合绑定的按值快照。
4. 扩展 `for-in` 分派：整数区间保持原路径；数组/切片使用其 typed 元素类型、长度和元素槽执行，继续沿用共享步骤预算与 break/continue/return 流。
5. 覆盖单文件及同模块跨文件路径，更新设计、待办、运行语料和完成记录。

## 验收

单文件 `run/73` 覆盖固定数组、切片下标/元素绑定和空切片；`comptimelocal` 覆盖跨文件函数体。完整验收运行 `make test`、`make selfhost-native` 和 `git diff --check`。所有门通过后滚动种子、冷编并校验 SHA-256。
