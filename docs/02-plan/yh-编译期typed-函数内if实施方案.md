# yh 编译期 typed 函数内 `$if` 实施方案

日期：2026-10-05。状态：**已交付；typed 函数内 `$for` 已由后续切片交付**。

## 范围与语义

本切片只让已准备的 `@[comptime] fn` 正文支持 typed `$if/$else` 选支。条件可以读取
调用帧中的整数形参、局部值和编译期调用结果；每次 `$f(...)` 调用都在执行期按本次值
选择一个分支。条件须满足 yh 已有条件类型规则。

普通函数中的 `$if` 仍按当前常量展开规则处理，顶层 `$if` 仍非法；`$for` 继续保留现有
展开实现，下一切片单独迁移。CT 函数体的两支都要完成常规名字与类型检查，因为不同实参
可能分别选择任一分支；检查阶段不触发分支中的诊断，也不发射目标代码。不存在 `$else`
时，条件为假即继续后续语句。

## 实施步骤

1. **完成**：新增正例：一个函数按形参进入两个 `$if/$else` 分支，各分支返回不同值；全局常量对真/假
   各调用一次。先确认当前实现因准备期要求条件常量而失败。
2. **完成**：新增负例：即使调用只会选择另一支，任一分支中的未声明名字仍在 typed 准备期被拒绝。
3. **完成**：在 `c_ct_prepare_active` 模式下，解析器不提前折叠函数体 `$if`；两支均进行语义检查并
   捕获到同一个 `AST_STMT_COMPTIME` 节点，条件关联 typed 表达式边，`op` 标明 `$if`。
4. **完成**：`comptime/ct_ir.yh` 仅在 typed 执行时求条件并执行对应子语句；共享现有局部帧、调用深度
   和步骤预算。结构化 `$for` 节点继续明确不属于本切片。
5. **完成**：定向单文件正反例、模块/项目用例、`make test`、`make selfhost-native` 全绿；滚动
   种子并冷编、核对 SHA-256。

## 成功标准

- 同一函数分别以真/假实参调用时返回对应分支结果，且条件能读取 typed 局部槽。
- 未选分支不执行诊断；两支都经类型和名字检查。
- 普通函数 `$if`、顶层控制语法、普通 `$for` 展开和现有 CT 执行语义保持通过。
