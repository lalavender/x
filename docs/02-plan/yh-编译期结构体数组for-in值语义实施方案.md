# yh 编译期结构体数组 for-in 值语义实施方案

日期：2026-10-06。状态：**已交付**。

## 目标

扩展 CT3 typed `for-in`，使受支持定长数组中的结构体和嵌套定长数组元素可绑定到迭代局部值；
每轮得到独立的复合值，循环体对该绑定的写入不能改动源数组。

## 边界

- 仅扩展已受支持定长数组中的结构体或嵌套定长数组元素；结构体字段沿用当前整数、嵌套结构体和定长数组白名单。
- 复合元素按值深复制到当前调用帧，沿用既有嵌套数组/结构体复制和元素预算。
- 切片元素仍限整数；本阶段不开放切片/指针/联合体字段或一般指针迭代。

## 实施步骤

1. 增加 `.yh` 正例，遍历结构体和嵌套数组，改写迭代变量，验证源数组仍保留原值。
2. 调整 `compiler/comptime/` 的聚合 for-in 绑定，让复合元素复用受支持形参的深复制逻辑。
3. 更新语法设计、待办和完成记录；运行 `make`、`make test`、`make selfhost-native`、滚种子冷编和 `git diff --check`。
