# yh 编译期 typed 结构体嵌套定长整型数组字段方案

日期：2026-10-06。状态：已完成。

## 目标

扩展 `@[comptime]` 本地具名结构体值，使字段可以是由多维定长数组组成、叶元素为整数的数组类型。例如 `[2][3]int` 字段可用嵌套数组字面量初始化、随结构体按值复制，并通过多级下标读写。

## 边界

- 只支持最多 32 层定长数组并递归到整型叶元素；每一级长度沿用既有 100000 聚合总量预算。
- 多维数组字段复制必须递归复制每一层存储，不能与源结构体或同一字面量的其他值共享可变元素。
- 在解析数组字面量的元素时传递该层元素目标类型，使嵌套字面量复用已有类型上下文。
- 不开放切片、数组/结构体参数与返回、联合体、结构体数组元素、非整型叶元素和指针字段。

## 步骤与成功标准

1. 新增运行语料，构造带 `[2][2]int` 字段的结构体，复制后修改深层元素；断言原值不变且复制值更新。
2. 用当前种子确认该语料因编译期数组元素类型受限而失败。
3. 解析嵌套数组字面量时逐层设置并恢复 `c_expect_tid`。
4. 在 `compiler/comptime/` 增加递归整型数组类型校验和存储克隆；让下标读取与写入沿数组元素聚合继续寻址，并用于局部值/结构体字段的按值复制。
5. 运行定向 `.yh` 用例、`make`、`make test`、`make selfhost-native` 和 `git diff --check`；全部通过后 `make seed` 并冷编 `make` 核对哈希。
6. 更新编译期设计、README、todo、finish 与完成报告。

## 风险

解析器改动会让普通运行时代码也能在有目标类型上下文时初始化多维数组；该行为与已支持的多维数组类型一致，但必须以既有语法和运行语料回归验证。聚合存储新增递归克隆路径，错误返回仍由调用帧统一释放。
