# yh 编译期 typed 聚合元素取址实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

在局部整数变量取址（run/131）与整数指针形参（run/132）之后，开放当前
调用帧内**整数聚合元素**的取址：`&array[i]`、`&slice[i]`、`&struct.field`，
使 `$bump(&cells[1], 10)` 这类按元素原地更新可在编译期执行。

## 明确边界

- 只接受整数叶元素/字段；元素或字段为非整数（结构体、数组、切片）时拒绝。
- 基址必须来自可写局部变量，临时值（函数返回的数组/结构体）取址继续拒绝。
- 指针目标仍是调用帧内的槽：局部值槽或（新）本帧聚合元素区；校验沿用
  存活调用帧链，只是把合法区间扩展到帧拥有的聚合元素块。
- 切片视图元素取址写回底层父聚合，别名语义与运行期视图一致。
- 指针算术（`p + n`、`p[i]`）仍不支持；指针返回、聚合逃逸、全局/字符串
  指针常量求值不变。

## 实施步骤与验收

1. 先用例：run/133 覆盖数组元素、切片视图元素与结构体字段取址写回；
   fail/135 覆盖非整数元素取址；fail/136 覆盖临时值下标取址。
2. `ct_ir.yh` 的 `&` 分支：`place.aggregate` 非空且元素类型为整数时，
   指针值取 `&place.aggregate.values[place.index]`。
3. `ct_ir_pointer_target` 扩展：遍历存活帧的聚合块（含非拥有视图块），
   地址落在块内时按该位置元素的实际类型校验。
4. 验证新增用例、`make`、`make test`、`make selfhost-native`；更新
   CT3/CT5B 进度与完成记录；全绿后 `make seed` 并用新种子冷编复核。
