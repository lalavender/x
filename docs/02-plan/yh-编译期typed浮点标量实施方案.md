## 目标

typed 编译期执行器此前只处理整数标量，浮点表达式一律拒绝。本片开放
**浮点标量（f32/f64）**：字面量、局部值、算术、一元正负、比较、显式转换
（整数↔浮点、f32 窄化）以及浮点形参与浮点返回，使顶层浮点常量可以经
`$fn()` 物化并被普通代码引用。

## 设计要点

- 值表示：`CtValue.value` 保存 IEEE754 **位模式**，类型仍由 `type_id` 决定；
  整数与浮点共用同一字段，复制、传参、返回天然正确。
- f32：内部按 f64 位模式保存，写入与物化时经一次往返窄化到单精度精度；
  单精度判定必须看类型表 `kind`（`type_id` 是索引，不能与 `TY_F32` 常量比较）。
- 顶层物化：`ct_call` 把位模式写入 `Res.ival` 与 `Res.fval_bits`，非折叠
  模式下发 `mov x0, bits` + `fmov d0, x0`；`sem_ident_val` 引用浮点 const
  时同样补 `fval_bits` 与 `fmov`。
- 冻结子集：编译期求值代码不得引入 yh-link 冻结子集之外的指令，一元负号
  改用符号位翻转，浮点转整数统一走有符号截断（`fcvtzu` 暂不生成）。

## 边界

- 仍拒绝：浮点数组/切片/结构体字段等聚合元素、浮点取址、指针算术。
- 前端自身的浮点常量折叠（`const A f64 = 1.5 + 1.0;`）仍报「浮点常量折叠暂
  不支持」；浮点常量目前只能经编译期函数求值产生。
- `%` 等非算术浮点运算报「编译期浮点只支持算术与比较运算」。

## 实施步骤与验收

1. 新增 `compiler/comptime/ct_ir_float.yh`：位模式↔f64、f32 窄化、显式转换、
   浮点二元与比较；接入 `ct_ir.yh` 的常量、一元、二元、转换、赋值与局部声明路径。
2. 放行浮点形参/返回，顶层物化写 `fval_bits`；修 `sem_ident_val` 的浮点常量引用。
3. 用例：run/134（含 f32 窄化断言与顶层常量消费）、fail/137（浮点定长数组仍拒绝）、
   fail/138（浮点取址仍拒绝）、`comptimelocal` 跨源文件浮点形参/返回断言。
4. 验证 `make`、`make test`、`make selfhost-native`（含自编导入审计构建）；全绿后滚种子。
