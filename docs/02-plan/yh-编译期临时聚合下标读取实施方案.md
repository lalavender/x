# yh 编译期临时聚合下标读取实施方案

日期：2026-10-06。状态：**已交付**。

## 目标

在 typed CT 函数内，允许对数组表达式求下标，包括函数返回的定长数组以及
函数返回结构体中的数组字段。当前聚合返回会复制到调用方帧，但下标位置解析
额外要求基址能追溯到局部绑定，导致这些可安全读取的临时聚合组合失败。

## 边界

- 仅放宽只读下标求值的基址限制；数组/切片下标写入仍须落到当前帧可变局部值。
- 数组和切片类型、整数叶子/受支持嵌套数组的现有限制不变。
- 不修改语法、聚合生命周期、调用帧复制方式或顶层 CT 结果规则。

## 实施步骤

1. 新增运行用例，组合读取 CT 函数返回数组的多级下标和返回结构体数组字段的下标；确认失败来自局部基址限制。
2. 让共享下标位置检查允许非局部表达式基址；读取只校验聚合与边界，赋值路径单独验证可写局部绑定，并增加临时数组写入拒绝用例。
3. 更新编译期过程设计、待办与完成流水；运行 `make`、`make test`、`make selfhost-native` 和 `git diff --check`。

## 验收

新增 `tests/yh-run/run/94-comptime-index-aggregate-expression.yh` 输出期望值，`tests/yh-run/fail/128-comptime-temporary-index-write.yh` 确认临时数组写入被拒；现有下标读写、切片别名与聚合按值返回语料保持通过。`make test`、`make selfhost-native`、`make seed`、滚种子后的冷编 `make` 和 `git diff --check` 均通过。新种子 SHA-256：`66d431a0764c69eb21ca59a59aac4bd25441fdd61f2f3173144cd0ffb493b81e`。
