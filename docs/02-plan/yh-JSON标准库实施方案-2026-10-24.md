## J0 规格冻结与探针

先确认「库能不能这么写」，再动 2600 行。

- [ ] 五项探针，全部放 `tests/modules/projects/jsonprobe/`（一个项目多个入口或
  分目录均可，产物进 `tmp/`）：
  1. `libs/` 内模块 `import string` 并调用 `make/append/as_view/release`；
  2. 按值返回含 `[256]u8` 数组字段的 `Builder` 结构体（大小、拷贝语义、
     `&builder` 传参后的字段写入）；
  3. `string.truncate` 回滚到起始长度，验证失败原子性可行；
  4. `malloc/free` 临时数组用于 `sort_keys` 插入排序；
  5. 读 stdin 到 EOF（`os.read_some` 循环）供一致性桥使用。
- [ ] 冻结预算常量（设计 §6 表），实测 16 MiB 输入、256 层嵌套的栈深与耗时，
  必要时调整 `JSON_MAX_DEPTH`。
- [ ] 在 `libs/project.toml` 注册 `json = {path = "./json"}`（J2 时再加 `num`）；
  先建空模块文件让 `make test` 不因缺模块失败。
- [ ] 记录实测数字到本文件「J0 实测」小节。

**风险**：`Builder` 按值返回若触发大结构体拷贝开销，退化为调用者持有
`Builder` 变量、`builder_init(b *Builder, out *string.String, options WriteOptions)`
的初始化式 API（不改变语义，只改首参）。

- [ ] `libs/toml/30_numbers.yh` 改为调用 `num.parse_f64`；删除本地大整数
  （或保留为私有包装，视改动面而定）。
- [ ] `json/30_numbers.yh`：词素 grammar 校验、i64 范围、`as_f64` 走 `num`、
  `write_f64` 走 `num.format_f64`（NaN/Inf → `write_number_range`）。
- [ ] 差分：把 toml 的 1437 组随机/边界值 + 400 组中点向量在 `num` 层重跑；

## J3 读取器骨架

- [ ] `10_storage.yh`：池（块链 + 累计预算 + 状态 0/1/2）、`node`（kind、
  span、字符串 `Text`、数字词素 `Text`、布尔、数组/对象指针）、对象条目
  `{key Text, key_span Span, value *node}`、数组容器、`doc_state`。
- [ ] `20_utf8.yh`：整体校验（返回首个非法序列偏移与长度）、标量编码
  （`escape_non_ascii` 与代理对输出用）。
- [ ] `40_lex.yh`：空白、`true/false/null`、字符串（两遍：算长、写入）、
  数字 grammar 扫描；所有失败写 `fail_code/fail_message/fail_span`。
- [ ] `50_parse.yh`：`p_value` 分派、数组、对象（键必须是字符串）、重复键
  线性检测、深度计数、尾随内容检查、行/列维护（CRLF 计一行）。
- [ ] `60_query.yh`：`kind`/`value_span`/`object_get`/`get`/`array_get`/
  `count`/`object_entry`/`as_text`/`as_bool`/`as_i64`/`as_f64`/`number_text`/
  `is_integer`。
- [ ] `90_api.yh`：`parse`/`parse_text`/`root`/`release`，失败整池释放。
- [ ] fixtures：`jsonmodel`（多文档、输入生命周期、释放幂等、空视图）、
  `jsonstrings`（转义全表、代理对、NUL 键、UTF-8 边界）、
  `jsoncontainers`（嵌套、插入顺序、空容器、顶层标量）。

**出口**：三组全绿；`make test` 内的 `tests/json/run.py` 接入后不拖慢主门
（单组超时 60 s）。

## J4 预算、重复键与失败原子性

- [ ] 深度 > `JSON_MAX_DEPTH`、输入 > `JSON_MAX_INPUT`、累计分配 >
  `JSON_MAX_BYTES`、有效位 > `JSON_MAX_SIG_DIGITS` 全部返回对应错误码。
- [ ] `JSON_TEST_FAIL_AFTER` 注入点（产品构建恒为 -1），`tests/json/injection.py`

- [ ] `tests/json/injection.py` 第二段把 `JSON_MAX_BYTES` 降到 2048，
  `jsonbudget` 验证 `error_resource_limit`。
- [ ] `jsonerrors` 组：BOM、裸控制字符、非法转义、孤立代理、`+1`/`01`/`1.`/

- [ ] `Makefile`：`test-json-injection`。

## J5 一致性与差分

- [ ] `tests/modules/projects/jsontestbridge/`：stdin 读字节 → 解析 → 退出码
  0/1；成功时把值树用 `json.encode` 紧凑写回 stdout（供差分二次校验）。
- [ ] `tests/json/conformance.py`：固定 JSONTestSuite 提交与 SHA-256，
  `--prepare` 下载到 `tmp/`；常规运行不静默联网，缺语料明确失败。
  `y_` 全接受、`n_` 全拒绝、`i_` 走本库登记表（每条写明预期与理由）。
- [ ] `tests/json/differential.py`：固定种子随机文档生成（含深层嵌套、大整数、
  超范围指数、Unicode、空键、重复键注入），与 Python `json` 比值树；
  写出后回读比位模式。
- [ ] `jsonroundtrip` 组：`parse → encode → parse` 树相等；数字词素字节保真
  （`1.0`、`1e2`、`1e400`、`-0`）。
- [ ] `Makefile`：`test-json-conformance`。

**风险**：JSONTestSuite 的 `i_` 集包含孤立代理与超长数字，本库按严格 profile
拒绝或接受都合法；登记表必须写清，不能靠 SKIP 掩盖。

## J6 写出器完善

- [ ] 缩进输出：`indent=1..16`，空容器仍写 `{}`/`[]`，`": "` 分隔，行尾不
  留空格；`indent > 16` 报参数错误。
- [ ] `escape_non_ascii=1`：逐标量 `\uXXXX`，BMP 以上代理对；输入非法 UTF-8
  报 `write_invalid_utf8`。
- [ ] `sort_keys=1`：条目索引插入排序，输出稳定；对象含重复键时保持原顺序
  （builder 不去重，文档写明由调用者负责）。
- [ ] `write_file`：Linux/Darwin 文件适配（`75_files.*.yh`），建/截断、短写
  循环、失败保留 `native_code`。
- [ ] `jsonfiles` 组：真实文件读写、I/O 错误分类、失败无半成品文档。

## J8 后置候选（有触发条件才立项）

| 项 | 触发条件 | 首步 |
| --- | --- | --- |
| JCS 规范模式（RFC 8785） | 需要对 JSON 做内容哈希或签名 | 独立 formatter，ECMAScript 数字格式单测对照 RFC 附录向量 |
| 大对象哈希索引 | 解析 10k 键对象成为实测瓶颈 | `JSON_HASH_THRESHOLD` 以上建开放寻址索引，插入顺序不变 |
| 流式 SAX | 文档超预算或需常量内存 | 先定事件契约与错误恢复边界 |
| JSON Pointer | 出现按路径取值的工具 | 只做读，不做写 |
| 结构体映射 | 语言支持反射/泛型后 | 不预先设计 |

## 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 抽取 `num` 打坏已验收的 toml | 681/681 回退 | J2 单独成阶段，语料为阻断门，一天内定位不到即回退为复制 |
| 最短往返浮点写出的性能 | 大量数字写出变慢 | 先测；触发线 1 ms/1000 个，超过再换 Ryu，不改 API |
| 大对象 O(n²) | 解析慢 | 记录基线，J8 阈值索引；README 披露 |
| `Builder` 大结构体按值传递 | 拷贝开销 | J0 探针 2 决定；必要时改 `builder_init(b *Builder, ...)` |
| 严格 profile 与生态习惯冲突 | 用户困惑 | README 与设计 §2 明列差异；宽松模式另立切片 |
| 与 `string`/`num` 的循环依赖 | 编译失败 | 依赖方向固定：`json → string/num/memory/os`，反向禁止 |
