# yh_link 静态 ELF 链接器实施方案

- 状态：**P0–P5 完成，P6 部分完成（文档/README 在收尾）**；集成到编译器待后续任务
- 设计依据：`docs/03-design/yh-link静态ELF链接器设计.md`
- 平台顺序：Linux/aarch64 优先（仓库既有决定）
- 关键约束（用户决定）：
  1. **当前不接入编译器**——等链接器稳定后再接入；
  2. **link 与 asm 解耦合**——`link/` 不 import `asm/`，两者只通过 ELF
     `ET_REL` 对象通信，验收走命令行调用。

## 1. 目标与完成判据

把 `link/` 做成一个能独立使用的静态 ELF 链接器，判据（全部机器可判定）：

| # | 判据 | 现状 |
| --- | --- | --- |
| G1 | `link/` 能用入库种子冷编通过（`make yh-link-build`） | 通过 |
| G2 | 无参数调用 = 自检，退出码即门；四组自检全绿 | 通过（57 项，失败 0） |
| G3 | CLI 契约：0 成功 / 1 输入失败 / 2 用法错误 | 通过（`check.py` 断言） |
| G4 | 端到端：汇编 → 链接 → 结构合法 → **真跑**得到期望退出码 | 通过（7 用例） |
| G5 | 与 `aarch64-linux-gnu-ld` 的差分：行为一致 + 符号间距一致 | 通过（7 用例，binutils 2.46） |
| G6 | 不影响编译器：`make` / `make test` / `make selfhost-native` 全绿 | 通过（见 §7） |
| G7 | 产物在 arm64 真机/容器上通过（非 qemu 模拟） | **待办**（并入 arm64 CI） |
| G8 | 接入编译器（工具查找改造 + driver + 门） | **待办**（用户要求稳定后） |

## 3. 验收门怎么跑

```bash
# 只跑构建 + 自检 + CLI 契约（不需要汇编器、不需要能跑 AArch64 产物）
make yh-link-build
make yh-link-probe

# 追加端到端 + GNU ld 差分（需要 yh_asm 与可执行 AArch64 产物的环境）
make yh-link-probe FULL=1

# 直接调脚本（WSL 下要先有 tmp/wsl.sh 设好的环境）
python3 link/tests/check.py --full
python3 link/tests/link_accept.py --link link/.build/yh_link --asm asm/.build/yh_asm
python3 link/tests/link_diff_regress.py --link link/.build/yh_link --asm asm/.build/yh_asm
```

## 4. 实施中修正的设计细节（记录下来，避免重犯）

| # | 现象 | 根因 | 处置 |
| --- | --- | --- | --- |
| 1 | 跨对象 `bl` 跳到自己，运行期死循环 | 符号定址漏了"输入节在输出节内的偏移" | 记录 `out_off` 并参与定址；自检加"多对象合并"组 |
| 2 | 链接器段错误（越界访存） | 全局符号表槽位算出**负数**（u32 哈希按补码落 int 后取余） | 哈希累加与取余改在 u64 域做，最后才落 int |
| 3 | `readelf` 报 `corrupt string table index` | `e_shstrndx` 硬编码为 9 项布局的下标，实际表只有 8 项 | 节头索引全部按"有没有 `.got`"现算 |
| 4 | 符号名乱码、`objdump` 拒绝反汇编 | `.symtab.sh_link` 指到 `.bss`（同样被硬编码常量带偏） | 同上 |
| 5 | 同余满足但一访存就段错误 | 段起始紧贴上一段末尾，虚拟地址未页对齐 | 段基址按页向上取整，文件偏移由基址反推 |
| 6 | `ADR_PREL_PG_HI21` 报"不是 adrp 指令" | 位与 `0x90000001 & 0x9f000000` 得到 0（种子编译器 `&` 错值） | 形态校验改为纯算术位段取值 |
| 7 | 分支被误判"位移未按 4 字节对齐" | 位移为负时"除以再乘回"的取余向零取整 | 用 `\|d\|` 取余判定 |
| 8 | 诊断自己覆盖自己（输出递归重复） | 消息拼在 `ctx.diag_buf`，而诊断函数会复用同一个缓冲 | 消息改在独立缓冲里拼 |
| 9 | 链接失败只给一个退出码 1，没有诊断 | 某条失败路径没打诊断 | 主流程记录阶段名，无诊断时补一条带阶段名的内部错误 |
| 10 | `link -o out missing.o` 返回 2 | 输入文件读不进来被当成用法错误 | 新增 `err_link2`，输入类失败统一返回 1 |

## 5. 已知限制（同设计文档 §12）

只做 Linux/AArch64 静态非 PIE；无跳板（分支超 ±128 MiB 报错）；不支持
TLS/弱符号/COMMON/可见性/链接脚本/归档库；映像上限 2 GiB；段间不共享页面；
映射符号不进输出符号表；尚未接入编译器。

## 6. 集成到编译器的任务分解（后续，本轮不做）

**前置条件**（缺一不可）：

1. G7（arm64 真机/容器验证）通过，且至少跑通一个真实程序的完整链路；
2. 编译器的汇编器查找从 `yh_link` 改为 `yh_asm`
   （`compiler/cmd/link_cache.yh` 的 `mb_asm_tool`），否则真链接器占用
   `yh_link` 名字会直接破坏现有 `make`；
3. `YH_ASM` / `YH_LINK` 环境变量与"找不到就回落系统 cc"的语义定稿；
4. 集成后的失败诊断与退出码在 `tests/selfhost/` 有对应门。

**任务**：

| # | 任务 | 依赖 |
| --- | --- | --- |
| I1 | 编译器工具查找改名（`yh_link` → `yh_asm`）+ 影子验收 | 无 |
| I2 | 链接器加 `--sysroot`/运行时兼容性检查（与编译器运行时对接） | I1 |
| I3 | driver 增加 `--toolchain=self`，最终链接步调 `yh_link` | I2 |
| I4 | 把 `yh_link` 产物放到约定位置（`make yh-link` 复制到仓库根或工具目录） | I3 |
| I5 | `tests/selfhost/` 增门：自举链全走自家工具链 | I3 |
| I6 | 滚种子前的完整门：`make test` + `make selfhost-native` + 链接器门 | I5 |
