# yh 编译期 typed 聚合形参实施方案

日期：2026-10-06。状态：**已交付**。

## 目标

让 `@[comptime]` 函数接受当前执行器已能表示的定长整数数组和整数叶字段结构体作为形参。数组与结构体实参按值深复制进被调函数帧；整数元素切片形参复制视图描述，但与调用方共享底层元素存储。本切片本身不扩展返回类型；嵌套 typed 聚合返回由[后续方案](yh-编译期typed聚合返回实施方案.md)另行加入。

成功标准：单文件与同模块跨文件 `.yh` 用例均验证嵌套编译期调用、数组/结构体参数可读写、数组与结构体副本不泄漏修改、切片参数的视图写入可见；不支持签名在函数定义检查时报错；原有 CT 语料和完整构建门通过。

## 边界与取舍

- 仅开放 typed IR 已支持的整数叶定长数组和整数/嵌套结构体字段组合，不扩展联合体、指针、浮点或其他数组叶类型。
- `[]int` 等整数叶切片形参采用切片值语义：复制视图描述、保留底层数据别名；不拥有或释放调用方存储。
- 兼容 token 执行器不解释聚合形参。签名含聚合形参时，函数体必须具有可执行 typed IR，否则给出明确诊断。
- 本切片的测试函数仍返回整数；返回数组/结构体需要跨调用帧的所有权转移，作为后续切片单独设计和实现。

## 实施步骤

1. 新增单文件运行正例和模块跨文件正例，旧种子应因签名限制拒绝。
2. 在 `comptime/` 暴露签名类型检查，并在 `parse_decl` 只接受执行器可复制/借用的形参类型。
3. `ct_invoke` 对 typed 函数验证聚合实参；调用帧初始化时深复制数组/结构体形参，浅复制整数切片视图。
4. 保持 token 执行器和整数返回边界，更新设计、待办、完成记录。
5. 定向回归、`make`、`make test`、`make selfhost-native`、`git diff --check`；全部通过后滚种子并冷编。
