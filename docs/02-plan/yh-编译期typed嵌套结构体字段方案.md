# yh 编译期 typed 嵌套结构体字段方案

日期：2026-10-05。状态：**已完成**。

## 目标与边界

在现有本地整型字段结构体值之上，允许结构体字段直接使用另一个具名结构体类型。编译期函数需支持嵌套结构体字面量初始化、链式成员读取/写入和包含嵌套值的按值复制；叶字段仍限整数类型。

不开放数组/切片、指针、浮点、联合体字段，结构体参数/返回、成员取址以及非本地结构体成员访问也不在本片范围内。
