# yh 编译期 typed 浮点指针实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

编译期指针此前只接受整数槽（`&` 取址、`*p` 解引用、指针形参、指针目标解析都写着
「整数」）。本片把指针目标从整数槽放宽到**标量槽**（整数或浮点），使
`*f64`/`*f32` 形参与浮点取址可用，闭合浮点线。

## 设计要点

- 指针目标解析 `ct_ir_pointer_target` 本来就按 `want_type` 精确匹配槽类型，
  只需放宽各调用点的整数门槛：取址（`ct_ir.yh` 的 `&` 分支）、解引用
  （`ct_ir_lvalue`）、指针形参（`ct_ir_param_supported`）。
- 解引用读与写路径直接搬运 `CtValue`（含位模式），无需浮点特判；浮点赋值/复合赋值
  已在 STORE 路径按浮点归一。
- 类型安全不变：指针与其目标类型必须逐类型相等（`*f32` 不能指向 `f64` 槽），
  `ct_ir_pointer_target` 的存活帧校验（局部槽 + 聚合元素块）保持原样。
- 诊断文本从「整数局部变量/整数聚合元素/整数局部值」改为「标量局部变量/标量聚合元素/
  标量局部值」，并保留既有 `fail-contains` 前缀子串。

## 边界

- 仍拒绝：指向指针的指针（`**int`）、指针元素聚合、结构体指针字段、指针返回值逃逸
  （浮点指针同样不能逃出帧）、浮点指针常量（CT5B）。

## 实施步骤与验收

   形参跨帧写回与二次转发）；`fail/104` 改为指向指针的指针仍拒绝，
   `fail/137` 改为浮点指针返回仍拒绝，`fail/138` 改为结构体浮点指针字段仍拒绝，
   `fail/135` 更新为「非标量聚合元素取址」。
