# yh 编译期 typed 联合体实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

编译期聚合此前只覆盖结构体、定长数组与切片，`union` 一律落到「成员访问只支持
本地结构体值」等诊断。本片补齐整数叶联合体在编译期的构造、读写、按值复制、
形参与返回，使编译期计算可以处理 C ABI 常见的 tag/共享存储联合体。

## 设计要点

- 受限支持：`ct_ir_union_supported` 只接受整数标量字段（浮点、指针、聚合字段
  仍拒绝，诊断「编译期联合体字段只支持整数标量」）。`ct_ir_struct_supported`
  现在同时承担结构体与联合体的聚合支持判定。
- 共享存储模拟：编译期每个字段各占一个 `CtValue` 槽，共享存储用
  **写入即广播** 实现 —— 写字段后 `ct_ir_union_broadcast` 把同一值按其他字段
  类型重解释（小端整数截断/零扩展）写入其他槽。于是「写 `int` 读 `u8` 取低位」
  与「写 `u8` 读 `int` 零扩展」都与运行期一致；未被写入的字节在编译期固定为 0
  （运行期是未定义垃圾，编译期取确定的 0 更严格）。
- 广播点：联合体字面量构造（`ct_ir_struct_eval`，只允许初始化一个字段）、
  字段赋值（`ct_ir.yh` STORE 的聚合写回分支）。
- 取址拒绝：`&v.field` 在共享存储模拟下无法保持别名语义（各字段槽独立），
  统一报「编译期联合体字段不支持取址」。
- 明确不开放：联合体作为数组/切片元素或结构体字段、联合体顶层静态物化
  （前端 `parse_global_init` 本就报「union 全局初始化暂不支持」）。

## 顺带修复的既有缺陷

- 模块模式（typed AST）下 union 字面量被 `parse/ast_expr.yh` 的
  `ast_expr_verify` 拒绝：该处要求 `STRUCT_INIT` 节点类型必须是 `TY_STRUCT`，
  导致任何模块代码写 `Val{ i: 1 }` 都报「内部错误：表达式 AST 校验失败」。
  现在同时接受 `TY_UNION`。

## 实施步骤与验收

1. `ct_ir_union_supported`、`ct_ir_union_broadcast`；聚合 kind 判定放宽到
   `TY_UNION`（参数、返回、局部声明、STORE、克隆、返回复制、注册表检查）。
2. 用例：run/139（字面量构造、双向重解释、形参、返回、跨帧复制）、
   fail/142（字段取址拒绝）、fail/143（浮点字段拒绝）、fail/144（顶层物化拒绝）。
3. `comptimelocal` 增加跨源文件联合体共享存储断言。
4. 验证 `make`、`make test`、`make selfhost-native`；全绿后滚种子。
