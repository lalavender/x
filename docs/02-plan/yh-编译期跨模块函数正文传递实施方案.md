# yh 编译期跨模块函数正文传递实施方案

日期：2026-10-06，2026-10-07 更新。状态：**CT5B 跨模块调用、闭包、缓存、来源路径/行/列映射已分片实现；指针能力边界仍在进行**。

## 目标

允许模块公开 `@[comptime] pub fn` 的签名与编译期正文分开传递。导入方可用
`$module.function(args)` 执行公开过程；其可达私有编译期函数和编译期常量随正文闭包
一同加载，但不进入导入方普通名字空间，也不产生目标运行期函数符号。

正文缓存必须跟随定义模块源码、可达闭包、依赖模块正文、目标模型和编译期 IR 版本
失效。公开签名仍由 `.s.i` 提供；正文由版本化 `.s.ct` 提供，不能把空函数体接口伪装成
可执行实现。

## 约束与边界

- 保持 `$` 显式调用；跨模块形式为 `$module_alias.function(...)`。普通调用
  `module_alias.function(...)` 仍按普通运行期函数规则处理。
- 只允许现有 comptime 类型和 typed IR 语句/表达式子集；不扩展浮点评估、指针、联合体、
  函数值或任意源码求值。`.s.ct` 可传递直接浮点字面量常量，仅供导入侧重新解析和检查正文类型。
- `.s.i v3` 保留类型及公开签名并带 comptime 属性；`.s.ct v1` 保存隐藏函数名与 YH 正文，
  导入后由正常前端重新捕获 typed IR。闭包已携带可达正文引用的就绪整数常量并重写其引用；
  局部类型按语义类型整体发射，覆盖 `[N]Alias`、`*Alias` 等复合引用；结构体字面量、
  `.to_type(Alias)` 和 `sizeof(Alias)` 的直接具名引用改写为底层类型名。模块限定公共类型在局部类型、
  结构体字面量、`.to_type` 和 `sizeof` 中解析为规范类型名；直接浮点字面量与直接字符串字面量初始化的
  私有 `*char` 常量可供导入正文类型检查。浮点表达式、其他指针常量表达式及全局/字符串指针求值
  仍未实现；函数定义路径/行/列已通过 `.s.ct` 传递。
- 导入方校验 `.s.ct` 头版本、目标、模块后缀，以及公开函数与隐藏正文的函数类型；缺失、损坏
  或不匹配时明确失败，不回退执行空函数体。
- `.s.ct` 与 `.s.i` 按同轮缓存发布：正文先原子发布，接口随后发布作为调度器就绪信号；
  消费者缓存哈希同时包含依赖 `.s.i` 与 `.s.ct`。

   正文调用私有辅助函数。
2. [x] 加入 `.s.i v3` 属性、`$module_alias.function(...)`、`.s.ct v1` 加载及签名一致性检查。
3. [x] 生产模块从公开 CT 函数的 typed 调用节点导出可达本地闭包；导入时经前端恢复 typed IR，
   函数名使用稳定隐藏符号，正文不发运行期码。
4. [x] `.s.ct` 纳入依赖缓存、并发就绪、原子发布、清理和两代固定点。
5. [x] 支持 CT 正文调用另一模块公开 CT 函数；导出时重写为提供方隐藏符号，导入时将
   typed IR 切片重定位到统一 arena；验证两层闭包执行及最底层依赖正文变化触发消费者重算。

   - [x] 擦除私有别名局部类型和结构体字面量引用；局部类型整体发射，覆盖数组/指针，直接具名

   - [x] 为隐藏 CT 函数保留定义源码路径、函数体起始行和重写列映射；导入时将正文语义错误以及执行期
     `$assert/$compile_error/$compile_warn` 映射回定义源码。`yh-ctcol v1` 逐段保存生成范围和原文范围，

   - [x] 拒绝 `.s.ct` 版本错误、正文截断和函数语法损坏；由

     `ct5b-malformed-body-rejected` 覆盖。
   - [x] 支持私有 `*char` 常量由单个字符串字面量初始化时随闭包传递，并在导入后仅供正文类型检查；

## 成功标准

- 导入模块的公开 CT 函数和它的可达私有闭包按调用帧执行，直接与嵌套 `$module.function`
  调用都得到正确值。
- 普通运行期模块调用、私有符号可见性及现有同模块 CT 调用行为不变；CT 正文不发目标符号。
- 定义正文或传递 CT 依赖变化会使导入方重求值；接口/正文缓存不会混用不同构建轮次。
- `.s.ct` 版本、布局和依赖参与固定点；所有 CT `.yh` 正反例、项目验收、`make test` 与
  `make selfhost-native` 通过后才滚种子。
