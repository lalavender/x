# yh 编译期 typed 指针形参实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

在上一片「当前帧整数局部 `&`/`*` 读写」的基础上，开放 `*T`（`T` 为整数）
形参：调用方把自己的局部槽地址交给被调编译期函数，被调方通过 `*param`
读写该槽，从而支持 `$bump(&value, 4)` 这类原地更新与指针继续向下传递。

## 明确边界

- 形参只接受指向整数的指针；`**int` 等指向指针或聚合的指针仍拒绝。
- 编译期指针值必须落在**现阶段存活**的调用帧局部槽上；空指针仍单独诊断。
- 指针仍不得作为返回值、不得进入聚合或切片元素；不做指针算术，不取
  聚合元素/成员的地址；全局与字符串字面量指针常量不参与求值。
- 普通运行期指针语义不变，语法不变（不改 `docs/yh.g4`）。

## 附带修复：字符串字面量指针解引用会崩编译器

本片前置缺陷：`let p *char = "abc"; return *p;` 会让编译器段错误
（exit 139）。局部指针槽拿到的是字符串字面量的地址/标签值，解引用时被
当作宿主 `CtValue` 地址直接访问。修复方式与形参同源：指针解引用和指针形参
绑定都必须先在「存活调用帧局部槽区间」中验证地址，不合格即报编译期诊断。

## 实施步骤与验收

1. 新增 `.yh` 用例：跨调用写回与二次转发的正例（run/132）、
   指针到指针形参、空指针形参解引用、字符串字面量指针解引用三个反例；
   先运行确认正例与反例的当前行为（正例失败、字符串指针反例崩溃）。
2. `CtFrame` 增加存活链字段：`ct_eval_ir_body` 在分配局部槽后登记当前帧，
   经由统一出口 `ct_ir_frame_release` 注销并释放；新增
   `ct_ir_pointer_target` 把指针值解析为存活帧内的整数槽地址。
3. 指针解引用、指针形参绑定改用该验证；`ct_ir_param_supported` 放行
   「指向整数的指针」；非 typed 正文的指针形参仍拒绝。
4. `comptimelocal` 项目新增跨源文件指针形参写回断言，`comptimecross` 项目新增
   跨模块导出正文的指针形参写回，覆盖 `.s.ct` 正文/签名与导入方取址路径。
5. 更新 CT3/CT5B 进度与完成记录；验证新增用例、`make`、`make test`、
   `make selfhost-native`，全绿后 `make seed` 并用新种子冷编复核。
