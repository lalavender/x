# yh 编译期 typed 顶层聚合结果实施方案

日期：2026-10-06。状态：**已完成**。

## 目标

让没有 typed 调用方帧的 `$f(...)` 能返回 CT3 已支持的定长数组、结构体和整数切片，并让结果可在普通代码中作为聚合值使用。运行期表达式路径将其编码为带目标布局的静态数据；编译期外层 `$g($f(...))` 则保留 `CtAggregate`，继续按编译期值传递。

## 边界

- 仅开放当前 typed 返回子集：整数叶结构体/数组及整数切片；指针、联合体和其他非受支持类型仍拒绝。
- 局部 `let`、全局可变聚合 `let`、普通运行期成员/下标访问和嵌套顶层编译期实参均须可用。
- 现有语义禁止聚合 `const`，本任务不改变该规则；CT5A 类型布局求值另行处理。

## 实施与验收

1. `run/89` 验证局部结构体/数组/切片结果、成员和下标写入及 `$g($f(...))`；`run/90` 验证全局可变结构体/数组初始化。
2. 在 `comptime/` 保留顶层求值产生的 `CtAggregate` 到当前编译单元结束；按类型布局将支持的值序列化到 `.data`，表达式返回稳定标签地址。
3. 全局聚合初始化将编译期值直接写入对应全局符号；仍拒绝指针返回和非整数元素切片。
4. 定向用例、`make test`、`make selfhost-native` 与 `git diff --check` 全绿后滚种子并冷编。

## 完成结果

- `run/89` 覆盖局部数组、嵌套结构体、整数切片静态物化和嵌套 `$f($g(...))`；`run/90` 覆盖全局结构体、数组、切片初始化及运行期修改。`comptimelocal` 项目增加跨源文件的全局和局部 CT 聚合返回回归。
- `compiler/comptime/ct_registry.yh` 保留最外层 CT 聚合结果并在普通求值时发射静态数据；`ct_ir_place.yh` 按目标布局序列化；`parse/parse_global_init.yh` 接入可变全局聚合初始化。
- 顶层聚合失败反例 `fail/106` 改为锁定指针返回拒绝，`fail/107` 继续锁定非整数元素切片拒绝。聚合 `const`、CT5A 依赖类型布局保持原有边界。
- 验收：`make test` 语法 71/71 + 44/44，运行 89/89 + 拒绝 90/90 + 通过 8/8（187/187）；`make selfhost-native` 固定点 14/14、自解析 64 个文件、模块 17/17、项目 82/82 及所有探针通过。
