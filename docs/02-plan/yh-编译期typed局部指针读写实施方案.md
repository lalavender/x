# yh 编译期 typed 局部指针读写实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

为 `@[comptime]` typed 函数首片开放局部标量变量的 `&` 取址、`*` 读取和
间接写入，使常见的局部原地更新可在编译期执行。编译期指针只引用当前
执行帧内的局部整数值；不改变普通运行期指针语义。

## 明确边界

- 支持局部可写整数变量：`let p *int = &value; *p = 9; return *p;`。
- 编译期指针值保存解释器内部局部 `CtValue` 槽地址，不暴露宿主内存访问。
- 指针不得作为编译期函数参数或返回值，也不得存进聚合；地址不能逃出当前帧。
- 不支持全局/字符串指针求值、指针算术、成员/下标取址、空指针解引用；空指针
  解引用必须产生编译期诊断而非访问地址零。
- 只接受元素类型与被指向局部槽类型完全一致的间接访问。

## 实施步骤与验收

1. 新增 `.yh` 正反例：局部取址后读取、写回及空指针/返回指针拒绝；先运行并确认
   正例因 typed 执行器尚不支持指针运算而失败，反例按预期失败。
2. 在 `CtPlace` 中表达直接值槽，统一让普通左值、取址和间接左值引用同一调用帧槽；
   typed 表达式执行 `&` 与 `*`，只开放整数槽并拒绝空指针。
3. 更新 CT3/CT5B 进度及完成记录。语法不变，不改 `docs/yh.g4`。
4. 验证新增用例、`make`、`make test` 和 `make selfhost-native`；所有门禁全绿后
   执行 `make seed` 并用新种子冷编复核哈希与固定点。
