# yh 编译期 typed IR 与函数执行器实施方案

日期：2026-10-05 起滚动更新。状态：**typed IR 执行器分阶段扩展中；局部循环、诊断、`$if`、`$for`、数组/切片视图及下标读写、递归嵌套结构体/数组值、整数或受支持结构体元素切片、受支持聚合形参与嵌套/顶层返回、当前帧整数局部槽指针读写已交付**。

## 目标

将 `@[comptime]` 函数从 token 快照解释迁移为前端已完成绑定与类型检查的稳定表示，
并在此基础上支持标量局部值、赋值、普通条件循环、递归与统一执行步数预算。CT 函数仍
只通过 `$f(...)` 调用，不生成目标函数代码；普通函数中的 `$for` 静态展开，CT 函数中的 typed
`$for` 按每次调用的边界执行。

成功标准：全局常量初始化可以调用定义在后面的 `@[comptime]` 函数；函数体只经普通
前端解析与类型检查一次，执行器不重新实现表达式优先级；调用帧以稳定绑定编号隔离
局部槽；整数/逻辑、分支、循环、诊断、递归与预算的 `.yh` 正反例逐步通过单文件和模块路径。

## 当前缺口

`ct_register` 在 pass1 保存定义源码与 token。全局初值在 pass2a 求值，因此 CT 函数现于
pass2a 前经普通 parser 准备；模块 worker 使用声明索引 AST，单文件入口使用合成文件身份，
两者把 `AstExpr/AstStmt/AstBinding` 切片复制到 comptime 私有 arena。typed 执行器目前
消费已支持的表达式/语句子集，并已直接执行诊断语句；暂未迁移的形式继续由兼容 token
执行器处理。

## 方案取舍

1. **继续扩充 token 执行器**：改动较少，但会产生第二套 yh 表达式/语句解析和绑定规则，
   后续局部变量、控制流及错误位置会持续分叉；不选。
2. **只复用项目 worker AST**：类型与绑定信息现成，但单文件入口没有 AST 捕获，且捕获
   时点在全局初始化之后；无法满足全路径与前向函数定义；不选。
3. **前端准备阶段输出 comptime 自有 typed IR**：在签名登记后、全局初始化前，使用
   现有 parser 对每个 CT 函数执行一次无发码准备；parser 将已解析的类型、运算符、
   稳定局部绑定和语句结构送入 `compiler/comptime/`。comptime 持有独立、可验证的 IR
   arena 与来源快照，调用时只解释 IR。采用此方案；它让 parser 继续独占语法与名字/类型
   语义，同时满足单文件、模块多文件和全局初值调用时序。

准备阶段须区分“检查函数定义”与“执行本次调用”：参数相关条件/诊断不得在准备时求值；
普通函数的结构 `$if/$for` 仍按既有编译规则处理；CT 函数 typed `$if/$for` 捕获条件、边界与循环体，
调用时按当前帧执行；不就绪的全局常量不能被冻结为零。CT 函数正文
不发码，准备好的函数不得在后续普通函数遍历中重复检查或重复登记局部状态。

## 实施顺序

1. 新增 `tests/yh-run/run/68-comptime-local-loop.yh`：全局常量调用位于定义解析之前，
   函数用局部变量、赋值和 `for condition` 累加；先确认当前 token 执行器因不支持语句而失败。
2. 在 `compiler/comptime/` 新增带类型的表达式/语句/绑定节点、函数 IR 范围与校验器；
   节点保存函数内绑定编号和定义源范围，不保存会在作用域弹出后复用的局部符号槽。
3. **已完成首片**：在 parse 顶层遍历增加 CT 函数准备子遍；单文件合成身份和模块索引
   文件都在全局初始化前准备，沿用 parser 的 typed 表达式/语句/稳定绑定并复制到
   comptime 私有 arena；普通函数遍历跳过已准备的 CT 函数。
4. **部分完成**：typed IR 执行器覆盖整数/布尔表达式、嵌套 `$g(...)`、局部 let/const
   槽、直接局部赋值、普通 if/else、条件 for、break/continue/return；递归共享 100000
   步预算与既有 64 帧上限。typed 诊断切片已交付：断言条件使用 typed 表达式边，消息
   来自函数源码快照，错误/警告按实际路径触发。暂未支持的 AST 子类继续走兼容 token
   执行器；typed `$if/$else` 和函数内区间 `$for` 也已按每次调用值选支/迭代并检查循环体。
   编译期函数调用表达式语句也会求值，以执行嵌套函数的诊断等编译期行为。普通 for-in 已实现整数区间和局部受支持数组/切片的元素/下标绑定、空范围及跳转；数组/切片下标读写与共享存储切片视图已完成。本地具名结构体支持整数或受支持结构体元素切片字段、嵌套结构体字段、结构体数组元素和多维定长数组字段初始化、链式成员读写与递归复制。数组及受支持结构体形参和嵌套 typed 返回均深复制；切片形参和普通结构体副本复制视图描述并保留共享元素存储；嵌套返回递归复制切片可见元素到调用方帧；顶层受支持数组/结构体/切片结果可物化为静态数据，或在外层 CT 调用中继续作为聚合值传递。静态数据发射延后输出切片 backing，以保持父结构和结构体数组布局连续；浮点/指针切片、联合体、其他非整数叶元素及一般左值仍待迁移。
5. **已完成首片测试**：`tests/yh-run/run/68-comptime-local-loop.yh` 从红转绿；
   `tests/modules/projects/comptimelocal/` 增加跨文件 typed IR 局部循环。继续增加错误/边界用例。
6. **首片门已通过**：模块项目验收 80/80，`make test`（156/156）及
   `make selfhost-native` 固定点/全量门通过；滚动 `make seed` 后新种子冷编与 SHA-256
