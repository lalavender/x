# yh 编译期 typed 切片返回实施方案

日期：2026-10-06。状态：**已交付**。

## 目标

允许 `@[comptime]` 函数在 typed 调用链中返回整数切片。被调函数返回前，
把切片可见元素复制到调用方帧，避免返回值指向已释放的局部存储；调用方
可以读取、写入并继续把切片传给嵌套编译期调用。

## 边界

- 只接受元素为整数的切片返回值；数组和结构体仍按值返回。
- 切片返回要求调用发生在 typed IR 调用帧中，直接 `$f(...)` 仍拒绝切片结果。
- 返回切片复制其可见区间，切片不再与被调方的局部数组或原调用方存储共享。
- 不开放切片字段、非整数切片元素或切片形参以外的其他借用关系。

## 实施与验收

1. 新增 `.yh` 正例覆盖返回局部数组切片、嵌套 typed 调用和调用方读写；更新旧反例为拒绝非整数元素切片。
2. 在 `comptime/` 中接受整数切片返回，并在被调帧销毁前复制元素到调用方帧。
3. 保持无调用方帧的顶层 `$` 结果拒绝切片，明确其仍不属于现有常量表示。
4. `make`、`make test`、`make selfhost-native`、模块项目门与 `git diff --check` 全绿；已滚种子并冷编。
