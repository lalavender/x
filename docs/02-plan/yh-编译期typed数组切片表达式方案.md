# yh 编译期 typed 数组/切片表达式方案

日期：2026-10-05。状态：**已完成**。

## 目标与边界

支持已类型化的 `base[start..end]`，使编译期本地整数数组/切片可以形成左闭右开的共享存储视图。视图必须保留别名关系：通过切片元素写入要更新原始数组/切片。合法边界满足 `0 <= start <= len` 与 `0 <= end <= len`；反向范围产生长度为零的视图，与 yh 运行期长度规则一致。指针、全局聚合、其他元素类型和通用切片值仍不在范围内。

## 步骤

1. 新增 run/76 覆盖嵌套切片视图、别名写入、for-in 与反向空范围；新增 fail/101 越界范围；扩展 `comptimelocal` 跨文件求值；先观察正例失败。
2. 为 `CtAggregate` 增加所有权标记；视图持有共享元素指针但不释放底层值，帧退出按链表逆构造顺序清理。
3. 解释 `AST_EXPR_SLICE`，验证基址、元素类型、边界并生成 view；新增视图统一纳入调用帧生命周期管理。
4. 运行 `make`、目标用例、`make test` 与 `make selfhost-native`，全绿后滚种子、冷编并校验哈希。

## 验收

`run/76` 验证嵌套视图的读写别名以及反向范围不迭代；`fail/101` 验证越界切片被拒；同模块跨文件项目验证导出编译期函数中的切片视图与别名写入。

## 实施结果

- typed IR 支持 `AST_EXPR_SLICE`，校验数组/切片源类型、整型边界和源长度；只有 `0 <= start,end <= len` 可通过，反向范围得到长度为零的视图。
- `CtAggregate` 增加所有权标记。新视图共享底层 `CtValue` 数组，支持嵌套视图和下标写入别名；帧清理只释放拥有存储的聚合，不会重复释放视图来源。
