# yh 编译期结构体元素切片实施方案

日期：2026-10-06。状态：已完成。

## 目标

让 typed 编译期执行器支持由已有受支持结构体元素构成的切片。`[]T` 继续共享
底层元素存储；通过切片写字段会修改底层结构体，切片形参保留别名；`for-in`
元素仍按值深复制。切片从被调帧返回时，复制可见结构体及其受支持字段到调用方帧，
最外层结果可按目标布局物化为静态数据。

## 范围

- 切片元素只扩展到现有 `ct_ir_struct_supported` 接受的结构体；元素结构体内部仍
  遵守既有字段限制和深度/总量预算。
- 覆盖定长结构体数组转切片、切片视图、下标和成员读写、for-in 值语义、切片形参、
  嵌套返回、顶层返回及全局静态数据物化。
- 整数切片行为保持不变；浮点、指针、联合体及其他不受支持的切片元素继续拒绝。

## 实施步骤

1. 新增单文件 `.yh` 正例，覆盖结构体切片别名写入、for-in 值复制、嵌套返回及全局/局部
   静态物化；在当前编译器上确认其失败。扩展现有 `comptimelocal` 项目并由模块入口断言。
2. 在 `compiler/comptime/` 集中扩展切片元素类型判定、结构体元素复制和递归静态序列化；
   保持调用帧所有权与结构体/数组按值复制规则。
3. 保留非整数且非受支持聚合切片元素的负例，更新诊断预期，并同步编译期执行设计文档。
4. 运行定向 `.yh` 用例、`make`、`make test`、`make selfhost-native` 与
   `git diff --check`。仅在两道完整门都通过后执行 `make seed`，再冷编并核对种子哈希。

## 成功标准

- 普通切片副本和形参别名可见结构体字段写入；for-in 绑定修改不写穿切片元素。
- 返回切片不引用已释放的被调帧；顶层切片静态数据中的结构体字段可由运行时代码读取。
- 原整数切片、数组/结构体复制、拒绝用例和完整自举门全部通过。
