# yh 编译期枚举 values 首片方案

日期：2026-10-06。状态：首片完成；CT4 后续字段反射仍待按用途规划。

## 目标

增加函数体内 `$for item in Enum.values { ... }`，按枚举成员声明顺序静态展开。
循环体内只提供只读的 `item.name` 与 `item.value`：名称是成员标识符的 NUL 结尾
静态字符串，值保留枚举类型。别名值不合并，空枚举展开为零轮。

## 边界与实现

- `Enum` 必须是当前模块可见的具名枚举；其他类型、未知类型和未支持的元信息成员均诊断拒绝。
- `$for` 仍只允许在函数体语句位置，整数区间语法保持 `$for i in (lo..hi)`。
- 两种循环共享单枚举最多 1024 轮及编译单元总展开预算；循环体不能修改迭代元信息。
- 普通函数解析时逐轮做语义检查和代码发射；`@[comptime]` 函数在 typed AST 准备期将每轮保存为 wrapper 下的独立块，调用时按顺序解释。
- 枚举成员在符号表中明确标记并由 `comptime/ct_enum.yh` 按声明顺序查询；元信息绑定不作为普通变量值逃逸。
- 本首片不实现 `T.fields`、类型值、动态成员名或任意源码生成。
