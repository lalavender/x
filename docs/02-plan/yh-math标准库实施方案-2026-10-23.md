# yh math 纯 yh 标准库实施方案（对齐 libc math 函数面）

日期：2026-10-23。状态：**P0 契约与探针已完成；P1–P7 待实施**（runner 与夹具骨架随 P1 落地）。
本版按用户决定改为**纯 yh 实现**：库内不引用宿主 libm，不写 `@[extern]`，
只用 yh 的 f64/u64/union/数组/循环；对外函数名与 `<math.h>` 保持一致。

**目标：** `libs/math/` 以同名函数提供 `double` 面（C 的 `f64`）、对应
`float` 面（C 的 `f` 后缀）、POSIX/BSD 补充与分类谓词；语义按 IEEE 754 与
C 标准，精度按 §1.4 的预算，不自研无法验证的近似。

**技术路线：** 以 fdlibm / musl 的算法与系数为准移植（两家许可均允许，
注释与 README 保留出处）；位级函数（取整、分解、`fmod`、`sqrt` 等）用整数
位模式实现并做到正确舍入；f32 变体复用 f64 内核后一次窄化，位级函数单独
实现。

## 0. 结论摘要

1. **普通 `pub fn`，不是 C ABI。** 编译产物是模块私有符号
   （按 `nm` 实测的模块符号格式，如 `_equals__yh_libs__string_$yhllvmv1`；math 会是 `_sqrt__yh_libs__math_$yhllvmv1` 形态），因此：① 不会覆盖
   进程里的 libm；② LLVM 不会把它当 libm 内建（`sqrt`/`sin`/`pow` 这类 C 名
   在 O2 可能被换成 intrinsic，从而绕过纯 yh 实现）；③ yh 用户看到的 API 名
   仍是 `math.sqrt`。C ABI 出口若以后需要，另加薄 shim，不在本方案里。
2. **算法移植而不是自创。** 指数/对数/幂/三角/误差函数/伽马/贝塞尔按
   fdlibm（Sun 许可）与 musl（MIT）的算法与系数移植；这些实现的设计目标
   本身就是 `<1 ULP`。文件头与 README 标注来源。
3. **精确函数正确舍入。** `fabs/copysign/nextafter/round/trunc/frexp/ldexp/
   fmod/remainder/sqrt` 等只用位运算与整数运算，误差 0 ULP。
4. **f32 变体是 f64 内核 + 一次窄化**，目标 ≤1 f32 ULP；`fabsf`、`nextafterf`、
   `frexpf`、`fmodf` 等位级函数直接按 32 位实现，不走 f64。
5. **公共 f64 常量仍后置。** 接口导出 `pub const f64` 当前损坏（位型当整数
   写出），本轮只交付函数与 `FP_*` int 常量；库内部常量用位模式构造，避开
   十进制字面量在极端指数上的误差。
6. **测试用宿主 libm 做差分参照，但不进库。** Python `ctypes` 调本机 libm，
   `.yh` 夹具用确定性 LCG 生成输入并写二进制结果，runner 按族计算 ULP/
   相对误差。

## 1. 契约

### 1.1 类型映射（LP64）

| C | yh | 说明 |
| --- | --- | --- |
| `double` | `f64` | 不提供 `*l`（long double） |
| `float` | `f32` | 只提供 ISO C 有 `f` 变体的函数 |
| `int` | `int`（i32） | 出参 `int *`、`ilogb` 返回值 |
| `long` / `long long` | `i64` | `lrint/llrint/lround/llround`、`scalbln` |
| `const char *` | `*char` | `nan`/`nanf` 的 payload |
| `double *` / `int *` | `*f64` / `*int` | `modf`、`frexp`、`remquo`、`lgamma_r` |

### 1.2 命名

- 双精度：与 `<math.h>` 完全一致（`sqrt`、`fabs`、`copysign`、`jn` …）。
- 单精度：与 C 完全一致（`sqrtf`、`fabsf`、`remquof` …）。
- 谓词：同名加 `_f32` 后缀（`isnan` / `isnan_f32`）；C 的谓词是宏，没有可
  对齐的函数名。
- 常量：`FP_*` 与 C 同拼写；`INFINITY/NAN/M_*` 见 §4。

### 1.3 语义与错误

- **IEEE 754 值语义**：NaN/±inf/±0 按标准传播；`sqrt(-1)` 返回 NaN、
  `sqrt(-0)` 返回 -0；`pow` 的特殊值组合按 C 附录 F。
- **不提供 errno/fenv**：域错误与上溢只体现在返回值；舍入模式固定为默认
  to-nearest；`errno` 读写与 `fesetround` 属于 libc L3/fenv，不在本模块。
- **线程安全**：所有函数无全局可变状态；`lgamma_r` 用显式 `int *sign`
  代替 `signgam`。
- **无分配**：所有表是模块私有 `const` 数组，运行期不调用 malloc。
- **性能**：纯 yh，单次调用比对 libm 的 C 调用慢（量级见 P7 实测），不在
  热循环里假装是 libm；接口稳定性优先。

### 1.4 精度口径

| 类别 | 目标 | 说明 |
| --- | --- | --- |
| 位级/精确函数 | **0 ULP（正确舍入）** | fabs、copysign、nextafter、round 家族、frexp/ldexp/scalbn、ilogb/logb、fmod/remainder/remquo、sqrt |
| 指数/对数/幂/三角/反三角/双曲 | **<1 ULP**（fdlibm 设计目标） | 实测最大 ULP 写入 README |
| expm1/log1p/asinh/acosh/atanh | **<2 ULP** | 小参数路径单独处理 |
| erf/erfc/lgamma/tgamma | **相对误差 ≤1e-15** | 极点/上溢按 C 语义 |
| 贝塞尔 j0/j1/jn/y0/y1/yn | **相对误差 ≤1e-13** | 大参数走渐近式 |
| f32 变体 | **≤1 f32 ULP** | f64 内核 + 一次窄化 |
| fma | **<1 ULP，不保证正确舍入** | 软件双精度补偿；如测试要求再改整数精确版 |

**不宣称**与宿主 libm 逐位相同：不同 libm 的最后一位本来就不同；验收看
ULP 预算而不是位相等。

### 1.5 依赖边界

库内只使用：f64/f32 四则与比较、`u64/i64/u32/i32` 位运算与移位、`union`
位重解释、模块私有 `const` 数组、`for` 循环、普通函数调用。**不出现**
`@[extern]`、`printf`、`malloc`、libm 符号；P7 用 `nm -u` 检查模块对象。

### 2.3 分类谓词（纯 yh）

| API | 返回 | 语义 |
| --- | --- | --- |
| `isnan` / `isnan_f32` | `bool` | 指数全 1 且尾数非 0 |
| `isinf` / `isinf_f32` | `bool` | 指数全 1 且尾数 0 |
| `isfinite` / `isfinite_f32` | `bool` | 指数不全 1 |
| `isnormal` / `isnormal_f32` | `bool` | 指数既非 0 也非全 1 |
| `signbit` / `signbit_f32` | `bool` | 符号位 |
| `fpclassify` / `fpclassify_f32` | `int` | `FP_*` |

`FP_*` 取 Linux 优先平台的稳定编号并写死（macOS 头文件是另一套，不跟随）：

```
FP_NAN = 0  FP_INFINITE = 1  FP_ZERO = 2  FP_SUBNORMAL = 3  FP_NORMAL = 4
```

不导出 `FP_ILOGB0`/`FP_ILOGBNAN`：两端 `ilogb(NaN)` 返回不同（macOS 为
INT_MIN，glibc 为 INT_MAX），导出任一个都会在一端说谎。

## 3. 算法设计

### 3.0 共享原语（`00_bits.yh`、`01_fma.yh`）

- `union Bits64 { f f64  u u64 }`、`union Bits32 { f f32  u u32 }` 与
  `bits_of/from_bits`；指数/尾数掩码常量。
- 指数提取：`(bits >> 52) & 0x7ff`；次正规数通过左移规范化。
- 软件 fma 原语：`two_sum`、`split`（27 位拆分）、`two_product`，用于
  `fma/fmaf`、`sqrt` 的最终校正、`hypot` 的补偿。
- 多项式求值统一 Horner；系数表为模块私有 `const [N]f64`。
- 缩放统一走内部 `scale2(x, k)`（按位加指数，含次正规与溢出），供
  `ldexp/scalbn/exp` 复用。

### 3.1 精确层（`10_exact.yh`、`15_round.yh`、`20_fmod.yh`）

- `fabs/fabsf`、`copysign/copysignf`、`signbit`：掩码。
- `fmax/fmin`：IEEE 754-2019 语义（一个 NaN 返回另一个；±0 相等时返回 +0）。
  `fdim(x,y) = x>y ? x-y : +0`，NaN 传播。
- `nextafter`：位步进（含跨 0、次正规、inf/nan）；`nextafterf` 按 32 位步进。
- `ldexp/scalbn/scalbln`：指数域相加，溢出→±inf，下溢→按就近偶数舍入到
  次正规/0；`scalbln` 的 `i64` 指数先夹取。
- `frexp`：拆分指数，次正规左移规范化；返回 `[0.5,1)`。
- `modf`：位截断取整后相减；保留 `-0`，inf/nan 直接返回。
- `ilogb/logb`：指数提取（次正规先规范化）；`ilogb(0/NaN/inf)` 值按
  宿主语义文档化（不导出常量）。
- `round/trunc/ceil/floor`：掩码取小数位；`round` 半值远离 0，`ceil/floor`
  保留 -0；`rint/nearbyint` 半值就近偶数。
- `lrint/llrint/lround/llround`：先取整再转 `i64`；越界为 C 未定义，文档
  注明实现取饱和（`to_type` 语义），测试不覆盖越界值。
- `fmod`：fdlibm `e_fmod` 的整数尾数对齐-相减算法，逐位归一；`y==0`/`x`
  非有限按 C 特殊值。
- `remainder`：fdlibm `e_remainder` 的最近商算法；`remquo` 同时回填商低 3 位。
- `nan(tag)`：解析 `"0x…"` 十六进制 payload（≤13 位）构造 quiet NaN；
  空/非法 payload 返回标准 qNaN；`nanf` 同理按 23 位尾数。
- 谓词与 `FP_*`（见 §2.3）。

### 3.2 根（`25_sqrt.yh`）

- `sqrt`：整数逐位开方（53 次迭代，u64 余数；指数奇偶对齐），得到正确
  舍入结果；次正规先规范化，`sqrt(-0)=-0`、负数→NaN。
- `sqrtf`：按 32 位尾数逐位开方（24 次），同样正确舍入。
- `cbrt`：指数按 3 取模分解 + 多项式初值 + 2–3 次牛顿迭代（目标 <1 ULP）。
- `hypot`：按较大指数缩放后 `sqrt(x²+y²)`，用 `two_product/two_sum` 补偿，
  避免中间上溢/下溢。

### 3.3 fma（`01_fma.yh`）

- `two_product` + `two_sum` 得到精确乘积的 hi/lo，再与 z 做压缩求和；
  目标 <1 ULP（不保证正确舍入）。
- `fmaf` 的 24+24 位乘积在 f64 内精确，求和后窄化；目标 ≤1 f32 ULP
  （双舍入的极少数边界除外）。

### 3.4 指数/对数（`30_exp.yh`、`35_log.yh`）

- `exp/exp2/expm1`：fdlibm `e_exp` 路线：`k = round(x/ln2)`，
  `r = x - k*ln2_hi - k*ln2_lo`，Horner 多项式，`scale2` 还原；
  `expm1` 小参数走专用多项式。
- `log/log2/log10/log1p`：`frexp` 拆 `m∈[√½,√2)`，`s=(m-1)/(m+1)` 的
  奇次多项式；`log1p` 小参数专用路径。
- 上溢/下溢阈值按 fdlibm 常量；`log(0)=-inf`、`log(-x)=NaN`。
- `log10/log2` 用 `log` + 精确拆分常数（`ln10_hi/lo`、`ln2_hi/lo`）。

### 3.5 幂（`40_pow.yh`）

- 移植 fdlibm `e_pow`：先按 C 附录 F 处理 0/±1/inf/NaN/负底数整数指数，
  再用两次 `log2`（hi/lo）+ `exp2` 组合，最后按低误差项校正。
- 整数指数走快速幂（平方乘），负指数取倒数；大指数范围检查。
- `powf` 用 f64 内核后窄化（目标 ≤1 f32 ULP）。

### 3.6 三角（`44_rem_pio2.yh`、`45_trig.yh`）

- 规约：`|x|` 小于阈值（约 2^20）用 Cody-Waite 三段 `2/π` 常数；
  更大用 Payne-Hanek（移植 fdlibm `__ieee754_rem_pio2` 的 2/π 位表，
  24 位分块，约 66 项，`const [66]u32`）。
- 核：`[-π/4, π/4]` 上的 minimax 多项式（fdlibm `k_sin/k_cos/k_tan`），
  按象限还原符号。
- `tan` 用 `k_tan` 单独实现；极大参数按规约后的象限结果返回。
- `sinf/cosf/tanf` 复用 f64 规约与核。

### 3.7 反三角/双曲（`50_inverse_trig.yh`、`55_hyper.yh`）

- `atan`：`|x|` 分段（>1 取倒数、>2^-27 用多项式），fdlibm `s_atan`。
- `atan2`：按象限与符号组合，含 ±0 与 inf 方向；fdlibm `e_atan2`。
- `asin/acos`：`asin(x)=atan(x/sqrt(1-x²))` 的小参数专用多项式 +
  `sqrt`，边界 ±1 精确；`acos` 用 `π/2 - asin` 的稳定形式。
- 双曲：`sinh/cosh/tanh` 用 `exp/expm1` 的分段（|x| 小、中、大），
  避免 `cosh` 上溢处的相消；`asinh/acosh/atanh` 用 `log1p/log`。

### 3.8 误差/伽马（`60_erf.yh`、`65_gamma.yh`）

- `erf/erfc`：fdlibm `s_erf` 的两段有理逼近 + `erfc` 尾部的 `exp(-x²)`
  缩放；相对误差 ≤1e-15，`erfc` 大参数下溢到 0。
- `lgamma/lgamma_r`：fdlibm `e_lgamma_r`（含负半轴反射与符号），
  `lgamma_r` 把符号写入出参。
- `tgamma`：Lanczos（g=7，双精度系数）+ 负半轴反射；整数极点返回 inf
  （C 语义），上溢 inf、下溢 ±0。
- `lgammaf_r`/`tgammaf`/`erff`/`erfcf` 复用 f64 内核后窄化。

### 3.9 贝塞尔（`70_bessel.yh`）

- `j0/j1/y0/y1`：fdlibm 的有理逼近 + 大参数渐近式（`sqrt(1/x)` 项），
  相对误差 ≤1e-13。
- `jn/yn`：向前递推（`jn` 对中间值做缩放避免上溢），`yn` 含负阶恒等式；
  阶数为负时按 `J_{-n}=(-1)^n J_n` 处理。
- 定义域：`y0/y1/yn` 在 x≤0 返回 NaN/-inf（按 C）。

### 3.10 f32 策略

- 位级函数（`fabsf/copysignf/fmaxf/fminf/fdimf/nextafterf/frexpf/ldexpf/
  scalbnf/scalblnf/modff/ilogbf/logbf/round` 家族/`fmodf/remainderf/remquof/
  sqrtf/nanf`）直接按 u32 位模式实现。
- 超越函数（`expf…powf`、三角、双曲、误差、伽马）用 f64 内核计算后
  `.to_type(f32)`；因为 f64 误差远小于 f32 半 ULP，窄化即正确舍入
  （边界中点除外，预算按 ≤1 f32 ULP）。
- `hypotf`、`cbrtf` 用 f64 内核；`fmaf` 在 f64 内精确后窄化。

## 4. 常量

| 阶段 | 常量 | 说明 |
| --- | --- | --- |
| P1 | `FP_NAN`…`FP_NORMAL`（int） | 可跨模块导出 |

做精确值（当前前端偏差已复现）。

## 5. 排除项

| 项目 | 原因 |
| --- | --- |
| 全部 `*l`、`nexttoward*` | yh 无 f80/f128；Linux/AArch64 `long double` 是 128 位 |
| complex.h / fenv.h | 独立头文件；无复数类型，且 fenv 会改舍入契约 |
| C23 新增（`roundeven`、`totalorder`、`fmaxmag`、`nextup`、`getpayload` …） | yh 没有对应标准面；可后续按需单独立项 |
| `exp10/pow10/sincos`、`sinpi/cospi/tanpi` | 非 ISO C（GNU/Apple 扩展），不属于「libc math 对外函数」 |
| `gamma`/`signgam` | 依赖 C 全局数据符号；用 `lgamma`/`lgamma_r` |
| float16、`*f32x`/`*f64` 别名 | yh 无对应类型 |
| `matherr`、`rinttol`/`roundtol` | 非标准 |

## 8. 测试与差分

- **runner**：`tests/math/run.py`，仿 `tests/string/run.py`
  （`--compiler`、`--stdlib`、`--workdir tmp/math-test`、`--group`、
  `--opt-level 0|2`）；fixture 复制到 tmp，失败非零退出。
- **输入生成**：夹具内置 xorshift64 LCG，按函数族的位模式范围生成输入；
  runner 用同一 LCG 复现输入，避免把上万条输入写进 `.yh`。
- **输出**：夹具用 `write(1, &bits, 8)` 写结果（u64 位模式，含 int 返回），
  二进制输出避免十进制/浮点格式化依赖。
- **参照**：runner 用 Python `ctypes` 调宿主 libm（macOS `CDLL(None)`，
  Linux `libm.so.6`）计算参考，按 §1.4 计算 ULP 或相对误差；NaN/±0/±inf
  单独判定。
- **边界集**：每族固定覆盖 ±0、最小次正规、最小正规、最大有限、±inf、
  NaN、半值、2 的幂边界、定义域边界；特殊函数另加极点与负半轴。
- **不做位比较的项**：`nan` 的 payload 由本模块规则构造、`ilogb(NaN/0)` 与
  宿主实现有关、`lrint/llrint/lround/llround` 越界是 C 未定义；这三类改写
  成本模块文档化的断言，不进 ULP 差分。
- **O2**：单独 `make test-math-o2`；纯 yh 实现的名字是 mangled，后端不会
  把它当 libm 内建折叠。
- **surface**：调用全部导出一次，防漏实现/漏 f32 变体。
- **不导入宿主 libm 做实现**：差分只发生在测试进程的 Python 侧。

## 9. 已探明事实（P0 证据）

探针在 `tmp/math-plan/`，当前种子 `./yh` 实测：

| 事实 | 证据 |
| --- | --- |
| 普通 `pub fn` 编译为模块私有符号 | `nm`：`_equals__yh_libs__string_$yhllvmv1` 等；因此不会与 libm 同名互撞，也不会被 LLVM 当内建 |
| 模块私有 `const [N]f64`、`const [N]u32` 可定义并在循环中索引 | 探针 `p11.yh` 前三项求和与 Python 一致 |
| 递归可用 | `fact(6)=720` |
| 二进制 stdout 可用 | `write(1,&u64,8)`，Python `struct.unpack` 正常 |
| union 位重解释可用（f64/f32） | `signbit(-0.0)`、f32 位模式、次正规构造均通过 |
| 精确 NaN/±inf 可构造 | `from_bits(0x7ff8…)`、`1e400`、`1e400-1e400` |
| 极端十进制字面量不精确 | `1e300`、`1e-300`、`DBL_MAX`、`2.2250738585072014e-308` 与正确位型不符（后者 +2 ULP）；π/0.1/1.5 精确 |
| `pub const f64` 跨模块导出损坏 | 导入侧报「浮点与整数之间需要 .to_type 显式转换」 |
| `return !bool` 退化为 i32 | `fn f(x bool) bool { return !x }` 报「整数不能隐式转为 bool」；条件位置正常 |
| `ilogb` 特例两端不同 | macOS：`ilogb(NaN)=INT_MIN`、`ilogb(inf)=INT_MAX`；glibc 的 NaN 为 INT_MAX |

## 10. 未决问题（本轮默认）

1. **C ABI 出口**：默认不提供；若需要 C 直接调用，另加 `@[extern]` shim
   （会引入 libm 同名覆盖与内建折叠风险，需单独评审）。
2. **公共 f64 常量**：默认后置到接口修复之后；若急需，可先以
   `pub fn` 访问器过渡，但会偏离 C 的常量拼写。
3. **fma 正确舍入**：默认 <1 ULP 软件补偿版；若验收要求正确舍入，再改用
   整数 106 位精确算法（成本更高）。
4. **贝塞尔/伽马精度**：默认 1e-13/1e-14 相对误差；如需与 glibc 位级一致，
   需要移植其专用实现，另行评估。
