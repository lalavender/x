# yh 编译期 typed 本地结构体字段方案

日期：2026-10-05。状态：**已完成**。

## 目标与边界

让 `@[comptime]` 函数可以创建本地结构体值，并读取、写入其整数成员。复用普通 parser 已完成的字段名解析、字段索引和类型检查，把结构体初始化列表保存为 typed IR；调用帧内按声明顺序保存字段 `CtValue`，成员表达式复用现有 `CtPlace` 读取/赋值路径。

本片只支持具名 `struct` 和整数类型字段，包含命名式与位置式字面量。拒绝联合体、嵌套结构/数组/切片字段、指针或浮点字段、结构体参数/返回、成员取址及通过非本地值访问成员。字段初始化表达式按源码顺序求值。

## 步骤

1. 新增 run/77 覆盖命名/位置式初始化、成员读写、嵌套编译期调用和结构体值复制；新增 fail/102 覆盖非整数字段；扩展 `comptimelocal` 跨文件 CT 函数；先确认现有执行器失败。
2. 在 parse AST 中添加结构体初始化根和字段初始化链节点，保留前端给出的字段表索引与已绑定字段值。
3. 在 comptime 帧中用有所有权的字段 `CtValue` 数组保存本地结构体值；实现结构体字面量求值、成员读、成员可写 place 和字段类型/索引校验。
4. 运行 `make`、目标语料、`make test` 与 `make selfhost-native`；全绿后滚种子、冷编并校验哈希。

## 验收

`run/77` 必须能写字段并由返回值观察结果，字段实参中的编译期调用可正常求值，复制后的字段修改不影响原值；`fail/102` 确认非整数字段被明确拒绝；跨文件项目调用验证函数正文仍按定义模块的类型和字段表执行。
