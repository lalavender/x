# yh 编译期 typed 浮点聚合元素实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

浮点标量在编译期已可用，但浮点**聚合元素**（定长数组元素、切片元素、结构体字段）
仍被拒绝。本片开放这些元素，使 `[3]f64`、`[]f64`、含 `f64` 字段的结构体在编译期
可构造、可写、可迭代、可作为形参与返回值，并可静态物化为顶层常量。

## 设计要点

- 支持判定：`ct_ir_array_supported`、`ct_ir_slice_elem_supported`、
  `ct_ir_struct_field_supported` 三个门把「整数叶」放宽为「整数或浮点叶」；
  指针元素、联合体仍拒绝。
- 元素归一：新增 `ct_ir_norm_scalar`（浮点按宽度窄化、整数按宽度与符号截断），
  统一替换元素克隆、字段写入、数组元素写入、局部声明与赋值等处的 `sem_fold_norm`。
- 静态物化：`ct_ir_data_value` 增加浮点分支——f64 直接发位模式，f32 先用
  `ct_ir_fp32_bits` 取单精度位模式（内部按 f64 位模式保存）。
- for-in 与聚合形参/返回沿用既有复制路径（`CtValue.value` 已承载位模式），无需特判。
- 诊断文本从「整数」改为「整数、浮点」，并保留既有 `fail-contains` 前缀子串。

## 边界

- 仍拒绝：指针元素数组/切片、指针叶结构体字段、浮点取址（`&values[0]` 仍是
  「整数局部变量或整数聚合元素」诊断）、联合体。
- 浮点切片的元素取址、浮点指针形参（`*f64`）继续拒绝。

## 实施步骤与验收

1. 放宽三个支持门；新增 `ct_ir_norm_scalar` 与 `ct_ir_fp32_bits`；接入数据发射。
2. 用例：run/136（数组元素写入、切片视图别名、结构体浮点字段、for-in 累加、
   顶层 f64/f32 数组与结构体物化）、改造 fail/103/105/129（改为指针元素情形）、
   fail/137（浮点元素取址仍拒绝）。
3. `comptimelocal` 增加浮点数组形参、浮点切片返回与顶层浮点切片物化断言。
4. 验证 `make`、`make test`、`make selfhost-native`；全绿后滚种子。
