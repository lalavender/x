# yh 编译期 typed 聚合返回实施方案

日期：2026-10-06。状态：**已交付**。

## 目标

支持编译期函数在嵌套 typed 调用中返回已支持的定长整数数组和受支持结构体。返回对象在被调帧释放前深复制到调用方帧，调用方可继续读取、复制和修改；不会留下指向已释放帧的地址。

顶层 `$f(...)` 仍只产生可进入现有常量系统的标量结果。切片返回暂不开放，因为返回视图可能指向即将释放的局部数组；联合体、指针和不支持的聚合类型继续拒绝。

## 实施步骤

1. 新增单文件与同模块跨文件 `.yh` 正例，覆盖数组/结构体返回、返回值在调用方修改，以及原值隔离；旧种子应在函数签名处拒绝。
2. 仅放宽 `parse_decl` 对受支持数组/结构体返回类型的签名检查。
3. 将调用方帧传入 typed 调用器；被调帧在释放前按返回类型深复制返回聚合到调用方帧。
4. token 兼容执行器与顶层常量接口继续拒绝聚合结果，避免悬垂生命周期或伪造标量常量。
5. 定向语料、`make`、`make test`、`make selfhost-native`、`git diff --check` 全绿后滚种子并冷编。
