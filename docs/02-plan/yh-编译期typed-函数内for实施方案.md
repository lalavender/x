# yh 编译期 typed 函数内 `$for` 实施方案

日期：2026-10-05。状态：**已交付**。

## 范围与语义

本切片让已准备的 `@[comptime] fn` 正文支持依赖本次调用值的 `$for i in (lo..hi)`。
边界在每次调用时通过 typed IR 求值，范围为左闭右开 `[lo, hi)`；循环变量 `i` 是只读
`i32` 绑定。循环体准备期只解析/类型检查一次，执行期逐轮更新绑定槽。

单区间沿用最多 1024 次的上限，调用树继续共享 100000 步预算；空区间不执行循环体。
普通函数中的 `$for` 仍在编译时按常量展开，顶层 `$for` 仍非法；for-in 语法、聚合迭代和
跨模块函数正文不在本切片；模块项目覆盖同模块多文件的定义与调用。
