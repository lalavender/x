# yh 前端浮点常量折叠实施方案

日期：2026-10-07。状态：已完成；滚动种子、冷编与自举主门均通过。

## 目标

前端常量折叠此前对浮点直接报「浮点常量折叠暂不支持」，导致
`const A f64 = 1.5 + 1.0;` 无法声明，普通函数里的 `$assert` 也不能比较浮点常量；
另外 `const A f64 = 1.5;` 虽能通过，但字面量没有把 IEEE754 位模式写入 `ival`，
常量引用读到的是 0。本片让前端折叠与编译期执行器的浮点语义一致。

## 设计要点

- 位模式统一：浮点常量值同时写入 `Res.ival` 与 `Res.fval_bits`（字面量、折叠结果、
  编译期函数物化三处一致），const 初始化按 `ival` 保存、浮点使用点读 `fval_bits`。
- 折叠实现：`sem_fold_float_binop`（算术与比较）、`sem_fold_const_unary` 的浮点分支、
  `sem_fold_float_convert`（整数↔浮点、浮点↔浮点、f32 窄化）。
- 冻结子集：一元负号走符号位翻转，浮点转无符号整数按有符号截断，不生成
  `fneg`/`fcvtzu`。
- 一元负号在常量路径不再把浮点常量改写成 `int`（此前浮点常量会落到整数一元分支）。

## 实施步骤与验收

1. `sem_number` 浮点字面量补 `ival`；`fp64_from_bits`/`fp64_norm_bits` 进入 gen 模块。
2. `sem_expr` 的浮点二元折叠入口、一元常量分支与转换折叠分支接入新辅助。
3. 用例：run/135（算术、比较、转换、f32 窄化、一元负号与常量引用）、
   fail/139（浮点取模仍拒绝）；`comptimelocal` 增加浮点常量折叠与浮点常量物化断言。
4. 验证 `make`、`make test`、`make selfhost-native`；全绿后滚种子。
