# yh 编译期 typed 数组/切片下标写入方案

日期：2026-10-05。状态：**已完成**。

## 目标与边界

支持编译期函数修改当前调用帧拥有的整型数组/切片元素，包括 `=` 和已支持的整数复合赋值。复用已类型化的 `AST_EXPR_INDEX` 左值；执行时解析出局部聚合与下标，验证可写绑定和边界，再更新对应 `CtValue`。

本片不开放指针/全局聚合写入、切片表达式、其他元素类型、结构体字段、取址或聚合参数/返回。

## 步骤

1. 新增 run/75 数组直接赋值与切片动态下标复合赋值，以及 fail/100 越界写入；先验证正例失败。
2. 在 comptime 私有 IR 中表示局部槽或聚合元素左值，执行赋值时统一处理读、整数运算、转换和写回。
3. 扩展 `comptimelocal` 跨文件修改并观察数组元素的回读。
4. 运行完整构建/测试/自举门；通过后滚种子、冷编并核对哈希。

## 实施结果

- `CtPlace` 表示局部槽或本地整型聚合元素；新增 `compiler/comptime/ct_ir_place.yh`，统一解析下标基址、元素类型和边界，读取与写入共用检查。
- 本地数组/切片下标支持 `=` 和当前已有的整数复合赋值；只允许当前调用帧可写的局部变量，越界和负下标均诊断失败。
