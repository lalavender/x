# 52 · 符号表：`put_elf_sym` / `find_elf_sym` / `set_elf_sym`

> **一句话**：TCC 的 `Sym` 是编译期的登记卡；`.symtab` 节里存的是**ELF 符号**。
> `put_extern_sym2`（第 37 篇）把前者发布成后者。查找用 ELF 哈希表，
> 合并（同名符号）用 `set_elf_sym` 的规则。
>
> 对应源码：`src/core/tccelf.c:323`（`put_elf_str`）、`:336`（`elf_hash`）、
> `:352`（`rebuild_hash`）、`:388`（`put_elf_sym`）、`:435`（`find_elf_sym`）、
> `:459`（`get_elf_sym_addr`）、`:490`（`set_elf_sym`）。

---

## 第 0 站：ELF 符号长什么样（`elf.h`）

```c
/* src/formats/elf.h 里 Elf64_Sym（概念） */
typedef struct {
    Elf64_Word  st_name;    /* 名字在 .strtab 里的偏移 */
    Elf64_Byte  st_info;    /* 绑定(STB_*) << 4 | 类型(STT_*) */
    Elf64_Byte  st_other;   /* 可见性(STV_*) */
    Elf64_Half  st_shndx;   /* 在哪个节（SHN_UNDEF = 未定义） */
    Elf64_Addr  st_value;   /* 值（地址/偏移） */
    Elf64_Xword st_size;    /* 大小 */
} Elf64_Sym;
```

第 37 篇 `put_extern_sym2` 填的就是这六项。TCC 的 `Sym.c` 存的是**这个表的数组下标**。

## 第 1 站：字符串表 —— `put_elf_str`（`tccelf.c:323`）

```c
/* src/core/tccelf.c:323-333 */
ST_FUNC int put_elf_str(Section *s, const char *sym)
{
    int offset, len;
    char *ptr;

    len = strlen(sym) + 1;
    offset = s->data_offset;      /* ★ 返回"名字在字符串表里的偏移" */
    ptr = section_ptr_add(s, len);
    memmove(ptr, sym, len);
    return offset;
}
```

**字符串表就是一堆 `\0` 结尾的字符串拼在一起**，符号的 `st_name` 是偏移。
多个符号名字相同？会各存一份（简单，但不省空间）。0 号偏移是空串。

## 第 2 站：写符号 —— `put_elf_sym`（`tccelf.c:388`）

```c
/* src/core/tccelf.c:388-433（节选）*/
ST_FUNC int put_elf_sym(Section *s, addr_t value, unsigned long size,
    int info, int other, int shndx, const char *name)
{
    int name_offset, sym_index;
    ...
    sym = section_ptr_add(s, sizeof(ElfW(Sym)));   /* 在 .symtab 追加一项 */
    if (name && name[0])
        name_offset = put_elf_str(s->link, name);  /* 名字存进 .strtab */
    else
        name_offset = 0;
    sym->st_name  = name_offset;
    sym->st_value = value;
    sym->st_size  = size;
    sym->st_info  = info;
    sym->st_other = other;
    sym->st_shndx = shndx;
    sym_index = sym - (ElfW(Sym) *)s->data;        /* ★ 返回下标 = Sym.c */
    hs = s->hash;
    if (hs) {
        if (ELFW(ST_BIND)(info) != STB_LOCAL) {
            /* 全局/弱符号要进哈希表 */
            nbuckets = base[0];
            h = elf_hash(...) % nbuckets;
            *ptr = base[2 + h];     /* 链到桶头 */
            base[2 + h] = sym_index;
            hs->nb_hashed_syms++;
            if (hs->nb_hashed_syms > 2 * nbuckets)
                rebuild_hash(s, 2 * nbuckets);     /* 装太多就扩容重建 */
        }
    }
    return sym_index;
}
```

**只有全局/弱符号进哈希表**——局部符号不会跨文件查，不用哈希。

哈希函数是 ELF 标准 `elf_hash`（`:336`），**不是**第 03 篇 `TokenSym` 用的那个。
因为 ELF 文件格式要求用标准哈希（链接器和动态加载器要用）。

## 第 3 站：查符号 —— `find_elf_sym`（`tccelf.c:435`）

```c
/* src/core/tccelf.c:435-456 */
ST_FUNC int find_elf_sym(Section *s, const char *name)
{
    ...
    nbuckets = ((int *)hs->data)[0];
    h = elf_hash(name) % nbuckets;
    sym_index = ((int *)hs->data)[2 + h];      /* 桶的第一个符号 */
    while (sym_index != 0) {
        sym = &((ElfW(Sym) *)s->data)[sym_index];
        name1 = (char *) s->link->data + sym->st_name;   /* 名字在 .strtab */
        if (!strcmp(name, name1))
            return sym_index;
        sym_index = ((int *)hs->data)[2 + nbuckets + sym_index];  /* 链上下一个 */
    }
    return 0;
}
```

**哈希表布局**（`rebuild_hash`，`:352`）：

```
[0]        nbuckets
[1]        nb_syms
[2..2+nb-1]      桶头数组（值 = 符号下标）
[2+nb ..]        每个符号的"链上下一个"数组
```

`get_elf_sym_addr`（`:459`）用它查地址，`tcc_get_symbol`（`:475`）是 libtcc 的公开版。

## 第 4 站：合并同名符号 —— `set_elf_sym`（`tccelf.c:490`）

同一个名字可能被多次定义/声明。`set_elf_sym` 是"**带规则的插入或更新**"：

```c
/* src/core/tccelf.c:490-574（节选）*/
ST_FUNC int set_elf_sym(Section *s, addr_t value, unsigned long size,
                       int info, int other, int shndx, const char *name)
{
    ...
    if (sym_bind != STB_LOCAL) {
        sym_index = find_elf_sym(s, name);   /* 已经存在？ */
        if (!sym_index) goto do_def;          /* 不存在：新增 */
        esym = ...;
        if (属性完全一样) return sym_index;
        if (esym->st_shndx != SHN_UNDEF) {    /* 已定义 */
            ... 可见性取更严格的 ...
            if (shndx == SHN_UNDEF) {
                /* 已定义后又来个未定义：忽略 */
            } else if (sym_bind == STB_GLOBAL && esym_bind == STB_WEAK) {
                goto do_patch;                /* ★ 全局覆盖弱符号 */
            } else if (sym_bind == STB_WEAK && esym_bind == STB_GLOBAL) {
                /* 已有全局，弱符号忽略 */
            } else if (sym_bind == STB_WEAK && esym_bind == STB_WEAK) {
                /* 弱+弱：保留先找到的 */
            } else if ((esym->st_shndx == SHN_COMMON || esym->st_shndx == bss)
                       && (shndx 是真实数据节)) {
                goto do_patch;                /* ★ 真实数据覆盖 common/bss */
            } else if (shndx == SHN_COMMON || shndx == bss) {
                /* 已有真实数据，common/bss 忽略 */
            } else {
                tcc_error_noabort("'%s' defined twice", name);
            }
        } else {
        do_patch:
            /* 用新的属性更新已有符号 */
            esym->st_info = ...; esym->st_shndx = shndx; ...
        }
    } else {
    do_def:
        sym_index = put_elf_sym(s, ...);      /* 局部符号直接新增 */
    }
    return sym_index;
}
```

这套规则实现了 C 的"**符号优先级**"：

| 情况 | 结果 |
|---|---|
| 全局 vs 弱 | 全局赢 |
| 真实数据 vs common/bss | 真实数据赢 |
| 已定义 vs 未定义 | 已定义赢 |
| 两个都定义 | 报错 `defined twice` |

**这就是链接器合并 `.o` 符号的基本规则**（第 59 篇会用同一套逻辑）。

## 第 5 站：TCC 的 `Sym` 与 ELF 符号的对应

```
TCC Sym                         ELF ElfSym
─────────                       ──────────
v（名字编号）        ──get_tok_str──►  st_name（.strtab 偏移）
r / type.t          ─────────────►  st_info（STT_FUNC/OBJECT）
VT_STATIC           ─────────────►  st_info 的绑定位（STB_LOCAL）
c                   ──下标────────►  .symtab 数组位置
（put_extern_sym2 填）           st_value/st_size/st_shndx
```

第 37 篇 `put_extern_sym2` 就是这座桥。`elfsym(sym)`（`tccgen.c:284`）用 `sym->c`
反查 `ElfSym`。

## 【动手小实验】

1. `int g; static int s;` 编译到 `.o`，`nm` / `readelf -s` 看绑定（GLOBAL/LOCAL）。
2. 两个文件各有 `int x;`（tentative），链接看是否合并（common 规则）。
3. 用 `objdump -t` 看符号表、`objdump -s -j .strtab` 看字符串表。
4. 写一个 `__attribute__((weak))` 符号，看 `STB_WEAK`。

## 【通关暗号】

```bash
printf 'int g=1; static int s=2; int main(void){return g+s;}\n' > /tmp/s.c
./tcc -c /tmp/s.c -o /tmp/s.o && objdump -t /tmp/s.o 2>/dev/null | grep -E ' g$| s$'
# 期望：g 是 g/GLOBAL，s 是 l/LOCAL
```

## 【常见卡点】

- **`Sym.c` 是 `.symtab` 下标**，`elfsym()` 转 `ElfSym*`。
- **`st_name` 是 `.strtab` 偏移**；字符串表就是 `\0` 串连。
- **只有全局/弱符号进 ELF 哈希表**。
- **`set_elf_sym` 实现符号优先级**（全局>弱，数据>common）。
- **TCC 用 ELF 标准哈希 `elf_hash`**，不是 `TokenSym` 的哈希。
