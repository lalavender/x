## 一、一句话讲清我们要干什么

TCC 是 Fabrice Bellard 写的一个很小的 C 编译器。它的性格是：

> **读一个词，立刻翻一个词。绝不先把整个程序抄成一张树再翻。**
> （这叫"单遍编译"，没有"语法树/AST"这个中间产物。）

我们要做的事，就是**沿着它的流水线走一遍**，每一站都：
1. 看输入是什么、输出是什么；
2. 贴出源码，一行一行讲；
3. 告诉你**为什么非这么写**（作者的取舍）；
4. 给你一条能跑的验证命令。

## 二、先记住 12 个"零件"的名字

读到后面，你会反复看到这些词。现在混个脸熟就行（第 10–15 篇会逐个拆开）：

| 名字 | 一句话（12 岁版） | 住哪 |
|---|---|---|
| `TokenSym` | 一个"名字"在内存里的唯一座位（比如 `main`） | `tcc.h:381` |
| `CType` | 一个 `int` 里塞下"这玩意儿是什么类型" | `tcc.h:405` |
| `SValue` | 值栈上的一张便利贴：这个值现在搁在哪、是什么类型 | `tcc.h:424` |
| `Sym` | 变量/函数/宏/标签的登记卡（一人分饰多角） | `tcc.h:465` |
| `Section` | 一条会自己变长的"纸带"（机器码写进 `.text`） | `tcc.h:492` |
| `BufferedFile` | 当前正在读的文件的"书签 + 缓冲区" | `tcc.h:554` |
| `TokenString` | 一串 token 存成的整数数组（宏的本体就是它） | `tcc.h:575` |
| `TCCState` | 整台机器的大账本（所有状态都挂在它身上） | `tcc.h:640` |
| `tok` | "当前这个词"的编号（全局变量） | `tccpp.c:30` |
| `tokc` | "当前这个词"附带的值/字符串 | `tccpp.c:31` |
| `vtop` | 值栈的栈顶指针 | `tccgen.c` |
| `file` | 当前文件的书签 | `tccpp.c:29` |

## 三、总流水线图（把这条线记在心里）

```
                 tcc.c  main()
                     │ 解析命令行、收集文件
                     ▼
        libtcc.c  tcc_add_file()  ── 嗅探：这是 C 源码？汇编？.o？.a？
                     │
                     ▼
        libtcc.c  tcc_compile()   ← 总装车间，setjmp 在这里按电梯
                     │
      ┌──────────────┼──────────────────────────┐
      ▼              ▼                          ▼
 -E 预处理      汇编文件 .s                   C 文件 .c
 tcc_preprocess  tcc_assemble()             tccgen_compile()
 (tccpp.c)       (tccasm.c)                 (tccgen.c)
                     │                          │
                     │         ┌────────────────┘
                     │         ▼
                     │   next()/next_nomacro()  ← tccpp.c 造 token
                     │         │
                     │         ▼
                     │   decl()/block()/expr_*()  ← tccgen.c 递归下降
                     │         │ 每认出一个结构，就调后端发机器码
                     │         ▼
                     │   gv()/gen_op()/gfunc_call()  ← tccgen.c 中间层
                     │         │
                     │         ▼
                     │   load()/store()/gen_opi()... ← targets/x86_64-gen.c 真发字节
                     │         │
                     │         ▼
                     │   机器码追加进 Section.data    ← tccelf.c 的"纸带"
                     │
                     ▼
        tcc_output_file()  →  elf_output_file() / pe_output_file()
                     │   ① 解符号 ② 定地址 ③ 回填重定位 ④ 写文件
                     ▼
        可执行文件   或   tcc_run() 直接在内存里跑（tccrun.c）
```

## 七、贯穿全程的"追兔子"例子

我们从 01 到 09 都用同一个程序当主角，方便你对照：

```c
/* t.c —— 第一部从头用到尾的主角 */
#define K 8
int add(int a, int b) { return a + b; }
int main(void) {
    int x = 3;
    int y = 2 * K;
    x = add(x, y);
    return x;          /* 期望退出码 = 19 */
}
```

第一部结束时，你会亲眼看到：`#define K 8` 变成一张录音带，
`2 * K` 在编译期就被心算成 16，而 `K` 这个名字**从来没有真正进入过 C 的语法分析**。
