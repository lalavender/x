## 第 0 站：编译一个文件前后的快照（`:140`）

```c
/* src/core/tccelf.c:139-152 */
ST_FUNC void tccelf_begin_file(TCCState *s1)
{
    Section *s; int i;
    for (i = 1; i < s1->nb_sections; i++) {
        s = s1->sections[i];
        s->sh_offset = s->data_offset;   /* ★ 记住每个节当前的尾部 */
    }
    /* 编译期间关闭符号哈希，加速（末尾才重建） */
    s = s1->symtab, s->reloc = s->hash, s->hash = NULL;
    ...
}
```

`tcc_compile`（第 01 篇）在每个文件开始时调它。**每个节记下"文件开始时的长度"**，
方便结束时把本文件新增的符号合并进全局符号表。

```c
/* src/core/tccelf.c:154-190（节选）*/
ST_FUNC void tccelf_end_file(TCCState *s1)
{
    Section *s = s1->symtab;
    int first_sym, nb_syms, *tr, i;

    first_sym = s->sh_offset / sizeof(ElfSym);       /* 本文件第一个符号 */
    nb_syms = s->data_offset / sizeof(ElfSym) - first_sym;
    s->data_offset = s->sh_offset;                    /* 回退符号表 */
    s->link->data_offset = s->link->sh_offset;        /* 回退字符串表 */
    s->hash = s->reloc, s->reloc = NULL;              /* 恢复哈希 */
    tr = tcc_mallocz(nb_syms * sizeof *tr);

    for (i = 0; i < nb_syms; ++i) {
        ElfSym *sym = (ElfSym*)s->data + first_sym + i;
        if (sym->st_shndx == SHN_UNDEF
            && ELFW(ST_BIND)(sym->st_info) == STB_LOCAL)
            sym->st_info = ELFW(ST_INFO)(STB_GLOBAL, ...);   /* 未定义局部→全局 */
        tr[i] = set_elf_sym(s, ...);      /* ★ 合并进全局符号表 */
    }
    /* 更新所有重定位里的符号下标 */
    for (i = 1; i < s1->nb_sections; i++) {
        Section *sr = s1->sections[i];
        if (sr->sh_type == SHT_RELX && sr->link == s) {
            for (rel ...) rel->r_info = ELFW(R_INFO)(tr[n], ...);
        }
    }
    ...
}
```

**为什么要"回退再合并"？** 因为一个 `.c` 文件编译时会往符号表里临时加符号；
结束时这些符号要**去重、合并**到全局符号表（同名符号可能已经在别处声明过）。
`tr[]` 是"临时下标 → 全局下标"的映射，重定位跟着改。

```c
{

    s->dynsymtab_section = new_symtab(s, ".dynsymtab", ...);
    get_sym_attr(s, 0, 1);
}
```

`new_symtab`（`:227`）一次造"符号表 + 字符串表 + 哈希表"三件套：

```c
/* src/core/tccelf.c:235-253（节选）*/
    symtab = new_section(s1, symtab_name, sh_type, sh_flags);
    symtab->sh_entsize = sizeof(ElfW(Sym));
    strtab = new_section(s1, strtab_name, SHT_STRTAB, sh_flags);
    put_elf_str(strtab, "");          /* 0 号字符串是空串 */
    symtab->link = strtab;            /* ★ symtab 的 link 是 strtab */
    put_elf_sym(symtab, 0, 0, 0, 0, 0, NULL);   /* 0 号符号 */
    hash = new_section(s1, hash_name, SHT_HASH, hash_sh_flags);
    symtab->hash = hash;
    hash->link = symtab;
```

**三个节互相挂钩**：`symtab->link = strtab`、`symtab->hash = hash`、`hash->link = symtab`。
第 52 篇的符号查找就靠这三者的关系。

## 第 2 站：申请空间（`:257-304`）

```c
/* src/core/tccelf.c:256-271 */
ST_FUNC void section_realloc(Section *sec, unsigned long new_size)
{
    unsigned long size = sec->data_allocated, ...;
    if (size == 0) size = 1;
    while (size < new_size) size = size * 2;        /* 翻倍 */
    data = tcc_realloc(sec->data, size);
    memset(data + sec->data_allocated, 0, size - sec->data_allocated);
    sec->data = data;
    sec->data_allocated = size;
}
```

## 第 3 站：找节（`:308`）

```c
/* src/core/tccelf.c:308-319 */
ST_FUNC Section *find_section(TCCState *s1, const char *name)
{
    Section *sec;
    int i;
    for(i = 1; i < s1->nb_sections; i++) {
        sec = s1->sections[i];
        if (!strcmp(name, sec->name))
            return sec;
    }
    return new_section(s1, name, SHT_PROGBITS, SHF_ALLOC);   /* 没有就建 */
}
```

线性 `strcmp`，节数量不多，不值得哈希。

## 【一次编译的节生命周期】

```
tcc_new:
  tccelf_new → 造 .text/.data/.bss/.symtab/.strtab/.hash

每个文件:
  tccelf_begin_file → 记 sh_offset 快照、关符号哈希
  ... 生成代码/数据、往节里写、登记临时符号 ...
  tccelf_end_file   → 回退、合并符号、修重定位下标

tcc_output_file:
  elf_output_file → 布局、重定位、写 ELF
```

## 【通关暗号】

```bash
printf 'int a=1; static int b=2; int main(void){return a+b;}\n' > /tmp/s.c
./tcc -c /tmp/s.c -o /tmp/s.o && nm /tmp/s.o 2>/dev/null | grep -E ' a$| b$'
# 期望：a 是全局(D)，b 是局部(d)
```

## 【常见卡点】

- **`tccelf_begin_file`/`end_file` 是一对快照/合并**。
- **符号表、字符串表、哈希表三者互相 `link`**。
- **`.bss` 不占实际数据**。
- **`section_add` 负责对齐**。
