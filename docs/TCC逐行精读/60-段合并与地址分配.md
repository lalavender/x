# 60 · 段合并与地址分配：`layout_sections`

> **一句话**：`layout_sections` 把内存里的几十条"节"组织成 ELF 的"段"，
> 给每个节算虚拟地址 `sh_addr` 和文件偏移 `sh_offset`，满足页对齐；
> 同时填好程序头（Program Header）。
>
> 对应源码：`src/core/tccelf.c:1563`（`layout_sections`）、
> `:1741`（`fill_unloadable_phdr`）、`:1290`（`tcc_output_binary`）、
> `src/formats/elf.h`（`ElfW(Phdr)` 定义）。

---

## 第 0 站：节 vs 段

- **节（Section）**：链接视角。`.text`、`.data`、`.rodata`、`.symtab`…
  每条有自己的名字、类型、对齐。
- **段（Segment / Program Header）**：加载视角。OS 加载器只看段。
  一个 `PT_LOAD` 段通常包含多个节。

TCC 把可加载的节分成两组：

```
PT_LOAD #1  PF_R | PF_X   （只读+可执行）← .text、.plt、.rodata…
PT_LOAD #2  PF_R | PF_W   （只读+可写）   ← .data、.got、.bss…
```

**为什么分两组？** 因为页保护：代码页不该可写，数据页不该可执行（安全性）。
缺点是有时一页要"复制"成两份（末尾那段）。

## 第 1 站：`layout_sections`（`tccelf.c:1563`）

```c
/* src/core/tccelf.c:1563-1581（节选）*/
static int layout_sections(TCCState *s1, ElfW(Phdr) *phdr, int phnum,
                           Section *interp, Section* strsec,
                           struct dyn_inf *dyninf, int *sec_order)
{
    int i, j, k, file_type, sh_order_index, file_offset;
    unsigned long s_align;
    addr_t addr;
    ...
    file_type = s1->output_type;
    sh_order_index = 1;
    file_offset = 0;
    if (s1->output_format == TCC_OUTPUT_FORMAT_ELF)
        file_offset = sizeof(ElfW(Ehdr)) + phnum * sizeof(ElfW(Phdr));  /* 头之后 */
    s_align = ELF_PAGE_SIZE;          /* 页大小 */
    ...
    if (phnum > 0) {
        if (s1->has_text_addr) { ... }       /* 指定了代码地址 */
        else {
            if (file_type == TCC_OUTPUT_DLL) addr = 0;   /* DLL 从 0 开始 */
            else                             addr = ELF_START_ADDR;  /* 可执行 */
            addr += (file_offset & (s_align - 1));
        }

        ph = &phdr[0];
        if (interp) ph += 2;              /* 留两个给 .interp / 程序头 */

        for(j = 0; j < 2; j++) {          /* ★ 两遍：RX 段、RW 段 */
            ph->p_type = PT_LOAD;
            if (j == 0) ph->p_flags = PF_R | PF_X;
            else        ph->p_flags = PF_R | PF_W;
            ph->p_align = s_align;
```

### 1a. 节的排序类别（`:1629`）

```c
            /* 每种段里的节按这个顺序摆：
               interp > 符号表/字符串/哈希 > 重定位 > PROGBITS > NOBITS */
            for(k = 0; k < 5; k++) {
                for(i = 1; i < s1->nb_sections; i++) {
                    s = s1->sections[i];
                    if (j == 0) {
                        if ((s->sh_flags & (SHF_ALLOC | SHF_WRITE)) != SHF_ALLOC)
                            continue;             /* RX 段：只要只读可执行 */
                    } else {
                        if ((s->sh_flags & (SHF_ALLOC | SHF_WRITE)) !=
                            (SHF_ALLOC | SHF_WRITE))
                            continue;             /* RW 段：只要可写 */
                    }
                    /* 按 k 决定这类节放第几轮 */
                    if (s == interp)                       { if (k != 0) continue; }
                    else if (DYNSYM/STRTAB/HASH)           { if (k != 1) continue; }
                    else if (SHT_RELX)                     { if (k != 2) continue; }
                    else if (SHT_NOBITS)                   { if (k != 4) continue; }
                    else                                   { if (k != 3) continue; }
                    sec_order[sh_order_index++] = i;       /* 记录输出顺序 */
```

**排序用 `k` 分 5 轮**，每轮扫所有节挑出对应类别。O(5×节数)，节数不多，够快。

### 1b. 对齐 + 分配（`:1662`）

```c
                    tmp = addr;
                    addr = (addr + s->sh_addralign - 1) & ~(s->sh_addralign - 1);
                    file_offset += (int)(addr - tmp);   /* 文件偏移同步对齐 */
                    s->sh_offset = file_offset;          /* ★ 文件偏移 */
                    s->sh_addr = addr;                   /* ★ 虚拟地址 */

                    /* 段头信息 */
                    if (ph->p_offset == 0) {
                        ph->p_offset = file_offset;
                        ph->p_vaddr = addr;
                        ph->p_paddr = ph->p_vaddr;
                    }
                    ...
                    addr += s->sh_size;                  /* 下一条节的地址 */
                    if (s->sh_type != SHT_NOBITS)
                        file_offset += s->sh_size;       /* .bss 不占文件 */
```

**核心就是对每条选中的节：先把 `addr`/`file_offset` 对齐到 `sh_addralign`，
把值写进 `sh_addr`/`sh_offset`，再前进 `sh_size`。**
`SHT_NOBITS`（`.bss`）只占地址、不占文件。

### 1c. 段信息（`:1707`）

```c
            ph->p_filesz = file_offset - ph->p_offset;   /* 段在文件里多大 */
            ph->p_memsz = addr - ph->p_vaddr;            /* 段在内存里多大 */
            ph++;
```

`p_filesz != p_memsz` 的情况正是 `.bss`：文件里没有，内存里有。

### 1d. 不可加载的节（`:1724`）

```c
    /* 其余节（.symtab/.strtab/.shstrtab 等）跟在后面 */
    for(i = 1; i < s1->nb_sections; i++) {
        s = s1->sections[i];
        if (phnum > 0 && (s->sh_flags & SHF_ALLOC))
            continue;                        /* 已被上面处理过 */
        sec_order[sh_order_index++] = i;
        file_offset = (file_offset + s->sh_addralign - 1) & ~(s->sh_addralign - 1);
        s->sh_offset = file_offset;
        if (s->sh_type != SHT_NOBITS) file_offset += s->sh_size;
    }
    return file_offset;
```

**这些节不进内存段**，只放在文件里（调试器/链接器用）。

## 第 2 站：`sec_order` 的作用

`sec_order[]` 记录"输出时节的顺序"。写文件时（`tcc_write_elf_file`）
按这个顺序写，而不是按节号顺序。**物理布局和逻辑编号可以不同。**

## 【一个可执行文件的地址布局】

```
0x0000000000400000  ELF Header + Program Headers
0x0000000000400xxx  .interp
0x0000000000400xxx  .note.* 
0x0000000000401xxx  .text        ← PT_LOAD #1 (R-X)
                    .plt
                    .rodata
0x0000000000402xxx  ── 页边界 ──
0x0000000000403xxx  .init_array
                    .data        ← PT_LOAD #2 (RW-)
                    .got
                    .bss         ← 文件里没有，内存里有
文件末尾            .comment
                    .symtab
                    .strtab
                    .shstrtab
```

## 【动手小实验】

1. `readelf -l a.out` 看两个 `LOAD` 段，注意 `Flags`（R E / RW）和 `MemSiz` vs `FileSiz`。
2. `readelf -S a.out` 看每个节的 `Addr`、`Off`、`Size`。
3. 观察 `.bss` 的 `FileSiz` 是 0 还是被算进段（看 `MemSiz > FileSiz`）。
4. `tcc -Wl,-Ttext=0x8000000` 指定代码地址（如果支持）看变化。

## 【通关暗号】

```bash
printf 'int g=1; int b; int main(void){return g+b;}\n' > /tmp/l.c
./tcc /tmp/l.c -o /tmp/l && readelf -l /tmp/l 2>/dev/null | grep -E 'LOAD|FileSiz|MemSiz' | head
# 期望：至少两个 LOAD 段，其中一个 MemSiz > FileSiz（.bss）
```

## 【常见卡点】

- **节是链接视角，段是加载视角**，一个段含多个节。
- **两个 `PT_LOAD`：RX 和 RW**，为了页保护。
- **`.bss` 不占文件，只占内存**（`p_memsz > p_filesz`）。
- **`sec_order` 记录输出顺序**，和节号无关。
- **对齐同时影响地址和文件偏移**。
