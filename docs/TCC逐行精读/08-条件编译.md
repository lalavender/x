# 08 · 条件编译与 include：哪些代码"当没看见"

> **本步输入**：`#if` / `#ifdef` / `#ifndef` / `#else` / `#elif` / `#endif` / `#include`
> **本步输出**：被跳过的代码段"像不存在一样"；被 include 的头文件接上输入流
>
> 对应源码：`src/core/tccpp.c:1714`（`preprocess` 分发所有 `#` 指令）、
> `src/core/tccpp.c:917`（`preprocess_skip` 跳过整块代码）、
> `src/core/tccpp.c:1426`（`expr_preprocess` 算 `#if` 的值）、
> `src/core/tcc.h:750`（`ifdef_stack` 那叠"开关"）。

---

## 第 0 站：`#` 指令的总调度台（`tccpp.c:1714`）

第 02 篇说，行首 `#` 会调 `preprocess()`。它就是一堆 `case`：

```c
/* src/core/tccpp.c:1714-1729 */
ST_FUNC void preprocess(int is_bof)
{
    TCCState *s1 = tcc_state;
    int i, c, n, saved_parse_flags;
    ...
    saved_parse_flags = parse_flags;
    parse_flags = PARSE_FLAG_PREPROCESS | PARSE_FLAG_TOK_NUM
        | PARSE_FLAG_TOK_STR | PARSE_FLAG_LINEFEED
        | (parse_flags & PARSE_FLAG_ASM_FILE);

    next_nomacro();       /* 读 # 后面的指令名 */
 redo:
    switch(tok) {
    case TOK_DEFINE:  ... parse_define(); break;      /* 第 06 篇 */
    case TOK_UNDEF:   ... define_undef(...); break;
    case TOK_INCLUDE:
    case TOK_INCLUDE_NEXT: ... 打开头文件 ... break;
    case TOK_IFNDEF: ...
    case TOK_IF: ...
    case TOK_IFDEF: ...
    case TOK_ELSE: ...
    case TOK_ELIF: ...
    case TOK_ENDIF: ...
    case TOK_LINE: ...
    case TOK_ERROR:
    case TOK_WARNING: ...
    case TOK_PRAGMA: pragma_parse(s1); break;
    case TOK_LINEFEED: goto the_end;
    default:
        ... tcc_warning("Ignoring unknown preprocessing directive ..."); ...
    }
 the_end:
    parse_flags = saved_parse_flags;
}
```

`parse_flags` 在这一段被临时改成"预处理模式"：需要 `TOK_NUM/TOK_STR` 把数字字符串变值，
需要 `TOK_LINEFEED` 把换行当指令结束。**`#` 指令处理完立刻还原。**

## 第 1 站：那叠开关 —— `ifdef_stack`（`tcc.h:750`）

条件编译的本质是"**一个开关栈**"：

```c
/* src/core/tcc.h:750-751 */
int ifdef_stack[IFDEF_STACK_SIZE];   /* 每遇到一个 #if 就压一个值 */
int *ifdef_stack_ptr;                /* 栈顶 */
```

每格是一个小整数，含义用**两个 bit** 表示：

| 值 | bit0（现在这段算不算） | bit1（前面有没有分支命中过） |
|---|---|---|
| 0 | 不算 | 没有 |
| 1 | **算** | 没有 |
| 2 | 不算 | 有 |
| 3 | **算** | 有 |

为什么需要 bit1？看 `#else`：

```c
/* src/core/tccpp.c:1893-1899 */
    case TOK_ELSE:
        if (s1->ifdef_stack_ptr == s1->ifdef_stack)
            tcc_error("#else without matching #if");
        if (s1->ifdef_stack_ptr[-1] & 2)
            tcc_error("#else after #else");      /* 已经有了 else */
        c = (s1->ifdef_stack_ptr[-1] ^= 3);      /* ★ 异或 3：翻转两个 bit */
        goto test_else;
```

**`^= 3` 就是"把 bit0 和 bit1 都翻过来"**：

- 原来是 `1`（这段算，前面没人命中）→ `2`（这段不算，因为已经命中过了）；
- 原来是 `0`（这段不算）→ `3`（这段算，前面没人命中）。

**一个异或，就实现了 `#else` 的语义。** 精妙。

`#if` / `#ifdef` / `#ifndef` 怎么压栈：

```c
/* src/core/tccpp.c:1867-1892 */
    case TOK_IFNDEF:
        c = 1;
        goto do_ifdef;
    case TOK_IF:
        c = expr_preprocess();       /* ★ 算 #if 后面表达式的真假 */
        goto do_if;
    case TOK_IFDEF:
        c = 0;
    do_ifdef:
        next_nomacro();
        if (tok < TOK_IDENT)
            tcc_error("invalid argument for '#if%sdef'", c ? "n" : "");
        if (is_bof) {
            if (c) {
                file->ifndef_macro = tok;   /* 记录 #ifndef 保护宏（提速用） */
            }
        }
        c = (define_find(tok) != 0) ^ c;    /* #ifdef: c^0; #ifndef: c^1 */
    do_if:
        if (s1->ifdef_stack_ptr >= s1->ifdef_stack + IFDEF_STACK_SIZE)
            tcc_error("memory full (ifdef)");
        *s1->ifdef_stack_ptr++ = c;    /* ★ 压栈，栈顶上升 */
        goto test_skip;
```

- `#ifdef X`：`c = (X 是否定义) ^ 0`。
- `#ifndef X`：`c = (X 是否定义) ^ 1`，取反。

`test_skip` 决定要不要跳过：

```c
/* src/core/tccpp.c:1916-1922 */
    test_skip:
        if (!(c & 1)) {          /* ★ bit0 == 0：这段不算 */
            preprocess_skip();   /* 跳过整块，直到 #else/#elif/#endif */
            is_bof = 0;
            goto redo;           /* 回到 switch 重新看指令（可能是 #else） */
        }
        break;                   /* bit0 == 1：这段要，继续正常读 */
```

**"跳过"不是逐字符读，而是 `preprocess_skip` 一口气跳到配对的 `#else`/`#elif`/`#endif`。**

## 第 2 站：跳过整块 —— `preprocess_skip`（`tccpp.c:917`）

```c
/* src/core/tccpp.c:917-1005（节选）*/
static void preprocess_skip(void)
{
    int a, start_of_line, c, in_warn_or_error;
    uint8_t *p;

    p = file->buf_ptr;
    a = 0;                       /* a = 嵌套的 #if 深度 */
redo_start:
    start_of_line = 1;
    in_warn_or_error = 0;
    for(;;) {
    redo_no_start:
        c = *p;
        switch(c) {
        case ' ': case '\t': case '\f': case '\v': case '\r':
            p++; goto redo_no_start;
        case '\n':
            file->line_num++; p++; goto redo_start;
        case '\\':
            file->buf_ptr = p;
            c = handle_eob();
            ... 处理缓冲区边界 ...
            p = file->buf_ptr; goto redo_no_start;
        case '\"':
        case '\'':
            if (in_warn_or_error) goto _default;
            p = parse_pp_string(p, c, NULL);   /* ★ 跳过字符串（不收集内容） */
            break;
        case '/':
            ... 跳过注释 ...
            break;
        case '#':
            p++;
            if (start_of_line) {
                file->buf_ptr = p;
                next_nomacro();                /* 读 # 后面的指令名 */
                p = file->buf_ptr;
                if (a == 0 && 
                    (tok == TOK_ELSE || tok == TOK_ELIF || tok == TOK_ENDIF))
                    goto the_end;              /* ★ 找到平级的收尾指令，停 */
                if (tok == TOK_IF || tok == TOK_IFDEF || tok == TOK_IFNDEF)
                    a++;                       /* 嵌套更深 */
                else if (tok == TOK_ENDIF)
                    a--;
                else if (tok == TOK_ERROR || tok == TOK_WARNING)
                    in_warn_or_error = 1;
                ...
            }
            break;
        default:
            p++;
            break;
        }
        start_of_line = 0;
    }
 the_end: ;
    file->buf_ptr = p;
}
```

三个要点：

1. **`a` 是嵌套深度**。遇到里层的 `#if` 就 `a++`，`#endif` 就 `a--`，
   只有 `a == 0` 时的 `#else`/`#elif`/`#endif` 才是本层要停的地方。
2. **它会跳过字符串和注释**，因为 `#if 0` 块里可能写着 `"#endif"` 这种文字，
   不能被误认成指令。**这就是为什么要"认真跳过"而不是 `strstr` 找 `#endif`。**
3. **它传 `NULL` 给 `parse_pp_string`**，意思是"只扫过去，不要内容"，省内存。

## 第 3 站：算 `#if` 的值 —— `expr_preprocess`（`tccpp.c:1426`）

`#if` 后面可以是一个完整的 C 常量表达式：

```c
#if defined(FOO) && FOO > 3
```

`expr_preprocess` 的做法很聪明：**把这一行"预处理化"，再交给正常的常量表达式解析器**。

```c
/* src/core/tccpp.c:1426-1468 */
static int expr_preprocess(void)
{
    int c, t;
    TokenString *str;

    str = tok_str_alloc();
    pp_expr = 1;                              /* 标记"正在算 #if" */
    while (tok != TOK_LINEFEED && tok != TOK_EOF) {
        next();                               /* ★ 先做宏替换 */
        if (tok == TOK_DEFINED) {
            next_nomacro();
            t = tok;
            if (t == '(') next_nomacro();
            if (tok < TOK_IDENT) expect("identifier");
            c = define_find(tok) != 0;        /* defined(X)：算布尔 */
            if (t == '(') { next_nomacro(); if (tok != ')') expect("')'"); }
            tok = TOK_CINT;                   /* 变成一个数字 0/1 */
            tokc.i = c;
        } else if (tok >= TOK_IDENT) {
            /* ★ 未定义的标识符在 #if 里当 0 */
            tok = TOK_CINT;
            tokc.i = 0;
        }
        tok_str_add_tok(str);                 /* 收进临时 token 串 */
    }
    pp_expr = 0;
    tok_str_add(str, -1); /* 模拟文件结束 */
    tok_str_add(str, 0);
    /* 现在当普通常量表达式求值 */
    begin_macro(str, 1);
    next();
    c = expr_const();                         /* ★ 复用 C 表达式求值器 */
    end_macro();
    return c != 0;
}
```

关键三步：

1. **`next()` 先做宏替换**：`#if K > 3` 里的 `K` 先被展开。
2. **`defined(X)` → `TOK_CINT(0/1)`**；**未定义标识符 → `0`**（C 标准规定）。
3. **变成一串数字 token，交给 `expr_const()`**（那是 `tccgen.c` 的常量表达式解析器，
   第 3 部会看到）。**预处理器不重复造一个表达式求值器，而是复用 C 的。**

> **这是 TCC 一个漂亮的复用**：`#if` 的表达式和 C 里的 `case`、数组大小、
   全局初始化值，用的是同一套常量表达式解析代码。

## 第 4 站：`#include` 怎么打开头文件（`tccpp.c:1747-1864`）

`#include` 是"打开新文件，接上输入流"。核心逻辑：

```c
/* src/core/tccpp.c:1747-1864（节选）*/
    case TOK_INCLUDE:
    case TOK_INCLUDE_NEXT:
        ch = file->buf_ptr[0];
        skip_spaces();
        if (ch == '<') { c = '>'; goto read_name; }       /* <...> 形式 */
        else if (ch == '\"') { c = ch; }                  /* "..." 形式 */
        read_name:
            inp();
            q = buf;
            while (ch != c && ch != '\n' && ch != CH_EOF) {   /* 读文件名进 buf */
                *q++ = ch;
                if (ch == '\\') ... else inp();
            }
            *q = '\0';
            minp();
        ...
        /* 保存当前文件到 include 栈 */
        *s1->include_stack_ptr = file;
        i = tok == TOK_INCLUDE_NEXT ? file->include_next_index : 0;
        n = 2 + s1->nb_include_paths + s1->nb_sysinclude_paths;   /* 搜索路径数 */
        for (; i < n; ++i) {
            ...
            if (i == 0) { /* 绝对路径 */ }
            else if (i == 1) { /* 相对当前文件目录，仅限 "..." */ }
            else { /* 依次在 -I 和系统目录里找 */ }
            pstrcat(buf1, sizeof(buf1), buf);
            e = search_cached_include(s1, buf1, 0);      /* ★ 查缓存 */
            if (e && (define_find(e->ifndef_macro) || e->once == pp_once)) {
                /* 头文件有 #ifndef 保护且宏已定义 → 整个跳过 */
                goto include_done;
            }
            if (tcc_open(s1, buf1) < 0)                   /* 打开文件 */
                continue;
            file->include_next_index = i + 1;
            ... 记录依赖 ...
            ++s1->include_stack_ptr;                      /* ★ 压 include 栈 */
            tok_flags |= TOK_FLAG_BOF | TOK_FLAG_BOL;     /* 新文件从头开始 */
            ch = file->buf_ptr[0];
            goto the_end;                                 /* 结束，回主循环读新文件 */
        }
        tcc_error("include file '%s' not found", buf);
```

搜索顺序（非常重要的 C 语义）：

1. `i == 0`：文件名是绝对路径，直接用；
2. `i == 1`：`"..."` 形式时，先找**当前文件所在目录**；
3. 之后：依次 `-I` 指定的目录，再系统目录。

**头文件保护优化**：`search_cached_include` 记住每个头文件的
"`#ifndef` 保护宏"。如果这个宏已经定义，说明头文件内容已经进过一次，
直接 `goto include_done` 跳过，**连文件都不用打开**。这是 TCC 编译速度的一个来源。

打开文件后：`tcc_open`（第 01 篇）造新书签并挂上 `file`，
`++s1->include_stack_ptr` 压栈。当新文件读完时，
第 02 篇 `next_nomacro1` 的 `CH_EOF` 分支会 `tcc_close()` + 弹栈，回到旧文件。

## 第 5 站：`#endif` 与"文件末尾"的配合（`tccpp.c:1923-1940`）

```c
/* src/core/tccpp.c:1923-1940 */
    case TOK_ENDIF:
        if (s1->ifdef_stack_ptr <= file->ifdef_stack_ptr)
            tcc_error("#endif without matching #if");
        s1->ifdef_stack_ptr--;                       /* ★ 弹栈 */
        /* 如果开头是 #ifndef，且现在回到文件开始的层次，说明"保护到头了" */
        if (file->ifndef_macro &&
            s1->ifdef_stack_ptr == file->ifdef_stack_ptr) {
            file->ifndef_macro_saved = file->ifndef_macro;
            file->ifndef_macro = 0;
            while (tok != TOK_LINEFEED) next_nomacro();
            tok_flags |= TOK_FLAG_ENDIF;             /* 标记给第 02 篇用 */
            goto the_end;
        }
        break;
```

这个 `TOK_FLAG_ENDIF` 标记会在第 02 篇那个"读到文件末尾"的分支里被用到：
把"这个头文件的保护宏"记进 include 缓存，**下次 include 直接跳过**。

## 【把一段条件编译走一遍】

输入：

```c
#define FOO 1
#if defined(FOO) && FOO > 0
int a = 1;
#else
int a = 2;
#endif
```

1. `#if` → `expr_preprocess`：
   - `defined(FOO)` → `TOK_CINT(1)`；
   - `&&` 原样；
   - `FOO` 被 `next()` 展开成 `1`，再变成 `TOK_CINT(1)`；
   - `> 0` 原样；
   - 得到 `1 && 1 > 0` → `expr_const()` → 1。
2. `do_if` 把 `1` 压进 `ifdef_stack`，`test_skip` 看到 bit0=1，**不跳过**，
   正常读 `int a = 1;`。
3. 读到 `#else`：`^= 3` 把 `1` 变 `2`，`test_else` 后 `test_skip` 看到 bit0=0，
   调 `preprocess_skip()` 跳过 `int a = 2;`，直到 `#endif`。
4. `#endif` 弹栈。

结果：只有 `int a = 1;` 进入编译。

## 【通关暗号】

```bash
printf '#if 1\nint main(void){return 7;}\n#else\nint main(void){return 9;}\n#endif\n' > /tmp/i.c
./tcc -run /tmp/i.c; echo $?
# 期望：7
```

## 【常见卡点】

- **`ifdef_stack` 里的值是 `0/1/2/3`**：bit0=现在算不算，bit1=前面是否命中过；
  `#else` 用 `^=3` 翻转。
- **"跳过"是认真的**：会识别字符串和注释，不会把 `#endif` 文字误判成指令。
- **`#if` 表达式复用 C 常量求值器**，预处理器不单独实现。
- **include 缓存**：`#ifndef` 保护宏已定义时，连文件都不打开。
