# 31 · 三元 `?:` 与跳转链机制总复习

> **一句话**：`a ? b : c` 要生成"两条分支 + 汇合"。难点是：两分支结果类型不同怎么办？
> 两分支各自用不同寄存器怎么办？TCC 用 `gen_cast` 统一类型、`move_reg` 统一寄存器。
>
> 对应源码：`src/core/tccgen.c:5480`（`expr_cond`）、`:5467`（`condition_3way`）、
> `:1118`（`gaddrof`）、`src/core/tccgen.c:1103`（`move_reg`）。

---

## 第 0 站：回顾第 17 篇的三元骨架

```c
/* src/core/tccgen.c:5480-5537（再贴一遍骨架）*/

{
    ...
    expr_lor();                       /* 条件 */
    if (tok == '?') {
        next();
        c = condition_3way();         /* 编译期定真假？-1=不知道 */
        g = (tok == ':' && gnu_ext);  /* GNU 的 a ?: b（省略中间） */

        } else {
            if (!g) vpop();

        }

            if (c == 0) nocode_wanted++;     /* 条件恒假：真分支不生成 */
            if (!g) gexpr();                 /* 真分支 */

            skip(':');
            u = 0;

            if (c == 0) nocode_wanted--;
            if (c == 1) nocode_wanted++;     /* 条件恒真：假分支不生成 */
            expr_cond();                     /* 假分支（右结合） */
            if (c == 1) nocode_wanted--;

            ...
            /* 分别 cast + gv，保证落到同一寄存器 */
            ...
        }
    }

```

**两大难点**：① 两分支类型可能不同；② 两分支的代码分别生成，结果要在同一位置。

## 第 1 站：类型统一（`tccgen.c:5544-5594`）

C 的三元规则：两分支类型不同时按"公共类型"转换。

```c
/* src/core/tccgen.c:5544-5594（节选）*/
            type.ref = NULL;
            if (is_float(bt1) || is_float(bt2)) {
                /* 浮点：取更宽 */
                if (bt1 == VT_LDOUBLE || bt2 == VT_LDOUBLE) type.t = VT_LDOUBLE;
                else if (bt1 == VT_DOUBLE || bt2 == VT_DOUBLE) type.t = VT_DOUBLE;
                else type.t = VT_FLOAT;
            } else if (bt1 == VT_LLONG || bt2 == VT_LLONG) {
                /* 取 long long，按规则定 unsigned */
                ...
            } else if (bt1 == VT_PTR || bt2 == VT_PTR) {
                /* 有一个是空指针常量 → 取另一个的类型 */
                if (is_null_pointer(vtop)) type = type1;
                else if (is_null_pointer(&sv)) type = type2;
                else type = type1;
            } else if (bt1 == VT_FUNC || bt2 == VT_FUNC) {
                type = bt1 == VT_FUNC ? type1 : type2;
            } else if (bt1 == VT_STRUCT || bt2 == VT_STRUCT) {
                type = bt1 == VT_STRUCT ? type1 : type2;
            } else if (bt1 == VT_VOID || bt2 == VT_VOID) {
                type.t = VT_VOID;
            } else {
                /* 整数：取更宽 */
                type.t = VT_INT | (VT_LONG & (t1 | t2));
                if (有 unsigned) type.t |= VT_UNSIGNED;
            }
```

这段和 `gen_op` 的类型提升（第 22 篇）思路一样。**但三元是"两分支独立生成后统一"**，
所以要分别 `gen_cast`。

## 第 2 站：结构体的左值处理（`:5595-5641`）

三元返回结构体时，有段特殊处理：

```c
/* src/core/tccgen.c:5595-5608（节选）*/
            /* 保持结构体左值：把 (expr ? a : b) 变成 *(expr ? &a : &b)，
               这样 (expr ? a : b).mem 不会报 "lvalue expected" */
            islv = (vtop->r & VT_LVAL) && (sv.r & VT_LVAL) && VT_STRUCT == (type.t & VT_BTYPE);
            islv &= c < 0;

            if (c != 1) {
                gen_cast(&type);
                if (islv) { mk_pointer(&vtop->type); gaddrof(); }   /* 取地址 */
                else if (VT_STRUCT == (vtop->type.t & VT_BTYPE)) gaddrof();
            }
```

**如果两分支都是结构体左值，就对它们取地址**，三元结果变成指针，
最后再 `indir()` 回来——这样 `(c ? a : b).field` 合法。

## 第 3 站：结果落到同一寄存器（`:5610-5650`）

```c
/* src/core/tccgen.c:5610-5650（节选）*/
            rc = RC_INT;
            if (is_float(type.t)) { rc = RC_FLOAT; ... }
            else if ((type.t & VT_BTYPE) == VT_LLONG) {
                /* long long 用固定寄存器，避免复杂的移动 */
                rc = RC_IRET;
            }

            tt = r2 = 0;
            if (c < 0) {
                r2 = gv(rc);          /* ★ 假分支的值装进寄存器，记下是哪个 */
                tt = gjmp(0);         /* 假分支结束 → 跳到汇合点 tt */
            }
            gsym(u);                  /* 回填真分支的跳转到汇合点 */

            if (c != 0) {
                *vtop = sv;           /* 恢复真分支的值 */
                gen_cast(&type);
                if (islv) { mk_pointer(&vtop->type); gaddrof(); }
                else if (VT_STRUCT == (vtop->type.t & VT_BTYPE)) gaddrof();
            }

            if (c < 0) {
                r1 = gv(rc);          /* 真分支的值装进寄存器 r1 */
                move_reg(r2, r1, type.t);  /* ★ 把它挪到假分支用的 r2 */
                vtop->r = r2;
                gsym(tt);
                if (islv) indir();
            }
```

**核心**：

1. 先给假分支 `gv(rc)`，得到寄存器 `r2`；
2. 真分支也 `gv(rc)`，得到 `r1`；
3. **`move_reg(r2, r1, ...)` 把真分支结果搬到 `r2`**——这样不管走哪条分支，
   结果都在 `r2`；
4. `vtop->r = r2`，三元表达式的结果就是 `r2`。

> 为什么不一开始就规定"两分支都用 `r2`"？
> 因为两分支代码是独立生成的，真分支生成时不知道假分支用了哪个寄存器。
> **先各自生成、再搬到一个公共寄存器**是最简单的修法。

## 第 4 站：跳转链机制总复习

到现在你已经见过 TCC 所有"控制流"的实现，它们都基于同一套机制：

| 原语 | 作用 |
|---|---|
| `gjmp(t)` | 发无条件跳转，挂到链 `t`，返回新链头 |
| `gjmp_addr(a)` | 发跳转到已知地址 `a`（自动选短/长） |
| `gsym(t)` | 把链 `t` 回填到"当前位置" |
| `gsym_addr(t, a)` | 把链 `t` 回填到地址 `a` |
| `gvtst(inv, t)` | 把栈顶值变成条件跳转，挂到链 `t` |
| `gtst(inv, t)` | 后端：按 `VT_CMP`/`VT_JMP` 发条件跳转 |
| `gtst_addr(inv, a)` | 条件跳转到已知地址 |

**统一的心智模型**：

```
生成时：不知道地址 → 发跳转 + 把"欠条"串成链
确定时：gsym → 遍历链，回填每条跳转的位移
```

所有 `if`/`while`/`for`/`do`/`switch`/`goto`/`&&`/`||`/`?:` 都是这套原语的不同组合。

## 第 5 站：`move_reg` 复习（`:1103`）

```c
/* src/core/tccgen.c:1101-1115 */
static void move_reg(int r, int s, int t)
{
    SValue sv;
    if (r != s) {
        save_reg(r);          /* 目标里若有旧值先存走 */
        sv.type.t = t;
        sv.type.ref = NULL;
        sv.r = s;
        sv.c.i = 0;
        load(r, &sv);         /* 把 s 装进 r */
    }
}
```

`move_reg` 在**三元、函数返回值、类型不匹配**等场景把值搬到指定寄存器。

## 【把 `(a > b) ? x : y` 走一遍】

| 步骤 | 生成的代码 |
|---|---|
| 1 | 求 `a > b`，得到 `VT_CMP` |
| 2 | `gvtst(1,0)` | `jle L_else`（链 `tt`） |
| 3 | 真分支 `x` | `mov eax,[x]`（`r1=eax`，记进 `sv`） |
| 4 | `gjmp(0)` | `jmp L_join`（链 `u`） |
| 5 | `gsym(tt)` | `L_else:` |
| 6 | 假分支 `y` | `mov ecx,[y]`（`r2=ecx`） |
| 7 | 假分支结束 | `jmp L_join2`（链 `tt`） |
| 8 | `gsym(u)` | `L_join:` —— 真分支也到这里 |
| 9 | 真分支 `gv` + `move_reg(ecx, eax)` | `mov ecx,eax` |
| 10 | `gsym(tt)` | `L_join2:` 汇合 |
| 11 | 结果 | 在 `ecx` |

## 【动手小实验】

1. 写 `int r = (a>b) ? a : b;`，反汇编看有没有 `move`/`cmov`。
2. 写 `double r = (a>b) ? 1.5 : 2.5;`，看浮点分支怎么统一。
3. 写 `(a?b:c).field`（两分支都是结构体），看指针化处理。
4. 写 `1 ? x : y`，确认假分支完全没生成。

## 【通关暗号】

```bash

./tcc -run /tmp/t.c; echo $?
# 期望：5
```

## 【常见卡点】

- **两分支类型先统一，再分别 `gen_cast`**。
- **两分支结果用 `move_reg` 搬到同一寄存器**。
- **结构体左值三元取地址再解引用**，保证 `.field` 合法。
- **所有控制流都基于 `gjmp`/`gsym`/`gvtst` 这套跳转链原语**。
