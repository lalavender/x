# 50 · 内联汇编与内置汇编器（选读）

> **一句话**：TCC 自带一个汇编器——既能汇编整个 `.s` 文件，也能把 C 里的
> `asm("...")` 字符串当场汇编进当前函数。它复用同一套词法器和"纸带"。
>
> 对应源码：`src/core/tccasm.c:850`（`tcc_assemble_internal`）、
> `:911`（`tcc_assemble`）、`:930`（`tcc_assemble_inline`）、`:1082`（`asm_instr`）、
> `src/targets/i386-asm.c`（x86 操作码表）、`i386-asm.h`、`x86_64-asm.h`。

## 第 1 站：汇编主循环 —— `tcc_assemble_internal`（`tccasm.c:850`）

```c
/* src/core/tccasm.c:849-908（节选）*/
static int tcc_assemble_internal(TCCState *s1, int do_preprocess, int global) {
  int opcode;
  int saved_parse_flags = parse_flags;

  parse_flags = PARSE_FLAG_ASM_FILE | PARSE_FLAG_TOK_STR;
  if (do_preprocess)
    parse_flags |= PARSE_FLAG_PREPROCESS;
  for (;;) {
    next();                          /* ★ 复用词法器！ */
    if (tok == TOK_EOF) break;
    ...
  redo:
    if (tok == '#') {
      /* gas 注释 */
      while (tok != TOK_LINEFEED) next();
    } else if (tok >= TOK_ASMDIR_FIRST && tok <= TOK_ASMDIR_LAST) {
      asm_parse_directive(s1, global);    /* .text/.data/.globl 等指令 */
    } else if (tok == TOK_PPNUM) {
      /* 数字开头的是局部标签（如 1:） */
      n = strtoul(tokc.str.data, &p, 10);
      asm_new_label(s1, asm_get_local_label_name(s1, n), 1);
      next(); skip(':'); goto redo;
    } else if (tok >= TOK_IDENT) {
      opcode = tok;
      next();
      if (tok == ':') {
        asm_new_label(s1, opcode, 0);     /* 标签 */
        next(); goto redo;
      } else if (tok == '=') {
        set_symbol(s1, opcode);           /* 符号赋值 */
        goto redo;
      } else {
        asm_opcode(s1, opcode);           /* ★ 汇编一条指令 */
      }
    }
    if (tok != ';' && tok != TOK_LINEFEED) expect("end of line");
    ...
  }
  ...
}
```

**关键点：汇编器用的还是 `next()`/`tok`/`tokc` 那套词法器**（`tccpp.c`）。
所以 `.s` 文件同样支持 `#include`、`#define`（`do_preprocess` 为真时）。
**一套词法，两个消费者（C 前端和汇编器）。**

## 第 2 站：`.s` 文件入口 —— `tcc_assemble`（`:911`）

```c
/* src/core/tccasm.c:910-922 */
ST_FUNC int tcc_assemble(TCCState *s1, int do_preprocess) {
  int ret;
  tcc_debug_start(s1);
  /* 默认节是 .text */
  cur_text_section = text_section;
  ind = cur_text_section->data_offset;   /* ★ 代码位置 = .text 当前偏移 */
  nocode_wanted = 0;
  ret = tcc_assemble_internal(s1, do_preprocess, 1);
  cur_text_section->data_offset = ind;   /* 收尾，把 ind 写回 */
  tcc_debug_end(s1);
  return ret;
}
```

**汇编器也往 `cur_text_section` 的 `ind` 位置写字节**——
和第 45 篇的 `g()` 完全一样。所以汇编和 C 生成的目标文件是同一种纸带。

## 第 3 站：C 内联汇编 —— `tcc_assemble_inline`（`:930`）

```c
/* src/core/tccasm.c:927-942 */
/* 在当前 C 编译单元里汇编字符串 str，不做 C 预处理 */
static void tcc_assemble_inline(TCCState *s1, char *str, int len, int global) {
  const int *saved_macro_ptr = macro_ptr;
  int dotid = set_idnum('.', IS_ID);     /* 汇编里 '.' 是标识符字符 */

  tcc_open_bf(s1, ":asm:", len);         /* ★ 造一个假文件 */
  memcpy(file->buffer, str, len);
  macro_ptr = NULL;
  tcc_assemble_internal(s1, 0, global);  /* 汇编这段字符串 */
  tcc_close();

  set_idnum('.', dotid);
  macro_ptr = saved_macro_ptr;
}
```

**和第 07 篇 `paste_tokens` 一样的技巧**：造一个假 `BufferedFile`（名字 `":asm:"`），
把字符串塞进去，然后让汇编器当文件读。**不用为字符串单独写一套输入逻辑。**

## 第 4 站：GCC 扩展内联汇编 —— `asm_instr`（`:1082`）

GCC 风格的内联汇编带有约束（constraints）：

```c
int x = 1, y;
asm("movl %1, %0" : "=r"(y) : "r"(x));
```

`asm_instr`（`tccasm.c:1082`）负责：

1. 解析汇编模板字符串；
2. 用 `parse_asm_operands`（`:1027`）读输入/输出操作数（`"=r"(y)` 等）；
3. `subst_asm_operands`（`:984`）把 `%0`、`%1` 替换成实际的寄存器名/内存引用；
4. `tcc_assemble_inline` 汇编替换后的字符串。

`find_constraint`（`:947`）解析约束字符（`r`=寄存器、`m`=内存、`=`输出、`+`读改写…），
`ASMOperand` 结构（`tcc.h:614`）存每个操作数的信息。

**这是 TCC 里最复杂的部分之一**，但思路就是"字符串替换 + 复用汇编器"。

## 第 6 站：汇编器的指令与符号（`:430`）

```c
/* src/core/tccasm.c:430 起 asm_parse_directive 处理 .section/.globl/.byte 等 */
```

常见指令：

| 汇编指令 | 对应 TCC 操作 |
|---|---|
| `.text` / `.data` / `.bss` | `use_section`（切换 `cur_text_section`） |
| `.globl name` | 把符号设成全局 |
| `.byte` / `.word` / `.long` | 往当前节写数据 |
| `.align n` | 对齐 |
| `.section name` | 指定节 |
| `label:` | `asm_new_label` |

它们大多直接调用第 14 篇的 `Section` 函数。

## 【把 `asm("nop")` 走一遍】

1. C 前端 `unary`/`block` 遇到 `asm` → `asm_instr()`；
2. 解析字符串 `"nop"`；
3. `tcc_assemble_inline(":asm:", "nop", 3, 0)`；
4. `tcc_assemble_internal` 读 token `nop`，查操作码表，发 `0x90`；
5. 字节写进 `cur_text_section`（当前 C 函数的 `.text`）；
6. 关闭假文件，继续编 C。

**汇编指令和 C 生成的指令混在同一条纸带上。**

## 【动手小实验】

1. 写 `asm("nop"); int f(){return 0;}`，反汇编找 `90`。
2. 写 `asm volatile("")` 看是否报错。
3. 写一个 `.s` 文件（`int f(){...}` 的汇编写法），用 `tcc -c` 汇编它。
4. 写 `asm("movl %1, %0":"=r"(y):"r"(x));` 看生成的 `mov`。

## 【常见卡点】

- **汇编器和 C 前端共用词法器**（`next`/`tok`/`tokc`）。
- **内联汇编用假文件（`:asm:`）承载字符串**。
- **汇编指令写进同一条 `.text` 纸带**。
- **GCC 约束靠字符串替换 + 复用汇编器**。
- **64 位汇编器在 `src/targets/*-asm.c` + `*-asm.h`。**
