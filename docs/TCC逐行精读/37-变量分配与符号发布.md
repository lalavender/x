# 37 · 变量分配与符号发布：`decl_initializer_alloc` / `put_extern_sym2`

> **一句话**：一个变量声明要经历"算大小 → 分配空间（栈或数据段）→ 登记 ELF 符号
> → 处理初始化"。`decl_initializer_alloc` 是总调度，`put_extern_sym2` 负责发布符号。
>
> 对应源码：`src/core/tccgen.c:6818`（`decl_initializer_alloc`）、
> `:338`（`put_extern_sym2`）、`:292`（`update_storage`）、`:284`（`elfsym`）、
> `src/core/tccelf.c:388`（`put_elf_sym`，第 52 篇）。

```c

                            addr_t value, unsigned long size,
                            int can_add_underscore)
{
    int sym_type, sym_bind, info, other, t;
    ElfSym *esym;
    const char *name;
    ...
    if (!sym->c) {                        /* 第一次：新建 ELF 符号 */
        name = get_tok_str(sym->v, NULL);
        ...
        t = sym->type.t;
        if ((t & VT_BTYPE) == VT_FUNC)      sym_type = STT_FUNC;    /* 函数 */
        else if ((t & VT_BTYPE) == VT_VOID) sym_type = STT_NOTYPE;
        else                                sym_type = STT_OBJECT;  /* 变量 */
        if (t & VT_STATIC)  sym_bind = STB_LOCAL;   /* static → 局部 */
        else                sym_bind = STB_GLOBAL;  /* 否则全局 */
        other = 0;
        ...

            name = get_tok_str(sym->asm_label, NULL);

        sym->c = put_elf_sym(symtab_section, value, size, info, other, sh_num, name);
        /* ★ sym->c 就是 ELF 符号表里的下标 */
    } else {                                /* 已存在：更新位置 */
        esym = elfsym(sym);
        esym->st_value = value;
        esym->st_size = size;
        esym->st_shndx = sh_num;

    update_storage(sym);                    /* 再应用 static/weak/visibility */
}
```

关键三步：

1. **`sym->c` 存的是 ELF 符号表下标**（第 13 篇说 `Sym.c` "或 ELF 符号索引"）。
   `elfsym(sym)`（`:284`）就是 `&symtab_section->data[sym->c]`。
2. **`STT_FUNC/STT_OBJECT`** 区分函数和变量。
3. **`st_shndx`** 是"在哪个节"；`SHN_UNDEF` 表示未定义（外部引用）。

`put_extern_sym` 是只传 Section 的包装：


## 【把 `int g = 5;` 走一遍】

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | `type_size(int)` | `size=4, align=4` |
| 2 | `has_init=1` → `sec = data_section` | |
| 3 | `addr = section_add(.data, 4, 4)` | 比如 0 |
| 4 | `sym_push("g", ...)`，`put_extern_sym(sym, .data, 0, 4)` | ELF 符号：`g`，`STT_OBJECT`，`STB_GLOBAL`，value 0 |
| 5 | `decl_initializer` → `init_putv` | `.data[0..3] = 05 00 00 00` |

`int g;`（无初值）则 `sec = .bss`，不写字节，只登记 `st_size=4`。

## 【动手小实验】

1. 编译 `int g=5; int h; static int s;` 到 `.o`，`nm` 看 `g`(D)、`h`(B)、`s`(b)。
2. `objdump -h` 看 `.data`/`.bss` 大小。
3. `int a[]={1,2,3,4};` 用 `nm` 看符号大小是不是 16。
4. 在某函数里 `int x[10];`，反汇编看 `sub rsp, ...` 怎么给栈分配空间。

## 【通关暗号】

```bash
printf 'int g=5; int h; int main(void){return g+h;}\n' > /tmp/g.c
./tcc -c /tmp/g.c -o /tmp/g.o && nm /tmp/g.o 2>/dev/null | grep -E ' g$| h$'
# 期望：g 在 D（.data），h 在 B（.bss）
```

## 【常见卡点】

- **`Sym.c` 是 ELF 符号下标**，`elfsym()` 转成 `ElfSym*`。
- **局部变量 `c` 是栈偏移；全局变量 `c` 是符号下标**（union 复用）。
- **`int a[]={...}` 先干跑算大小**。
- **`static` → `STB_LOCAL`**，`weak` → `STB_WEAK`。
- **`.data` 有初值，`.bss`/`.common` 无初值**。
