# 05 · 字符串与字符常量：`"a\n"` 和 `'x'` 怎么变成字节

> **本步输入**：`TOK_PPSTR` 的原始文本，比如 `"a\n"`（含引号）或 `L'中'`
> **本步输出**：`tok = TOK_STR` / `TOK_CCHAR` / `TOK_LSTR` / `TOK_LCHAR`，
> 以及 `tokc.str.data`（字节）或 `tokc.i`（字符值）
>
> 对应源码：`src/core/tccpp.c:853`（`parse_pp_string` 扫原始文本）、
> `src/core/tccpp.c:2015`（`parse_escape_string` 解释转义）、
> `src/core/tccpp.c:2187`（`parse_string` 总调度）、
> `src/core/tccpp.c:339/362`（`cstr_ccat` / `cstr_wccat` 往缓冲里加字节/宽字符）。

---

## 第 0 站：为什么要分两步？

第 02 篇说词法阶段只把字符串**原文**（连引号、连 `\n` 两个字符）存进 `TOK_PPSTR`。
为什么不当场解释转义？

因为预处理器**不认识转义**！看这个宏：

```c
#define S "abc" "def"     /* 两个字符串拼接 */
```

以及：

```c
#define LOG(x) "value=" #x
```

如果词法阶段就把 `\n` 变成换行符，宏拼接时就没法正确处理原始文本了。
所以必须**先原样保留，等真正给 C 语法分析用的时候再解释**。

分工：

| 函数 | 干什么 | 什么时候 |
|---|---|---|
| `parse_pp_string` | 从字符流扫到配对引号，**原样**收集 | 词法阶段（第 02 篇） |
| `parse_string` | 去掉引号/`L`，调度 | `next()` 里 `PARSE_FLAG_TOK_STR` |
| `parse_escape_string` | 解释 `\n`、`\x41`、宽字符 | 上面调它 |

## 第 1 站：扫描原始文本 —— `parse_pp_string`（`tccpp.c:853`）

```c
/* src/core/tccpp.c:852-913 */
/* 扫描一个字符串，不做转义解释。sep 是引号字符（' 或 "） */
static uint8_t *parse_pp_string(uint8_t *p, int sep, CString *str)
{
    int c;
    p++;                          /* 跳过开引号 */
    for(;;) {
        c = *p;
        if (c == sep) {
            break;                /* ★ 遇到配对引号，结束 */
        } else if (c == '\\') {
            file->buf_ptr = p;    /* 反斜杠：可能是缓冲区墙也可能是转义 */
            c = handle_eob();
            p = file->buf_ptr;
            if (c == CH_EOF) {
            unterminated_string:
                tcc_error("missing terminating %c character", sep);
            } else if (c == '\\') {
                /* 真是反斜杠：检查是不是 \<换行> 续行 */
                PEEKC_EOB(c, p);
                if (c == '\n') {
                    file->line_num++;    /* 续行：吃掉，不写进缓冲 */
                    p++;
                } else if (c == '\r') {
                    PEEKC_EOB(c, p);
                    if (c != '\n') expect("'\n' after '\r'");
                    file->line_num++;
                    p++;
                } else if (c == CH_EOF) {
                    goto unterminated_string;
                } else {
                    if (str) {              /* ★ 普通转义：原样收两个字符 */
                        cstr_ccat(str, '\\');
                        cstr_ccat(str, c);
                    }
                    p++;
                }
            }
        } else if (c == '\n') {
            file->line_num++;
            goto add_char;              /* 字符串里不能有裸换行，但先收着由后面报错 */
        } else if (c == '\r') {
            PEEKC_EOB(c, p);
            if (c != '\n') {
                if (str) cstr_ccat(str, '\r');
            } else {
                file->line_num++;
                goto add_char;
            }
        } else {
        add_char:
            if (str) cstr_ccat(str, c);  /* 普通字符：收进缓冲 */
            p++;
        }
    }
    p++;
    return p;                          /* 返回闭引号之后的位置 */
}
```

四个要点：

1. **它不解释 `\n`**：碰到 `\` 后，只要不是续行，就把 `\` 和后面的字符**两个都收进去**。
   所以 `"a\n"` 收进来是 4 个字节：`a`、`\`、`n`。**解释留给下一站。**
2. **`sep` 参数**同时处理 `"` 和 `'`（字符常量也是字符串形式扫的）。
3. **续行 `\<换行>` 被吃掉**：编译器看不到它，但行号要加 1。
4. **`str` 可以是 NULL**：`preprocess_skip` 跳过 `#if 0` 里的字符串时传 NULL，
   表示"只要扫过去，不要内容"——**同一个扫描器，两种用途**。

## 第 2 站：总调度 —— `parse_string`（`tccpp.c:2187`）

```c
/* src/core/tccpp.c:2187-2233 */
static void parse_string(const char *s, int len)
{
    uint8_t buf[1000], *p = buf;
    int is_long, sep;

    if ((is_long = *s == 'L'))       /* 是不是 L"..." / L'...' */
        ++s, --len;
    sep = *s++;                      /* 取引号字符 */
    len -= 2;                        /* 扣掉两个引号 */
    if (len >= sizeof buf)
        p = tcc_malloc(len + 1);     /* 太长就堆分配，短就用栈上 buf */
    memcpy(p, s, len);
    p[len] = 0;

    cstr_reset(&tokcstr);
    parse_escape_string(&tokcstr, p, is_long);   /* ★ 解释转义 */
    if (p != buf)
        tcc_free(p);

    if (sep == '\'') {               /* 字符常量 'x' */
        int char_size, i, n, c;
        if (!is_long)
            tok = TOK_CCHAR, char_size = 1;
        else
            tok = TOK_LCHAR, char_size = sizeof(nwchar_t);
        n = tokcstr.size / char_size - 1;    /* 减 1 是去掉结尾的 '\0' */
        if (n < 1)
            tcc_error("empty character constant");
        if (n > 1)
            tcc_warning("multi-character character constant");
        for (c = i = 0; i < n; ++i) {        /* 多字符常量按大端拼起来 */
            if (is_long)
                c = ((nwchar_t *)tokcstr.data)[i];
            else
                c = (c << 8) | ((char *)tokcstr.data)[i];
        }
        tokc.i = c;
    } else {                          /* 字符串 "..." */
        tokc.str.size = tokcstr.size;
        tokc.str.data = tokcstr.data;
        if (!is_long)
            tok = TOK_STR;
        else
            tok = TOK_LSTR;
    }
}
```

几个细节：

- **短字符串用栈上 `buf[1000]`**，长字符串才 `malloc`。省一次分配，也省一次 free。
- **`n = tokcstr.size / char_size - 1`**：`parse_escape_string` 会在末尾补一个 `'\0'`，
  所以要减 1。
- **`'ab'` 多字符常量**：把字节按 `c = (c << 8) | byte` **大端**拼成一个 int。
  例如 `'ab'` = `0x6162`。这是 C 的历史遗留特性。
- **`'x'` 的类型是 `TOK_CCHAR`，值是 `tokc.i`**；`"x"` 类型是 `TOK_STR`，值是 `tokc.str`。

## 第 3 站：解释转义 —— `parse_escape_string`（`tccpp.c:2015`）

这是本步骤的核心。

```c
/* src/core/tccpp.c:2014-2185（节选）*/
static void parse_escape_string(CString *outstr, const uint8_t *buf, int is_long)
{
    int c, n;
    const uint8_t *p;

    p = buf;
    for(;;) {
        c = *p;
        if (c == '\0')
            break;
        if (c == '\\') {
            p++;
            c = *p;
            switch(c) {
            case '0': case '1': ... case '7':       /* 八进制，最多 3 位 */
                n = c - '0';
                p++;
                c = *p;
                if (isoct(c)) { n = n * 8 + c - '0'; p++; c = *p;
                    if (isoct(c)) { n = n * 8 + c - '0'; p++; }
                }
                c = n;
                goto add_char_nonext;
            case 'x':
            case 'u':
            case 'U':                                /* 十六进制，位数不限 */
                p++;
                n = 0;
                for(;;) {
                    c = *p;
                    if (c >= 'a' && c <= 'f') c = c - 'a' + 10;
                    else if (c >= 'A' && c <= 'F') c = c - 'A' + 10;
                    else if (isnum(c)) c = c - '0';
                    else break;
                    n = n * 16 + c;
                    p++;
                }
                c = n;
                goto add_char_nonext;
            case 'a': c = '\a'; break;   /* 响铃 */
            case 'b': c = '\b'; break;   /* 退格 */
            case 'f': c = '\f'; break;
            case 'n': c = '\n'; break;   /* 换行 */
            case 'r': c = '\r'; break;
            case 't': c = '\t'; break;   /* 制表 */
            case 'v': c = '\v'; break;
            case 'e': c = 27; break;     /* GNU 扩展：ESC */
            case '\'': case '\"': case '\\': case '?':
                break;                    /* 这些转义后就是自己 */
            default:
            invalid_escape:
                tcc_warning("unknown escape sequence: ...");   /* 不认识的转义只警告 */
                break;
            }
        } else if (is_long && c >= 0x80) {
            /* 宽字符串：把 UTF-8 解码成一个码点 */
            ...
            c = n;
            goto add_char_nonext;
        }
        p++;
    add_char_nonext:
        if (!is_long)
            cstr_ccat(outstr, c);        /* 普通串：加一个字节 */
        else {
#ifdef TCC_TARGET_PE
            /* Windows 宽字符是 UTF-16：码点 > 0xFFFF 要拆成代理对 */
            if (c < 0x10000) cstr_wccat(outstr, c);
            else {
                c -= 0x10000;
                cstr_wccat(outstr, (c >> 10) + 0xD800);
                cstr_wccat(outstr, (c & 0x3FF) + 0xDC00);
            }
#else
            cstr_wccat(outstr, c);       /* Linux：wchar_t 是 32 位，直接放 */
#endif
        }
    }
    /* 末尾补 '\0' */
    if (!is_long) cstr_ccat(outstr, '\0');
    else          cstr_wccat(outstr, '\0');
}
```

三块内容：

1. **八进制** `\123`：最多吃 3 位，`n = n*8 + digit`。
2. **十六进制** `\x41`：位数不限，`n = n*16 + digit`。
   （注意 `\x` 能吃任意多位，`"\x41" "B"` 和 `"\x41B"` 不同——前者是 `"AB"`，
   后者 `B` 是十六进制数字，值是 `0x41B`。这是 C 的一个著名坑。）
3. **简单转义**：`\n`、`\t`… 直接换成对应控制字符。
4. **宽字符（`L"..."`）**：先按 UTF-8 解码成码点，再按平台存：
   - Linux/mac `wchar_t` 是 32 位，直接存；
   - Windows 是 16 位，大于 0xFFFF 的码点要拆成**代理对**（surrogate pair）。

**注意结尾补 `'\0'`**：这就是为什么 `parse_string` 里要 `size - 1`。

## 第 4 站：往缓冲里加东西 —— `cstr_ccat` / `cstr_wccat`

```c
/* src/core/tccpp.c:325-336 */
static void cstr_realloc(CString *cstr, int new_size)
{
    int size;
    size = cstr->size_allocated;
    if (size < 8) size = 8;          /* 首次至少 8 字节 */
    while (size < new_size)
        size = size * 2;             /* 每次翻倍 */
    cstr->data = tal_realloc(cstr_alloc, cstr->data, size);
    cstr->size_allocated = size;
}

/* src/core/tccpp.c:338-347 */
ST_INLN void cstr_ccat(CString *cstr, int ch)   /* 加一个"窄"字节 */
{
    int size;
    size = cstr->size + 1;
    if (size > cstr->size_allocated)
        cstr_realloc(cstr, size);
    ((unsigned char *)cstr->data)[size - 1] = ch;
    cstr->size = size;
}

/* src/core/tccpp.c:361-370 */
ST_FUNC void cstr_wccat(CString *cstr, int ch)  /* 加一个"宽"字符 */
{
    int size;
    size = cstr->size + sizeof(nwchar_t);   /* 一次加 4 或 2 字节 */
    if (size > cstr->size_allocated)
        cstr_realloc(cstr, size);
    *(nwchar_t *)(((unsigned char *)cstr->data) + size - sizeof(nwchar_t)) = ch;
    cstr->size = size;
}
```

`CString`（`tcc.h:398`）就是"会自己长大的字节数组"：

```c
typedef struct CString {
    int size;            /* 现在有多少字节 */
    void *data;          /* 字节们 */
    int size_allocated;  /* 分配了多大 */
} CString;
```

**容量翻倍**（`size = size * 2`）是最省事的增长策略：均摊下来，
每个字节只被拷贝固定次数，不用预先算大小。

`cstr_ccat` 加 1 字节，`cstr_wccat` 加一个宽字符（`nwchar_t`：Windows 是 2 字节，其他 4 字节）。
**同一个"字符串"结构，靠这两个函数调用区分窄/宽。**

## 第 5 站：反向打印 —— `add_char`（`tccpp.c:391`）

报错时要把字符串打印出来，需要把字节变回可读文本：

```c
/* src/core/tccpp.c:390-409 */
static void add_char(CString *cstr, int c)
{
    if (c == '\'' || c == '\"' || c == '\\') {
        cstr_ccat(cstr, '\\');       /* 需要转义的先加反斜杠 */
    }
    if (c == '\n') {
        cstr_ccat(cstr, '\\');
        cstr_ccat(cstr, 'n');
    } else if (c < 32 || c >= 127) {
        cstr_ccat(cstr, '\\');       /* 控制字符/非 ASCII：八进制转义 */
        cstr_ccat(cstr, '0' + ((c >> 6) & 7));
        cstr_ccat(cstr, '0' + ((c >> 3) & 7));
        cstr_ccat(cstr, '0' + (c & 7));
    } else {
        cstr_ccat(cstr, c);          /* 普通字符直接加 */
    }
}
```

它被 `get_tok_str`（第 03 篇）用来把字符串 token 打印成 `"a\n"` 的形式。
**这就是编译器报错信息里那个带引号、带 `\n` 的字符串的来源。**

## 【把 t.c 里的字符串走一遍】

假设 `t.c` 里有：

```c
printf("x=%d\n", x);
```

1. 词法阶段：`"x=%d\n"` 被 `parse_pp_string` 原样收成
   `"x=%d\\n"`（注意 `\` 和 `n` 是两个字符），`tok = TOK_PPSTR`。
2. `next()` 看到 `TOK_PPSTR` 且开了 `PARSE_FLAG_TOK_STR`，调 `parse_string`。
3. `parse_string` 去掉引号，得到 `x=%d\n`（4 个"字面"字符：`x``=``%``d``\``n`）。
4. `parse_escape_string` 处理：`x`→`x`，`=`→`=`，`%`→`%`，`d`→`d`，
   `\`+`n`→ 换行符 `10`。末尾补 `'\0'`。
5. 结果：`tokc.str.data = "x=%d\n\0"`，`tok = TOK_STR`。

后面生成代码时，这串字节会被放进 `.data` 段（第 5 部），
`printf` 拿到的就是一个指向它的指针。

## 【常见卡点】

- **为什么分两步解释转义**：因为预处理器要看到原始文本（宏拼接、字符串化）。
- **`\x` 和八进制位数不同**：八进制最多 3 位，十六进制不限位——C 标准就这么定的。
- **`tokc.str.size` 是含 `'\0'` 的**：用的时候常要 `-1`。
- **宽字符平台差异**：Windows 16 位要代理对，Linux 32 位不用。
