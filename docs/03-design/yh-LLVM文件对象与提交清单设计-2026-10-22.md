# yh LLVM 文件对象与提交清单设计（LA4）

日期：2026-10-22。性质：LA4 专项设计门，**本次不改变默认单模块对象构建**。
依据 [LA4 方案 §11](../02-plan/yh-LLVM架构分阶段实施方案-2026-10-22.md) 与
[架构复核](yh-LLVM分支架构复核-2026-10-22.md)。LA3 的函数 IR/check 缓存与
稳定重绑定已完成，可提供文件对象所需的稳定身份。

## 1. 目标

把当前“一个模块一个 LLVM 对象”改为：

```text
module IR
  → 按逻辑定义归属拆成 N 个文件对象
  → 必要的 runtime/support 对象
  → 完整 manifest
  → 最终链接
```

只重建内容/依赖/目标身份变化的文件对象；文件删除、重命名、runtime 需求变化、
单对象损坏和并发失败都不能提交缺对象的成功清单。

## 2. 所有权与分区

- 每个函数/全局实体按符号来源文件归属一个文件对象；无源码的 runtime/合成
  数据进入 support 对象。
- 每个文件对象包含：本文件定义的函数/全局、其读取所需的声明、类型闭包；
  不复制其他文件的定义。
- 全局初始化中的字符串/匿名静态数据归属创建它的文件对象；跨文件共享的
  运行时入口进入 support 对象。
- 分区计划先由纯函数生成（不读写文件），再交给 cmd 发射；计划必须保证
  每个 `defined=1` 实体恰好一个所有者，声明可重复。
- 文件删除/重命名时旧对象进入待删除集合；只有完整新清单成功后才替换。

## 3. 可见性

- 源级 `pub` 与对象级可链接性分离：`.s.i` 仍只导出真实 `pub` 声明，私有类型
  规则不变。
- 模块私有但跨文件对象引用的函数/全局使用模块限定的隐藏身份
  （`__yh_<module>_<logical>`），LLVM linkage 为 `hidden` 外部；
  新增 `IR_MODULE_LINK_HIDDEN`，verifier/序列化/后端同时支持。
- 同文件私有实体可继续 `internal`；对外部/导入符号保持现有 ABI 名称。
- 不在 `.s.i` 暴露隐藏身份，不把私有类型提升为 `pub`。

## 4. 文件对象键与 manifest

文件对象键包含：

- 编译器/schema/LLVM 桥身份；
- 目标 triple/data_layout/ABI、O0/O2；
- 模块环境键与依赖接口内容；
- 文件路径与规范化内容；
- 该文件贡献的函数/全局、类型/符号闭包、重定位与 runtime 使用集合。

manifest 记录：文件对象相对路径、键、对象内容哈希、接口/依赖哈希、support
对象集合。提交顺序：

1. 所有对象写临时文件并完成 machine/verifier 校验；
2. 全部成功后原子发布对象与 manifest；
3. 链接只读完整 manifest；
4. 任一对象失败或并发会话失败不发布新清单。

## 5. 失效矩阵

| 变化 | 期望 |
| --- | --- |
| 一个纯函数文件内容 | 只重建该文件对象；其他对象/support 命中 |
| 删除文件 | 移除旧对象；新 manifest 完整 |
| 重命名文件 | 新路径对象重建，旧对象清理 |
| runtime 使用集合变化 | 相关文件对象 + support 对象重建 |
| 跨文件私有符号签名/类型 | 相关对象重建，隐藏身份不泄漏 |
| 目标/ABI/O 级别 | 全部重建（目录已隔离） |
| 单对象损坏 | 只重建该对象；不发布缺对象清单 |
| 并发失败 | 不发布混合代产物 |

## 6. 实施切片

**LA4.1 分区模型**：`ir` 内纯分区计划；每个实体唯一所有者；声明/类型闭包
可验证；离线探针比较冷编与分区后的函数归属。

**LA4.2 可见性**：新增 hidden linkage、模块限定隐藏名、verifier/序列化/
后端支持；跨文件私有函数/全局可运行，跨模块私有访问仍拒绝。

**LA4.3 对象与清单**：worker 发射多对象 + support；cmd 管键/manifest/原子
提交；链接只消费完整清单。

**LA4.4 回归**：删除/重命名/runtime 集合/单对象损坏/并发失败/只改一个文件
仅重建一个对象；全量 `make test` + `make selfhost-native`。

## 7. 风险

- IR verifier 当前要求 `defined` 符号有实体；分区对象需要允许外部声明，
  必须把“对象内声明”与“模块定义”分开检查。
- 隐藏身份命名不能改变 `.s.i`、诊断名或 ABI；需要独立命名层。
- 字符串/匿名数据的归属若跨文件共享，容易重复定义；初期可保守放入 support。
- 链接缓存键必须包含完整对象清单，不能只看模块主对象。
- 自举/并发会放大 partial publish 问题；先做单文件对象和离线计划，再接生产。
