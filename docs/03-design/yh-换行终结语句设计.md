# yh 换行终结语句设计

修改时间：2026-11-06

版本：0.0.8-rc。让 `\n` 参与语句边界：简单语句、模块头、类型
别名、字段与枚举成员可以省略行尾分号；同一行相邻语句仍用 `;` 分隔。采用
严格续行：括号外的运算符必须写在上一行末尾。

## 规则

- 简单语句、`module`/`import`、`type` 别名、`let`/`const`、结构体/联合体字段
  与枚举成员可以用换行终结；显式 `;` 仍然有效。
- 只有上一 token 能结束语句时才终结：名字、字面量、内建类型、`)`、`]`、`}`、
  `true`/`false`、`return`、`break`、`continue`；成员访问中保留字同名字处理。
- `()` 与 `[]` 内换行不终结语句，允许自由换行；运算符、逗号、冒号、点号之后
  继续读下一行。
- 括号外的行首运算符属于下一条语句，不回接上一行。因此 `a`⏎`+ b` 是两条语句，
  `a +`⏎`b` 是一条表达式。
- `return` 在行尾终结；跨行返回值必须写成 `return (` 或在括号内换行，不再吞
  下一行开头的表达式。
- `}` 前与 EOF 前允许省略最后一个分号；空语句与块后多余的显式分号仍非法。
- 块收尾（`if`/`for`/`switch`/裸块、`fn`/`struct`/`union`/`enum`）后面不写
  分号，显式写 `;` 也仍然报错。
- 结构体字面量字段仍由逗号分隔；只允许最后一个字段与 `}` 之间省略分号，换行
  不能代替逗号。
- 空行与注释不形成语句；块注释内的换行参与边界判断；CRLF 与 LF 一致。

每个边界由相邻 token、括号深度与源位置唯一决定，不依赖名称解析、类型或错误
恢复，因此不存在「一条语句 vs 两条相邻语句」的歧义。

## 实现

1. **词法归一化**（`compiler/lex/layout.yh`）：扫描结束后重建 token 表，在
   「换行处、`}` 前、EOF 前」插入长度为 0 的 `TK_SEMI`，位置取上一 token 末尾。
   括号/方括号内、属性组 `@[...]` 之后、行首 `{` 之前不插入（跳转语句之后的
   裸块除外）；显式 `;` 优先，不重复产生终结符。
2. **解析器**（`compiler/parse/`）：继续复用原来的分号扫描。`p_implicit_semi()`
   用 `len == 0` 区分隐式与显式终结符；`p_take_block_end()` 在块与顶层声明闭合
   后只消费隐式终结符；`p_expect('}')` 单独放行字面量尾部；编译期展开范围
   （`parse_comptime`）跨过块后的隐式终结符。
3. **所有入口共用**：单文件、项目索引、接口加载、编译期正文都经 `lex_all`，
   没有第二条词法路径。
4. **参考语法与门禁**（`docs/yh.g4`、`tests/yh/check.py`）：语法用 `tokens {
   IMPLICIT }` 表示归一化终结符（`stmtEnd : ';' | IMPLICIT`），ANTLR 门禁用与
   `lex_layout` 相同的规则把换行归一化成 `IMPLICIT` 后再解析，因此两套实现
   对同一份语料给出相同判定。
5. **严格续行迁移**：括号外的行首运算符由 `tmp/` 下的一次性脚本移到上一行末尾，
   只移动空白与运算符，token 序列不变；编译器、语料、标准库共 201 + 82 处。

## 边界

- 生成物（接口 `.s.i`、编译期正文 `.s.ct`）继续写显式分号；正文重写把内部换行
  放在 `$` 之后与 `=` 之后，避免重写后意外终结。
- 括号外裸块前保留分号（`{` 前不自动终结）；`return`/`break`/`continue`/
  `goto 名字` 之后的裸块属于下一条语句，仍补终结符。
- 同一行的多条语句、同一行的多个字段/成员仍需 `;`；不为消分号强行拆行。

## 验收

- 语法正反例：`tests/yh/02-basic/04`、`05`，`tests/yh/rejected/45`、`46`；
  模块头正例 `tests/modules/accept/09`，同行缺分隔反例
  `tests/modules/reject/04`。
- 运行语料：`tests/yh-run/run/183`（无分号程序输出 15）、
  `tests/yh-run/fail/158`（非 void 裸 `return` 换行必须报错）。
- 旧种子对新正例必须报错（红灯成立），再用新编译器跑全门。
