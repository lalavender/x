# yh 编译器模块导出面收缩设计

日期：2026-10-12。状态：**已实施**（Linux/WSL 上 `make`、`make test`、
`make selfhost-native` 全绿，并按流程滚 Linux 种子）。
相关：[编译器源码模块化设计](yh-编译器源码模块化设计.md)、
[AST 模块拆分设计](yh-编译器ast模块拆分设计.md)、
[ADR-0007](../adr/0007-yh编译器使用源码模块.md)、
[完成报告](../01-finished/yh-编译器导出面收缩-2026-10-12.md)。

## 1. 背景

模块化后各模块沿用「成模时 pub 从宽」的历史口径：1048 处声明写 `pub`，而其中
461 处（fn/const）没有任何其他模块引用。`pub` 在这个编译器里有两个作用：

1. **接口导出**：决定 `.s.i` 里出现哪些名字，消费者据此绑定；
2. **符号绑定**：`gen/emit_arm64.yh` 的 `em_prologue`/数据/`bss` 发射按
   `F_PUB` 决定是否写 `.globl`——`pub` 函数是 GLOBAL 符号，非 pub 是 LOCAL。

因此「只有别的模块真的用到才 `pub`」既缩小接口文件，也缩小每个模块的全局符号表。

## 2. 收缩规则

| 声明 | 规则 |
| --- | --- |
| `fn` | 有外部引用（别的模块以 `前缀.名字` 引用，含 tests/ 里依赖 `compiler/ir` 的 fixture）才保留 `pub` |
| `const` | 同上 |
| `struct` / `union` / `enum` | **不可收缩**：2026-10-02「pub struct/union/enum 一等化」要求必须写 `pub`，类型一律进接口 |
| `let` | 本就不导出（2026-10-02「let 不导出」）：可变状态经 `pub fn` 访问（`gen.G()`、AST 访问函数） |
| 入口 `main`（cmd） | **强制保留**：CRT 调用它，必须 `.globl` |

判定方法：按 `module X;` 归集源文件；逐文件解析 `import NAME (as ALIAS)?;` 得到
可见前缀（含别名）；在**其他模块**与 `tests/` 的 `.yh` 中查 `前缀.名字`（先剔除
注释与字符串字面量，避免把统计字符串当成引用）。类型闭包只对可能被丢弃的声明
生效——由于类型不可丢弃，闭包实际只影响 const。

## 4. 与「每模块一个结构体 + 一个函数」的距离

收缩后各模块仍导出的项（fn / struct / const）：

| 模块 | fn | struct | const | 说明 |
| --- | --- | --- | --- | --- |
| lex | 1 | 0 | 0 | 已达目标形态 |
| backend | 1 | 0 | 0 | 已达目标形态 |
| main（cmd） | 1 | 6 | 0 | 函数只剩入口 `main`；结构体受语言规则限制 |
| parse | 19 | 2 | 0 | cmd 需要的前端入口与接口读取 |
| ir | 12 | 8 | 42 | `ir` 的模型常量与 SSA API 被 ast/backend 直接使用 |
| ast | 39 | 10 | 29 | parse/cmd 调用的 AST 构造与校验入口 |
| comptime | 71 | 20 | 0 | 编译期登记/求值 API 被 ast/parse 使用 |
| gen | 158 | 21 | 145 | 语义、类型、符号、发射的共享底层 |

能不能进一步压到「1 个结构体 + 1 个函数」：

- **函数**：要压到 1 个，只能把跨模块调用改成门面派发（例如
  `gen.call(op, a, b, c)` 或把函数指针塞进状态结构体）。代价是丢掉参数/返回
  类型检查、调用点从直接 `bl` 变间接跳转（自举编译器本身对编译时间敏感），
  且 145 个 `gen.TK_*`/`IR_TY_*` 常量也要改成取值函数。**不建议**：这是把编译器
  改成动态派发解释器，收益只是接口数字好看。
- **结构体**：`struct/union/enum` 的 `pub` 已按 ADR-0013（2026-10-12）恢复可选，
  不带 `pub` 即模块私有类型、不进接口。精确统计后 **12/66** 个类型可干净私有化
  （ast 5、main 4、comptime 2、parse 1；gen/ir 为 0，消费方直接引用其类型），
  本次全部落地：接口 39,990 → **36,633** 字节，见
  [模块私有类型设计](yh-模块私有类型设计.md)与
  [完成报告](../01-finished/yh-模块私有类型-2026-10-12.md)。

## 5. 维护规则

1. 新增跨模块接口必须有真实消费者；仅模块内使用的 `fn`/`const` 不写 `pub`。
2. 本模块状态用模块级 `let` 承载，跨模块只经 `pub fn` 访问（`gen.G()`、
   `ast.ast_stmt_current_now()` 等模式）。
3. 入口模块 `cmd/` 只保留入口 `main` 为 `pub`。
4. 类型导出面当前由语言规则决定，不视为本规则的收缩对象。
