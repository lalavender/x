# yh 0.0.1 语义边界（M0-04 定案）

修改时间：2026-11-06

> 本文件记录实现前必须确定的语义规则；只有语法形态的问题以 `docs/yh.g4`
> 为准。已确定的规则同时引用 `CONTEXT.md`（类型化变参末尾唯一、for-in
> 绑定为局部值拷贝）。每条决定都须有对应 `.yh` 用例（M3/M4 落地）。

## 1. 前向调用：先扫描顶层函数签名

**决定**：函数体内调用任意顶层函数，不要求定义先于使用。实现按两遍处理
用户源文件：第一遍只扫描并登记顶层 `fn` 的签名（名字、参数、返回）与
`type/struct/union/enum` 的类型名；第二遍单遍编译各函数体与全局变量初始化。

- 全局 `let/const` 初始化表达式仍要求引用先声明的名字（初始化在第二遍按
  顺序求值）；递归初始化不存在。
- 局部声明不前向：块内名字在其声明点之后可见。
- 依据：互递归是常规需求；TCC 单遍模型下"先登记符号再逐个编译函数体"
  改动可控（对源文件重新词法两遍即可，无需 AST）。
- 用例：M3-01 `tests/yh-run/pass/` 互递归正例；`fail/` 引用不存在名字。

## 2. main 与程序入口

**决定**：用户程序必须定义 `fn main() int`（无参数；`int` 与 `i32` 同型）。
编译模式（单文件 `yh -o <out> <file.yh>`，项目模式 `yh build` / `yh run`）
缺少 `main` 或签名不符时报错；`--syntax-check` 不要求。

- 无参 main 与 `int main(int, char**)` 的 C ABI 兼容：入口多余参数被忽略。
  命令行参数捕获已于 0.0.2 落地（`main(argc, argv)`）。
- `main` 的 ELF 符号保持 GLOBAL（crt 引用），无论是否书写 `pub`。
- 返回值即进程退出码。其他函数返回类型省略 = void；`main` 返回类型不可
  省略（保证退出码确定）。
- 用例：`run/hello.yh`、`fail/` 缺 main、`fail/` `fn main()` 返回 void。

> 0.0.3 修正：`main` 返回值即进程退出码这条始终成立，但「与 `tcc_run()`
> 的调用约定一致」的依据已随 C 版 stage0 删除而失效，改为按 C ABI 惯例实现。

## 3. pub 与跨模块可见性（模块系统）

**决定**：`pub` 是语言级可见性修饰符——不加 `pub` 的声明只在本模块内可见，
跨模块访问须声明 `pub`。0.0.3 起本节取代原「无模块/import 机制、`pub` 只影响
ELF 符号绑定」的表述；模块与项目规则见
[模块与项目管理设计](yh-模块与项目管理设计.md)。

- 文件头用 `module NAME;` 声明归属；`import NAME (as ALIAS)?;` 导入本项目
  模块，`import KEY.MOD (as ALIAS)?;` 导入依赖项目模块；入口是
  `module main;`。
- `pub fn` / `pub const`（生成符号的声明）：GLOBAL 绑定，不加 `pub`：
  LOCAL 绑定，跨模块不可见。**`pub let` 非法**（2026-10-02「let 不导出」）：
  let 只能是模块变量或函数局部变量，可变状态跨模块共享经 `pub fn` 封装
  （编译器自身经 `GenState` + `gen.G()` 指针实现）。
- `pub type/struct/union/enum`：控制该类型在接口文件（`.s.i`）中的可见性；
  类型名字面作用域仍限当前模块。2026-10-12 起（ADR-0013）struct/union/enum
  的 pub 可选：带 pub 的类型进接口、跨模块可命名，struct/union 字段一律
  公开并随接口完整携带布局，enum 成员常量随枚举导出（F_PUB），跨模块以
  `模块名.成员` 引用；不带 pub 的是**模块私有类型**，只在本模块可见、不进
  接口，出现在本模块 `pub` 签名、`pub` 结构体字段或 `pub` 类型别名体时报错
  （「pub 接口引用了非 pub 类型」，指针形式同样拒绝）。2026-10-02 至
  2026-10-12 期间曾强制「struct/union/enum 必须带 pub」。
- 局部 `pub` 报语法错误（现有 rejected/19_local_pub.yh）。
- 用例：`tests/modules/projects/pubpriv/`（跨模块字段访问/位置式构造/
  私有函数）与 `tests/modules/build-check.py` 的 `u3-pub-field-access`、
  `u3-positional-pub-construct`、`u3-private-fn`。
- 用例：M3-01 `readelf -sW` 核对 pub→GLOBAL、非 pub→LOCAL。
- 模块私有类型用例（2026-10-12）：`tests/yh/03-decl/10_private_types.yh`、
  `tests/yh-run/run/175-private-types.yh`、
  `tests/modules/accept/08-private-type.yh`，以及
  `tests/modules/projects/privtype/` 的 7 条 build-check 用例
  （`u3-private-type-*`、`u3-private-enum-member-not-exported`）。

## 4. 字符串字面量：类型与可写性

**决定**：字符串字面量类型为 `*char`（NUL 结尾匿名 `char` 数组退化）。
0.0.1 存储落在可写数据节（TCC 现行为，`decl_initializer_alloc` 用
`data_section`），通过字面量指针写入是**允许但未定义内容共享语义**的低层
操作；语言不提供"字符串不可写"保证，也不做运行期防护。

- 依据：TCC 0.9.27 无 rodata 落地路径；方案 §4.1 明确不能靠 `const` 绑定
  宣称不可写。若要只读，需先设计指针限定符（0.0.2+）。
- `const P *char = "hi";` 只是绑定名不可再赋值，所指存储仍可写。
- 用例：M3-02 记录性用例（不验收写行为，验收字面量读取与 strlen）。

## 5. 零长度数组与数组赋值

**决定**：

- `[0]T` 编译期报错（数组长度必须是 ≥1 的编译期整数常量；负值同样报错）。
- 同型数组赋值 `a1 = a2;`（`[N]T` 同型，长度相同）合法，语义为整体值复制
  （编译为块拷贝，走结构体赋值路径）；长度不同即不同型，拒绝。
- 数组比较（`==`/`!=`）拒绝；数组做算术运算拒绝。
- 用例：M4-01 `run/` 赋值复制独立性、`fail/` 零长度与跨型赋值。

## 6. 切片边界与生命周期（已声明边界，不做防护）

**决定**：0.0.1 不做切片边界检查，越界下标是未定义行为；`len(s)` 读
len 字段，`s[i]` 降糖为 `s.data[i]`；空切片 `data == 0`，解引用空 data
是未定义行为。

- `[N]T.to_type([]T)` 生成的视图 `{len:N, data:&arr[0]}` 指向原数组存储；
  原数组是局部变量时，函数返回该切片即悬垂视图——0.0.1 不做静态生命周期
  证明（方案 §4.1 既定），文档与用例注释明示。
- 用例：M4-02 `run/` 视图构造与遍历；边界说明写入用例注释。

## 7. 裸 C 变参：窄整数与浮点提升

**决定**：仅 prelude 函数（`printf`、`open`）允许裸 `...`；用户源码写
裸 `...` 报错（rejected 语料）。调用 prelude 变参函数时，实参按 C 默认
提升后再进变参位置：`i8/i16/u8/u16/bool/char → int`，`f32 → f64`，
数组/切片不进裸变参（指针按指针传递）。类型化变参 `name ... T` 不做提升，
按声明类型 T 打包为切片。

- prelude 签名（M3-01 直接登记 extern Sym，不注入 yh 文本；
  `read`/`close` 为 0.0.2 自举 B1 新增——stage1 须从文件描述符读入
  源码字节，用完关闭）：

  | 符号 | 签名 |
  | --- | --- |
  | printf | `fn printf(fmt *char, ...) int` |
  | malloc | `fn malloc(size u64) *void` |
  | free | `fn free(p *void) void` |
  | memcpy | `fn memcpy(dst *void, src *void, n u64) *void` |
  | strlen | `fn strlen(s *char) u64` |
  | exit | `fn exit(code int) void` |
  | open | `fn open(path *char, flags int, ...) int` |
  | close | `fn close(fd int) int` |
  | read | `fn read(fd int, buf *void, count u64) i64` |
  | write | `fn write(fd int, buf *void, count u64) i64` |

- 用例：M4-03 Linux 上 printf 各提升组合、open/write 回路；
  read/close 见 0.0.2 B1 的 `tests/yh-run/run/16..18`。

## 8. 类型化变参与 for-in（CONTEXT.md 既定，编译器强制）

- 类型化变参：参数表末尾至多一个 `name ... T`；其余位置或重复出现报错。
  函数体内该参数是 `[]T`；零变参传 `{len:0, data:0}`；实参按源码顺序求值
  并打包进存续到调用结束的临时数组。
- for-in：绑定只在循环体可见；每次迭代复制下标/元素值；修改绑定不影响
  容器；区间左闭右开，空区间执行零次（不以 `b-a` 作循环长度）。

## 9. const 语义

**决定**：`const` 是编译期常量绑定：初始化表达式必须可编译期求值
（整型/浮点/bool/字符字面量及其运算、其他 const、字符串字面量地址）。
const 值可参与 case 表达式与数组长度。`const` 不表示"指向只读存储"
（见 §4）。const 无类型省略（语法已强制显式类型）。

- 用例：M3-01 const 用作 case 值/数组长度正例；非常量初始化 `fail/`。
