## 一、这套文档怎么用

1. 顺序读 01 → 06。每一篇都拿**同一个程序**当例子，从头贯穿到尾：

```c
/* t.c —— 全书唯一主角 */
#define K 8
int add(int a, int b) { return a + b; }
int main(void) {
    int x = 3;
    int y = 2 * K;
    x = add(x, y);
    return x;          /* 期望退出码 = 19 */
}
```

2. 每篇先讲"这一步输入什么、输出什么"，再贴源码、逐行讲。
3. 文末有【本步日志】，把你该记住的那几行写成一个清单。
4. 源码路径用重组后的新目录：`src/core/`（核心）、`src/targets/`（后端）、
   `src/formats/`（目标格式）。

## 三、贯穿全书的“追兔子”约定

每篇都在追同一只兔子：`t.c` 里的 `main` 怎么从 19 个字符变成退出码 19。
你会反复看到这条链条：

```
源文件 ──next()──▶ token ──unary()──▶ 值栈 SValue ──gv()──▶ 寄存器
      ──gen_op()──▶ 机器码字节 ──写进 Section──▶ .text
      ──链接器──▶ 可执行/内存 ──CPU 执行──▶ 退出码 19
```

每篇只点亮这条链上的一段，全部读完后链条就通了。
